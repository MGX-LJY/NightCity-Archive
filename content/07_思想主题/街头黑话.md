# 街头黑话

> 英文原名: **Streetslang**
> 类别: 夜之城街头通用俚语 / 赛博朋克亚文化语言

## 类型

夜之城街头通用的俚语体系——国际化、技术黑话与犬儒态度交织而成。
本页为**精选词典**，收录在本宇宙高频出现、且与本档案各节点相关的词条，并非全集。

## 词汇精选

### 身份与人

- **边缘行者**（Edgerunner）——活在社会"边缘"、靠义体 / 武器 / 智谋对抗巨头的人，通常游走法外
- **公司狗 / 公司人**（Corpo）——公司雇员 / 高管；也是一种出身路径
- **乔姆 / 朋友**（Choom / Choomba / Choom）——新非裔美语，指朋友或家人
- **冈克**（Gonk）——蠢货、傻子；也指"蠢到家的举动"（a gonk move）
- **顶尖 / 牛**（Preem，源自 premium）/ **Nova**——棒极了、酷毙了
- **[[Fixer|中间人]]**（Fixer）——居间牵线、派活的人（详见 [[Fixer]]）
- **网络黑客**（Netrunner / Deckhead）——潜入网络的黑客
- **欢愉玩偶 / 性工作者**（Joytoy）——性产业从业者
- **玩偶**（Doll）——装有解离义体、可让"半空白人格"临时接管并事后抹除记忆的人（详见 [[性偶]]）
- **浪人 / 武士**（Ronin / Samurai）——自由雇佣刺客 / 受公司雇佣的打手
- **[[流浪者七大邦|流浪者]]**（Nomad）——以部落式"家族"在城市外流动求生的群体
- **异人**（Exotic / Throwback）——把身体生物改造成非人外观（毛皮、长耳、獠牙）的人
- **有机人**（Ganic）——几乎没装义体的人
- **对象**（Input / Output）——2077 中 Input 指男友、Output 指女友（早期游戏中相反）
- **[[高轨者联盟|高轨者]]**（Highrider / Alien）——出生或长期工作在太空的人（地表蔑称 Alien）
- **摇滚客**（Rockerboy）——用艺术作政治 / 社会表达的乐手（区别于被唱片公司"豢养"的 Rockstar）
- **增强帮**（Booster / Boostergang）——装义体、穿皮衣、滥施暴力的帮派成员

### 义体与精神

- **铬 / 改造**（Chrome）——即 [[义体]]；装义体叫 **Chromed / Chipped**
- **全身改造 / 铁脑壳**（'Borg / Metalhead）——除脑外几乎全机械化的人（含贬义）
- **着魔**（Hexed）——患上 [[赛博精神病]]，或对网络走火入魔
- **生体监测**（Biomon）——医疗义体，持续监测生命体征；[[创伤小组]] 据此判断该救谁
- **桑迪**（Sandy）——斯安威斯坦（Sandevistan）反射加速器的俚语简称
- **[[义体|义体医生]]**（Ripperdoc）——专装非法义体的地下医师

### 网络与超梦

- **黑冰**（Black ICE）——可击杀入侵黑客的反人员防御程序（如 [[灵魂杀手]]）；ICE 即入侵对抗电子措施
- **[[超梦]]**（Braindance / BD）——记录并重放他人完整感官与情绪的技术
- **极限超梦**（XBD）——含暴力、虐杀等的非法超梦
- **舞者 / scroller**（Braindancer）——被录制超梦的人
- **生料超梦 / virtu**——未经编辑的原始超梦
- **肉身空间**（Meatspace）——黑客对物理世界的称呼
- **R.A.B.I.D.S.**——网络传奇 [[巴特莫斯]] 死后扩散到旧网络的致命黑冰

### 钱、物与交易

- **欧元 / 油子**（Eddies / Ennies，2070s）/ Ebucks（2020s）——欧洲元（eurodollars）
- **钱**（Scratch / Jack）
- **芯片 / 数据片**（Chip / Shard）——数据存储介质
- **夜市 / 午夜市场**（Night Market / Midnight Market）——中间人临时摆设的黑市

### 暴力与死亡

- **抹平 / 归零 / 报废**（Flatline / Zeroed / Wasted / Iced / Geeked）——杀死 / 死亡
- **铁家伙**（Iron）——枪
- **雇佣肌肉**（Huscle）——保镖 / 打手
- **回收**（Recycling）——把人杀掉、尸体送去器官库

### 消费与食物

- **SCOP**（单细胞有机蛋白）——占食品总量约 20% 的廉价主食；也用作"低质"的蔑称
- **狗粮口粮**（Kibble）——形似猫狗干粮的廉价食品
- **战斗区**（Combat Zone）——治安彻底崩坏、警方放弃的法外区域
- **街头 / 地下**（The Street / The Metro）——夜之城的亚文化与地下世界

## 世界观意义

街头黑话是 [[公司统治]] 时代底层文化的语言层证据：

- **多语混杂**——日语（giri 义理 / gaijin 外人 / ronin / samurai）、西语（gato）、俄语（organiskaya 俄黑帮）的渗入，
  正是公司全球化把各国劳力搅在同一座城市的副产品
- **技术黑话日常化**——chrome、netrun、biomon、flatline 等词把赛博技术下沉为口头禅，
  说明义体与网络已不是奇观，而是空气
- **对死亡的轻佻命名**——zeroed / wasted / iced / geeked 一长串杀人同义词，
  是暴力常态化后语言自然长出的厚茧
- 与 [[Fixer]] 一样，许多街头身份（边缘行者、浪人、增强帮）最初都只是黑话，
  最终却定义了整座城市的社会结构——**先有词，后有人照着词活**
