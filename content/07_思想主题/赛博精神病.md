# 赛博精神病

## 核心命题

[[义体]] / 神经植入超出某一阈值后，使用者会出现严重的人格解体与同理心丧失，
最终爆发无差别暴力，直至肉体被清除——
这是 [[公司统治]] 时代义体产业最普遍的"系统副作用"。

赛博精神病并非纯粹的硬件故障，而是机械改造与社会心理压力**共同作用**的产物。

## 病因（四个维度）

### 1. 身体异化

肉体被金属与塑料逐步替换，使用者对自身的"人类身份"产生持续怀疑——
身体在哪里结束、零件在哪里开始，没有人能给出干净的答案。
（参见佛教比丘的同源论证：《[[佛教与义体 新观点]]》）

### 2. 同理心 / 人性枯竭

按官方 TTRPG 设定，每装一次义体都会损耗"人性"（Humanity，由 EMP / 共情属性决定）：

- 人性归零的人会把普通人类视为低等、脆弱的生物
- 这是渐进式而非突变式的——一台一台义体的边际损耗最终积成临界

### 3. 阶级与社会压力

- 底层穷困、超负荷工作、战后 PTSD、长期暴力创伤——
  社会压力是触发器，不是次要变量
- 夜之城本地调查显示：赛博精神病更频繁地爆发在被公司外包出去的底层中

### 4. 劣质硬件 / 黑客攻击

- 未经临床测试的黑市义体、不兼容的硬件
- 黑客的恶意代码可直接烧毁神经元，触发急性精神错乱
- [[扭扭街]] 一带的"不三不四的义体医生"是低端案例的孵化点
  - 具体样本 A：义体医生**米勒**给客户**高客**装疼痛编辑器没装好，
    客户疼到威胁要剜眼睛、要一手术刀切米勒的喉咙
    （参见 [[对话记录 高客和米勒]]）
  - 具体样本 B：黑医**凯萨·赫尔佐格**——
    使用**从荒坂员工身上摘的盗窃义体**（"动一半手术醒过来那个，那公司的小姑娘嚷得跟什么似的"）
    + 客户**贾克斯**装完植入体后开始"犯病"
    + 凯萨还要靠中间人**拉希姆·贝吉尔**提供"**带冰雪软件的芯片**"破解被锁死的义体
    （参见 [[对话记录 贾克斯·奥康纳和吉尼娅·撒克逊]] + [[对话记录 凯萨·赫尔佐格和拉希姆·贝吉尔]]）
  - 这种"装错植入体 → 客户疯狂"的瞬间是赛博精神病爆发期的预演场
  - "**人一嗑屁植入体就会锁上**"——
    这条业内常识印证了"黑客攻击可烧毁神经元 / 锁死义体"的硬件机制

## 临床表现（三期）

### 初期
- 疏远人群、回避社交、拒绝与亲友接触
- 对机械设备表现出超乎寻常的狂热

### 中期
- 剧烈情绪波动
- 作息与饮食规律崩溃
- 出现自大、偏执、施虐倾向

### 爆发期
- 人性彻底湮灭
- 爆发无差别自残 / 谋杀 / 恐怖袭击 / 大规模暴力
- 通常以肉体被清除告终

> 已知典型病例：[[音频抄报 贾克斯·福格雷夫和诺娃·麦克斯特]] 中诺娃·麦克斯特短时间内表现出全部三期特征——
> 包括"它是活的，在我的脑袋里"的体感、"撞死城里所有条子"的无差别冲动。

## 文学样本

赛博精神病在大众文化里以悬疑 / 黑色小说的形式被反复讲述——
样本不是为了科普，而是为了让公众"理解"这种症状的存在感：

- **《[[犯罪现场]]》**：老警探麦克莱恩与初级督查马林诺夫斯基查案。
  现场是一具被残杀的尸体，老警探不动声色地分析"这就是赛博精神病人作案"。
  剧情转折：当马林诺夫斯基指出"窗外脚印是你的"、当老警探掏出受害者口袋里的照片发现是**自己的脸**——
  他才意识到凶手就是他本人，且他对此毫无知觉。
  > "我活得太久了…警察活得越久，最后就越明白，其实自己是在给死神打下手。"

  这个样本是赛博精神病爆发期的典型表征：
  - 行为已严重失控（杀人、爬墙、栽赃）
  - 自我认知与行为完全脱钩
  - 受害者通常是熟人（"两个人应该认识"）
  - 同事 / 学徒成为最后的执法者——
    与 [[MaxTAC 暴恐机动队]] 的逻辑同构

## 被除名的真相

参见 《[[赛博精神病的真相]]》——一篇被泽塔科技赛博义体研究团队**直接除名**的研究宣言。

作者立场（与本节点上文论点高度同构，可作为体制内对该议题的官方否认与边缘研究者反击的样本）：

- **不存在"在条件简陋的义体医生诊所感染"** 这一说法——这是公众迷思
- 科学家们"**根本否认它的存在**"——但他们从 **[[义体]] 游说集团**那里领取丰厚薪水
- 真正成因：
  > "完完全全就是当代生活方式造成的，是人们过度强调现代科技和日常生活相结合所催生的副产品"
- [[义体]] 植入体只是**催化剂**，不是病因
- **真正的临床盲区**：
  > "并非所有的赛博精神病都是装有斯安威斯坦反射技术的在册退役老兵或者前雇佣兵。
  > 并非所有人都会和暴恐机动队展开激烈交火。
  > 在我们这个世界，许多赛博精神病患者只有一个植入体：一副膝盖，一个肝脏。
  > 他们不被注意，不被察觉。"
- 也就是说：**绝大多数病患永远都不会被诊断出来**——他们安静地病在膏肓，无人为此做点什么
- 这一证言为本节点上文"**穷人发病时面对的是 MaxTAC 的枪口**"提供了第二层补强：
  连"发病"这件事本身，在底层都是被刻意忽视的

> "我被泽塔科技赛博义体研究团队除名的事实，足以证明这篇宣言的价值。"

## 应对机制

### 暴力路径：[[MaxTAC 暴恐机动队]]
- [[NCPD]] 下属特种部队，专门"现场清除"爆发期患者
- 内部讽刺：成员本身大多是被体制化收编的赛博精神病患者
- 公司制造的副作用，最终由同一种副作用的"驯化版本"来处理

### 治疗路径：超梦疗法
- 若患者能被活捉，义体医生剥离其全身攻击性 [[义体]]
- 强行接入定制 [[超梦]] 程序
- 通过精神分析与记忆重组，尝试拼凑残存人性
- 成功率不公开，且只有有钱的患者能买得起

### 公司内部"安抚式处置"通道（莫厄尔中尉案）

参见 [[对话记录 马丁·西普拉医生和莫厄尔中尉]] + [[命令]]——

军用科技军官**莫厄尔中尉**"红色警报"发病：

| 阶段 | 行为 |
|---|---|
| 自己报告 | 中尉拨通公司医生 [[马丁·西普拉医生]] 求救：抽搐、腹绞、植入体关不掉 |
| 公司医生承诺 | "军用科技是不会不管自己人的"——派他去**偏僻地址自行隔离** |
| 公司话术 | "要不了几天你就会恢复正常的""你为公司效力，公司也会照顾你" |
| **真实下场** | NCPD 同步签发 [[命令]]：**代码红色 / 危险 / 恶性不可治疗 / 可以进行突袭** |

这条线揭示：

- 公司表面给员工**安抚通道**，让他自愿离开人群躲到偏僻处
- 暗中医生与 NCPD 通气——所谓"偏僻地址"实际是**便于突袭清除**的隔离坐标
- "公司会照顾你" = "公司会让你死得离群众远一点"——
  这是夜之城最隐秘的赛博精神病处置变种：
  **不让 [[MaxTAC 暴恐机动队]] 上街曝光**，
  改用专属命令系统**直接派精英突袭队定点清除**
- 与公开 MaxTAC 路径对照：

| 路径 | 用于谁 | 公开度 |
|---|---|---|
| MaxTAC 街头清除 | 街头 / 黑市义体用户 | 高 / 媒体能拍到 |
| 内部安抚 + 突袭定点清除 | 公司员工 | 零 / 连同事都不知道 |

- 患者本人在被处决前的最后一句话是"谢谢"——
  公司话术的最高完成度：让被杀者感激

参见 [[报告草稿 码头分销]]——

>  但是当然了，我们不会在报告里提到这一点。"

- 这是夜之城档案里**最直白的供应商认罪样本**——
  分销链知道因果关系，且**主动决定不写入正式报告**
- 配合方案："**也许再过几个月我们就可以通过建模来得到精确模拟的结果**"——
  公司化的语言把死亡变成需要"精确建模"的待优化变量
- 看守弗兰克本身就因为掺扑热息痛的批次被掺出问题，
  管理者评估的解决方案不是停售，而是**换成康陶机器人接管看守**
- 这一份草稿直接坐实了本节点的核心命题：
  赛博精神病不是"个人疾病"，而是**供应链已知且不报的外部性**

### 第一人称发病者的语言模板

爆发期 / 准爆发期患者的自白在档案中高度同构——
四份独立第一人称文本共用同一种"仪式化死亡话语"：

| 文本 | 关键词 | 共通修辞 |
|---|---|---|
| [[硬启动]] | "鲜血流过光纤""通往深渊的大门""硬重启 / 蓝屏 / 大脑格式化" | 把自身死亡说成系统升级 |
| [[时辰已到]] | "硅晶渴望鲜血""电线滋滋响""深渊已经失去耐心""深渊饿了" | 把暴力欲望说成硬件需求 |
| [[我早就知道会这样]] | "我跟这帮脑子都接在一块儿的王八蛋拼了""死也要拉他们垫背" | 把走向同归于尽说成早就预见的必然 |
| [[永别了]] | "我就是一个怪物！！！！""压力越来越大越来越大但我不知道什么时候会爆" | 把对自己的厌恶说成等待引爆的能量 |

四份样本说明：

- 赛博精神病爆发前的自我描述**已经被技术词汇彻底入侵**：
  "硅晶""光纤""硬重启""格式化"——患者用机器零件思考自身
- "深渊"是反复出现的隐喻——
  患者把即将爆发的暴力体感**外化为某种非人格的客体**，
  避免承认是"自己"想要杀人
- 都伴随着**仪式化的告别叙事**——
  写信、留言、自我辩白——
  说明发病者在临界点仍试图把暴力嵌入"故事"以获取意义
- 这套语言已经**模板化**——
  意味着发病者并非完全失语，他们使用的是被夜之城街头与亚文化共享的赛博精神病话语包

### 商品化的赛博精神病暴力：[[西贡姐妹 大纲|《西贡姐妹》]]

参见 [[发给黄灵的消息]] + [[发给黄淘的消息]] + [[西贡姐妹 大纲]]——

档案中保存了一组三联文本：

1. 姐姐**席琳**写给黄灵：承诺保护其婚礼安全，"淘还在昏迷"
2. 同一席琳（"灵 xoxo"）写给黄淘：自曝在婚礼下药 +
   "**特意从扭街最最恶心的义体医生那里专门为你挑来了最难看的义体**"，
   把黄淘改造成战斗植入体怪物，并要嫁给原本属于黄淘的未婚夫**肯尼**
3. 同期 [[超梦]] 制作公司一份名为《西贡姐妹》的剧集大纲——
   情节几乎逐字复刻：黄淘装战斗植入体在婚礼袭击黄灵 + 落水结尾

这意味着：

- **真实的赛博精神病暴力 → 直接被超梦工业改编成剧集**——
  受害者尚未死透，剧本已经写完
- 标题中的"**西贡姐妹**" = 战后东南亚移民符号 +
  夜之城常见的"姐妹相残"恶趣味题材，
  超梦行业把私人创伤打包为**类型化娱乐**
- 与 [[2069利琪死亡表演事件]] 同构——
  夜之城对暴力的最终处理方式不是法律，而是**改编为可消费产品**
- 这一组样本同时确认：赛博精神病的"加害者"
  不只是装义体的人，
  更是**给受害者强制装义体的人**——
  本案中真正的精神病人是席琳，而被诊断的"怪物"是被她改造的黄淘

## V 的免疫案例

主角 V 在装有大量顶级 [[义体]] 的情况下并未发病，原因：

- 脑内植入 [[Relic]] 芯片，承载 [[强尼银手]] 的意识印记
- [[Relic]] 在不断**重写和修复**宿主的神经系统
- 同时两个意识（V + 强尼）共同分担义体造成的精神侵蚀

这是目前已知**唯一**能对冲赛博精神病的硬件路径，但代价是宿主与印记之间的边界持续侵蚀。

## 小北斗的"献祭狂热"——非义体的赛博精神病

[[小北斗计划]] 提供了一个**完全脱离义体过量**的赛博精神病样本：

- 该项目研究员长期与 [[黑墙]] 之外的 AI 接触（封印 / 驯化 / 穿透）
- 基地终端日志显示：随着研究深入，
  实验人员心理逐渐扭曲——说疯话、产生
  "**自愿向系统献祭、与 AI 融为一体**"的狂热
- 这是 [[公司统治]] 时代意识技术对人格的"反向腐蚀"的最纯粹样本
- 暗示：赛博精神病的**真正根源**可能不只是义体，
  而是**人类意识与非人类意识技术的长期接触本身**
- [[百灵鸟]] 在数十年后被 NUSA 工具化频繁穿透黑墙——
  其精神被蚕食的过程，与当年研究员的"献祭狂热"完全同构

这一样本要求重写本节点的核心命题：
赛博精神病不只是义体产业的副作用，
还是**所有"意识可被改造"的技术体系的共生现象**。

> 用"精神病"的命名来抹掉系统性责任。

## 世界观意义

赛博精神病是 [[公司统治]] 时代身体商品化最完整的副作用：

- 公司供应病因 → 让公共执法清除症状 → 再卖治疗——
  整个链条上的每一环都在赚钱
- 它被建构为**个人疾病**而非**公司外部性**：
  叫"精神病"暗示责任在使用者，叫"系统副作用"则指向责任在公司——
  公司选择前者，而且词典也归公司
- "解药"由 [[Relic]] 这种顶级商品提供，意味着对抗赛博精神病也是阶级问题——
  穷人发病时面对的是 MaxTAC 的枪口，富人面对的是义体医生与超梦疗法
