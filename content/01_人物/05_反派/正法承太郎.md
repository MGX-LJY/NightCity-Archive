# 正法承太郎

> 英文名: Jotaro Shobo (条太郎·正坊)

## 身份

[[虎爪帮]] 高层 / 歌舞伎区"**河原俱乐部**"(Ho-Oh)酒吧老板 /
**虐杀超梦(XBD)导演** / 黑市人口贩子 / 夜之城最黑暗的"导演"

## 特征

- 名字梗:CDPR 故意挪用《JOJO 的奇妙冒险》**空条承太郎**的名字——
  但作恶完全相反:
  - 原作承太郎:正义守护者
  - 本作条太郎:夜之城最黑的虐杀产业链主理人

## 关键事件

- **XBD 虐杀超梦工业化经营**——绑架无辜市民、流浪者、性工作者录制虐杀超梦
- **艾芙琳·帕克之死**——其产业链的著名受害者
- **【委托:怪物狩猎】**——中间人 [[瑞吉娜·琼斯]] 派 [[V]] 在河原俱乐部三楼解决他
- **NCPD 内部渗透**——买通 NCPD 警员安娜·哈米尔,反向出卖线人伊万·佛雷克斯

## 已知活动 / 深度档案

### 公开身份 vs 真实身份

| 层 | 内容 |
|---|---|
| **公开** | 歌舞伎区**河原俱乐部**(Ho-Oh)酒吧老板 |
| **实际** | [[虎爪帮]] 高层 / XBD 虐杀超梦导演 / 黑市人口贩子 |

### 罪行:虐杀超梦 XBD 工业化

经营路线:

- 绑架**无辜市民、流浪者、性工作者**
- 在镜头前**残忍折磨、虐待、杀死**他们
- 录制成极度重口味的 **XBD(极限超梦)**
- 卖给有**特殊癖好的富豪**

完整的"虐杀消费"产业链:

- 公司提供技术([[超梦]] 头环)
- [[虎爪帮]] 提供地点、武装、清理
- 条太郎本人担任**导演 + 选角 + 处理人**
- 富豪买家提供市场

### 关联事件:艾芙琳·帕克之死

- [[艾芙琳·帕克]] 是 [[朱迪]] 的好友
- 卷入 XBD 黑产链后**被迫害致死**
- 她身上的**致命黑超梦**就是条太郎所在产业链制作的
- 这条线是 [[朱迪]] 整条主线复仇与夺权动力的根源

### 委托:怪物狩猎

中间人 [[瑞吉娜·琼斯]] 发布给 [[V]] 的赏金任务——

- 任务目标:潜入河原俱乐部**三楼**,解决条太郎
- 玩家路径:
  - **击杀**:螳螂刀分尸 / 猩猩手臂砸烂 / 扔进毒气管道——
    民愤极大,玩家开发出大量花式死法
  - **活捉**:非致命打晕后扛出俱乐部,塞进瑞吉娜派来的车——
    瑞吉娜会表示他会受到"**应有的审判**"(通常生不如死)

### 买通 NCPD 的内部眼线:伊万案完整闭环

参见 [[伊万泄密被承太郎报复链]]——

承太郎已经**买通 NCPD 内部**,把警察当作自己的眼线:

- 13 号摊小贩伊万信了 NCPD 警员**安娜·哈米尔**,告诉警察歌舞伎区市场做生意的事
- 安娜表面承诺保护伊万,转身把情报**反向送回承太郎**:
  > 承太郎:"好,NCPD 的小伙子们给我交了底。走漏消息的人查出来了,伊万·佛雷克斯。"
- 承太郎下令"**场面给我弄得大一点。得让他们全都知道知道好歹**"——
  公开示众处置,作为对其他线人的恐怖威慑

#### 安娜·哈米尔的双面身份

- **明面**:NCPD 警员,以"保护证人"为名招募线人
- **暗面**:承太郎在 NCPD 的眼线,把线人情报反向回流给虎爪帮
- 这与之前 [[对话记录 安娜·哈米尔和比尔·亚当斯]] 中她"受雇杀警察科瓦尔斯基"
  构成同一个人的腐败横截面:**她同时为多个雇主工作**

#### 玛莎·佛雷克斯的反应

- 玛莎(伊万妻子)叫他**去美泉区的码头逃跑**——
  说明这种"被 NCPD 出卖 → 等死"的剧本在歌舞伎区**人人都知道**
- 玛莎说"你真是个天真的白痴"——
  在虎爪帮地盘上信 NCPD 等于自杀,这是夜之城底层共识

#### 承太郎反间谍机制总结

结合本案 + [[承太郎追猎惠子 杰科救援]]:

| 流程 | 工具 |
|---|---|
| 监控逃跑 / 泄密 | NCPD 眼线 + 自家义体大夫情报网 |
| 抓捕 | 直接派 13 号摊那种"自己人去找他" |
| 示众处置 | "场面办大点" — 公开恐怖威慑 |
| 协助者收编 | 给钱(义体大夫) — 反向变眼线 |

承太郎不只是 [[虎爪帮]] 内部一个 XBD 导演——
他在 NCPD、义体黑诊所、街头线人网络都有自己的**反间谍渗透网**。
这让他在主线后期被 V 杀掉之前几乎不可能被告发——
告发者一开口就死。

### 联动影响

  舞子和朱迪商量夺取**云顶妓院**控制权时,

- 即把"个人复仇"与"产业接管"在 V 的时间线上**串成一条因果链**

### 关联档案碎片的重新解读

之前在原始文本中出现的"承太郎"相关碎片,
全部应在"XBD 导演 + 虐杀产业链"框架下重新理解——

#### [[定制订单]]:武士刀形状假鸡巴

- 不是"武士道狂热"——
  而是**虎爪帮日式黑帮美学** + **病态恋物癖**
- 与他在 XBD 镜头前折磨受害者的角色一脉相承

#### [[合同 加密承太郎]]:"荒坂男孩"暗号

- 加密合同中的"荒坂男孩"+"100 / 250 单位"
- 极可能是 XBD **受害者代号 + 计费单位**——
  "男孩" = 绑架对象类型,"单位" = 录制时长 / 客户档次

#### [[对话记录 彼得和承太郎]]:集装箱国际人口贩卖直接证据

承太郎亲自接收**跨国集装箱人口贩卖货物**——
参见 [[对话记录 彼得和承太郎]]:

- 上游运输商**彼得**通过集装箱**海运一星期**把"货物"运到夜之城
- 抵达后承太郎说"**可算来了!我派人过去**"——
  说明这是**承太郎本人长期固定的进货渠道**
- 彼得描述货物状态:"**一个个累得不成人形,还臭烘烘的 / 在集装箱里待了一个星期**"
- "**你要多少人干嘛?:D**"——彼得明确说"人"
- 承太郎一听员工多嘴立刻**摆架子施压**:
  > "谁他妈要你多嘴了?/ 你还有别的什么自以为是的意见?"
- 最后用"哥儿们我逗你呢!别紧张!"收尾——
  典型黑老大威吓后**强行装亲热**的话术
- 这段对话第一次**用承太郎自己的嘴**承认 XBD 产业链的**入货端**:
  - 不止抓街头人,还跨国集装箱走私
  - 承太郎本人**直接对接货源**(不全是底层经办)
  - 货源属性"集装箱待一星期"——
    与 [[艾芙琳·帕克]] 这类"街头精选"不同,
    这一线是**廉价批量**——可能用于流水级 XBD 拍摄

#### [[承太郎追猎惠子 杰科救援]]:追猎逃跑货品的标准流程

参见 [[承太郎追猎惠子 杰科救援]]——

承太郎对**逃跑的性奴 / XBD 候选受害者**的标准追猎流程:

1. **货品装追踪器**——惠子身上有承太郎的定位器
2. **义体大夫拆器**——杰科带惠子找朋友(义体大夫)拆掉定位器
3. **承太郎反向追踪**——丈带人找到义体大夫
4. **义体大夫被收买**——承太郎下令"**给他钱**",
   不是杀,而是**列入承太郎情报网**:
   > "再有妓女去找他,让他先通知我们"
5. **逃跑者本人公开示众处置**——承太郎下令:
   > "要让大家瞧见 / 让大家瞧瞧这婊子敢从承太郎手里逃走是个什么结果"

这段对话第一次揭示承太郎**对内部逃亡的完整反应机制**:

- 承太郎手下不只是绑架陌生人——
  受害者**身上装定位器**,被当作**家畜级别管控**
- 对**逃亡未遂者**:公开示众处置作为帮派恐怖威慑
- 对**协助逃亡的义体大夫**:**收买而非杀**——
  这是更冷酷的处置:让协助者**反过来成为眼线**,
  下次再有妓女来拆定位器,第一时间通报承太郎
- 承太郎的情报网由此**渗透进义体黑诊所体系**——
  整个夜之城的地下医疗系统都被他逐步染指

#### 杰科:拆定位器的义体大夫案

参见 [[承太郎追猎惠子 杰科救援]]——

- 杰科:嘴巴装义体的小白脸,承太郎称之为"那个狗日的小白脸"
- 主动救人:在惠子犹豫时直接说"今天,你今天走 / 多等一天就多一天暴露的风险"
- 路径:找朋友(义体大夫)拆定位器 → 装作惠子的哥哥 → 在杰科家住一晚 → 第二天帮她出城
- 警告惠子:**"但不管怎么样都别提承太郎 / 不然他该不干了"**——
  说明义体大夫朋友也知道承太郎、害怕承太郎,
  这就是为什么承太郎只需要"给他钱"就能反向收买
- 结局:丈已经找到义体大夫,承太郎下令"把他们逮起来"——
  逃亡的成功率极低

#### [[对话记录 特蕾西·欧文斯和阿娜·欧文斯]]:派对绑架受害者

参见 [[对话记录 特蕾西·欧文斯和阿娜·欧文斯]]——

少女特蕾西·欧文斯被绑架:

- 起点:在朋友**瑞秋家开派对**
- 之后**记忆中断**(典型药物 / 神经芯片下毒手法)
- 醒来发现**"我想我在一艘船上"**
- "船"指向**集装箱货运 / 海港**——
  与 [[对话记录 彼得和承太郎]] 的集装箱进货渠道**逻辑上吻合**
- 母亲阿娜已报警,但能否找回视 NCPD 反应速度
- 这是 XBD 产业链**入货端的受害者视角**——
  特蕾西可能正在被运往承太郎或同类黑超梦买家

#### [[对话记录 正法承太郎和伊莱扎·弗洛瑞斯]]:冷库尸体

- "我这儿有几具尸体要处理 / 在冷库里"

  伊莱扎·弗洛瑞斯(火葬场内部人)夹带焚尸

  说明这种处置是**日常化、批量化**的,

## 世界观意义

正法承太郎是 [[公司统治]] 时代**XBD 产业链具象化**的极端样本:

- 把"娱乐 / 表演 / 体验商品化"这条公司逻辑**推到道德归零的尽头**——
  当一切体验都能被超梦录下来卖钱,"虐杀"自然也成了商品
- 公司不直接参与,但**提供整条技术基础设施**——
  超梦头环、神经轨编辑器、加密配送渠道
- 帮派接管"取材 + 制作 + 分销"——
  [[虎爪帮]] 的日式美学包装让产品看起来"高端"
- 受害者是**身份系统中最容易被抹掉的人**——
  流浪者、性工作者、底层移民
- 名字梗"承太郎"——
  作者用流行文化中的正义代名词反向命名最大恶人,
  正是 [[公司统治]] 时代的隐喻:
  **没有"正义的承太郎",只有反过来被武士道美学包装的虐杀者**
