# 兰乔科罗纳多

> 别名:Rancho Coronado / 科罗纳多农场

## 类型

[[圣多明戈]] 子区域 / **工人居住区** /
**"睡城(Bedroom City)"** /
"美国梦残骸"的样本地段

## 特征

兰乔科罗纳多是 [[阿罗约]] 工人的**下班后居住地**:
- 工厂工人
- 蓝领家庭
- 中低收入居民

与 [[阿罗约]] 是同区两面:
- **阿罗约 = 工业地狱**(上班的地方)
- **兰乔科罗纳多 = 工人睡觉的地方**

这里是夜之城**唯一像"未来郊区"的地段**——
完全不像市中心的赛博朋克美学。

## 视觉风格:伪装的"美国梦"

你会看到:
- **独栋房屋**
- **小草坪**
- **街边树木**
- **家庭社区**

但同时:
- **天空灰蒙蒙**(阿罗约的污染飘过来)
- **工厂永远在远处轰鸣**(24 小时不停的机械声)
- **房屋很旧**(没人投资升级)
- **绿化稀薄**(草坪是塑料的或半枯萎)

## 表面"美国梦"的真相

兰乔科罗纳多表面看**很像"美国梦"**——
白色围栏 / 郊区住宅 / 家庭社区。

但实际上:
- 这里的人**永远在加班**
- 被企业**榨干**
- **没真正未来**

"独栋住宅 + 后院 + 安静邻居"——
2077 年这些不是"成功的标志",
而是**"廉价诱饵"**:让工人愿意接受微薄工资换一份"看起来体面"的生活。

## 居民构成

- **第一代蓝领**:从外地迁来阿罗约工厂工作
- **多孩家庭**:夜之城人口结构的下沉地段
- **退休工人**:工作 40 年后留在原区,无力搬走
- **失业的年轻人**:父母在工厂上班,孩子在家打游戏

## 世界观意义

兰乔科罗纳多是 [[公司统治]] 时代**"美国梦被改造成廉价诱饵"**的样本:

### 与 [[宪章山]] 的镜像

| | [[宪章山]] | 兰乔科罗纳多 |
|---|---|---|
| 阶级 | 企业中产 / 白领 | 工人 / 蓝领 |
| 工作地点 | [[市政中心]] | [[阿罗约]] |
| 住房 | 高级公寓 / 安保社区 | 独栋郊区房 / 无安保 |
| 风险 | 失业 / 玻璃天花板 | 工伤 / 被替代 |
| 美学 | 成功精英 | 美国梦残骸 |

**二者都是公司奴隶,只是工资数额不同**。

### "美国梦"作为压制工具

兰乔科罗纳多的"郊区美学"不是给工人的奖励——
它是**让工人甘愿继续工作的视觉麻醉**:
- 你有自己的房子(虽然在还贷)
- 你有后院(虽然空气有毒)
- 你有家庭社区(虽然每个人都在加班)
- "**这就是你工作的意义**"——公司用这套话术说服工人不要罢工

### 与 [[海伍德]] 的对比

- [[海伍德]]:**真正的社区**——拉美家族文化 / 邻里关系 / 信仰
- 兰乔科罗纳多:**伪装的社区**——独栋房 + 草坪但邻居互不认识
- 二者揭示 [[公司统治]] 时代"家庭"的两种形态:
  - 海伍德:**自发组织的家庭**(被资本忽视)
  - 兰乔科罗纳多:**资本设计的"家庭"**(廉价诱饵)

### 与《[[边缘行者]]》David 家的对应

David 的成长环境就是兰乔科罗纳多式的:
- 工薪阶层
- 企业教育压力
- 底层家庭
- 母亲拼命供他上 Arasaka 学院

兰乔科罗纳多是夜之城**最像"现实"的地段**——
也是最让玩家觉得**绝望**的地段:
比起 [[太平洲]] 的"明显废墟",兰乔科罗纳多的"正常生活"更恐怖,
因为它说明:**未来世界里,大多数人的命运不是被毁灭,而是被驯化**。

### "睡城"的命名残忍

"Bedroom City" 这个名字本身就是侮辱——
- 这里不是"生活的地方",只是"睡觉的地方"
- 居民的真实存在只在 [[阿罗约]] 工厂里——
  那才是他们的"主要场所"
- 兰乔科罗纳多只是**让工人有地方躺平、恢复体力,
  以便明天继续上班**的功能性建筑群
