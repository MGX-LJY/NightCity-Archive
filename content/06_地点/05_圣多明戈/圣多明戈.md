# 圣多明戈

> 别名:Santo Domingo / 圣多明各

## 类型

[[夜之城]] 六大区之一 / **工业心脏(Industrial Heart)** /
**夜之城真正的"动力核心"** /
"被工业资本榨干的劳动阶层"聚居地

## 核心定位:被低估的"动力核心"

很多玩家第一次来这里会觉得:
- 没 [[西谷区]] 华丽
- 没 [[沃森]] 赛博朋克味浓
- 没 [[太平洲]] 那么震撼

但实际上:**圣多明戈才是 Night City 的真正"动力核心"**。

因为发电站 / 工厂 / 重工业 / 能源系统 / 制造业全部集中在这里。

### 公司的"工业实验场"

官方定位:**"公司把这里当成工业实验场"**——
- 今天拆工厂
- 明天建新工业园
- 后天再废弃
- **居民永远只能适应资本变化**

## 整体特征

关键词:**工业化 / 工人阶级 / 发电厂 / 企业实验区 /
军事化街区 / 灰尘 / 热浪 / 电力污染 / 底层劳动者**

### 与其他区的根本不同

Night City 其他地方大多卖:
- 欲望(西谷)
- 娱乐(日本街)
- 梦想(沃森的传奇)
- 消费主义

**圣多明戈卖的是"劳动"**——
这里的人不做梦、不追传奇,只是**拼命活下去**。

## 历史:从难民营到工业牢笼

[[圣多明戈]] 是 Night City 最古老的区域之一。

### 第四次公司战争后

2023 [[荒坂塔袭击事件]] 核爆后:
- 大量难民逃到这里
- 建临时营地、搭建贫民聚落
- 因为这里**远离市中心 / 远离企业战争核心区**

### 企业重新进入

后来企业回来了——因为**圣多明戈地便宜**。

- 建工厂、建发电站、建制造基地
- 结果整个区域**彻底工业化**
- 原本的难民被"重新雇佣"成新工人——
  从无家可归者变成有工资的"自由人"——
  但本质都是被资本困住

| 子区 | 本质 | 主题 |
|---|---|---|

### [[阿罗约]](Arroyo)

- 工厂区 / 发电厂 / 制造基地 / 废料处理区
- 官方直接称"**工业心脏**"
- 新旧工业混在一起——废弃烟囱旁就是高科技自动化生产线
- 高温 / 高污染 / 巨大噪音
- 主题:**人像机器零件**

### [[兰乔科罗纳多]](Rancho Coronado)

- 工人居住区 / "**睡城(Bedroom City)**"
- 独栋房屋 / 小草坪 / 街边树木 / 家庭社区——
  表面看像**"美国梦"**
- 但天空灰蒙蒙 / 工厂永远在远处轰鸣
- 主题:**被加班榨干的郊区幻觉**

## 控制帮派:[[六街帮]]

### 起源:不是黑帮,是退伍军人民兵

六街帮**原本不是黑帮**——
他们是**第四次公司战争退伍军人组成的社区民兵**。

成立原因:
- 战争后 [[NCPD]] 崩溃
- 城市混乱
- 社区无人保护
- 于是老兵们决定**自己巡逻 / 自己执法 / 自己维持秩序**

### 黑化:武装组织的必然命运

后来他们逐渐:
- 收保护费
- 控制地盘
- 进行军阀化

**武装组织一旦拥有权力,最终都会黑帮化**——这是 Cyberpunk 的经典命题。

### 视觉风格

与其他帮派完全不同——**军事化民兵**:
- 军用装备
- 突击步枪
- 爱国主义
- 美国旗元素
- 战术装备

## 世界观意义

圣多明戈是 [[公司统治]] 时代**"未来资本主义下的劳动阶层"**的样本:

### 与 [[市政中心]] 的产业链关系

二者是**夜之城产业链的两端**:
- 市政中心的玻璃幕墙总部**需要圣多明戈的电厂供电与工人保养**
- 电厂养活总部,**总部从不回望电厂**
- 这是 [[公司统治]] 时代最完美的"看不见的人"链条

### "民间秩序最终都会黑帮化"

[[六街帮]] 从"爱国民兵"演化为黑帮——
揭示 [[公司统治]] 时代**所有"民间秩序"最终都会黑帮化**:
- 当公司不提供秩序
- 政府不存在
- 唯一可能填补的就是**武装组织**
- 而武装组织一旦掌握权力,就会异化

### "正义涂鸦在电厂油罐"的反讽

"正义"塔罗牌涂鸦出现在电厂油罐外墙——
**正义在这个城市只能写在工业废墟的墙上,而不能写在法律里**。

### "美国梦"在 [[兰乔科罗纳多]] 的残骸

独栋住宅 + 后院的旧时代生活模板,
在 2077 年成为低收入廉价住房标签——
不是"美国梦实现了",而是**"美国梦被改造成廉价诱饵"**。

### 为什么这里没有"传奇感"

很少传奇雇佣兵来自圣多明戈——因为这里的人**没空做梦**:
- [[沃森]] 的人会幻想成为传奇雇佣兵
- [[西谷区]] 的人幻想享乐
- [[太平洲]] 的人幻想反抗
- **圣多明戈的人只想发工资**

这是整个区域最压抑的地方。

### 圣多明戈最恐怖的地方:"正常得可怕"

它不像 [[太平洲]] 那样**明显崩坏**,
也不像 [[沃森]] 那样**明显混乱**,
它反而**"正常得可怕"**——

因为这里的人已经接受**被压榨 / 被替代 / 被企业控制**是理所当然的。

### 与《边缘行者》的关系

《赛博朋克:边缘行者》中 David 的成长环境——
工薪阶层 / 企业教育压力 / 底层家庭——
都非常符合圣多明戈的主题。

### 本质命题

> **即使未来 AI 发达、自动化普及、科技爆炸——
> 底层劳动者依然存在、依然贫穷、依然被榨干。**
