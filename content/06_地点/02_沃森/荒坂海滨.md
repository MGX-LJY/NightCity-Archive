# 荒坂海滨

> 别名:Arasaka Waterfront

## 类型

[[沃森]] 子区域 / **沃森崩塌的真正核心** /
夜之城地下经济的物理出入口

## 特征

### 战略位置

- 沃森东缘的港口与海岸地段
- 海运 / 军火 / 企业物流 / 国际贸易枢纽
- 货运码头 + 集装箱堆场 + 仓储建筑群
- 视觉风格:工业冷峻 / 起重机森林 / 海雾 / 集装箱

### 港口控制权 = 城市控制权

夜之城所有地下经济的物理出入口——
谁拿下这里,谁就掌握整个沃森。

## 历史:沃森崩塌的源头

[[荒坂]] 回归夜之城后**真正想要的就是这里**:

- 通过**金融打压**——挤压本地中小航运企业的信贷
- 通过**地产吞并**——低价收购沃森港区物业
- 通过**企业战争**——直接打击竞争对手的物流网络

**最终结果**:荒坂摧毁了沃森原本的经济基础,
让整个沃森从"日本财团投资的新区"沦为"被资本抛弃的贫民工业区"。

这是夜之城叙事中**"资本如何主动摧毁一个区域"**的最完整样本。

## 核心地点 / 业务

### 货运码头

- 名义上的合法物流枢纽
- 实际是 [[荒坂]] 进出夜之城的国际通道
- 同时也是夜之城各种非法货物的隐蔽出入口

### 闪闪原料走私链

参见 [[对话记录 羽田凉芽中尉和浅井和晴]] / [[闪闪]]:

- [[军用科技]] 的**羽田凉芽中尉**与 [[虎爪帮]] **浅井和晴**合作
- 军方提供货箱情报,虎爪帮"闯码头偷货"做表面遮掩
- 军方警卫"打过招呼,他们会当没看见"
- 港务局安保被嘲讽为"几个混饭吃的烂酒鬼"

揭示:[[荒坂]]、[[军用科技]]、[[虎爪帮]] 三方在此区
**共享一套不公开的物流默契**。

### 仓储区

- 闪闪原料、武器、走私货物的中转点
- 部分仓库由 [[清道夫]] 临时占据用作人口仓储

## 控制势力

- **[[荒坂]]**——真正的产权与决策方
- **[[军用科技]]**——表面军方监管,实际参与走私
- **[[虎爪帮]]**——零售执行端 / 偷货劳务
- **港务局安保**——被三方共同绕过的形式主义机构

## 关联

- [[沃森]]——所属区
- [[荒坂]]——区域真正主人
- [[军用科技]] / [[虎爪帮]]——共享物流默契
- [[闪闪]]——走私原料终端产品
- [[小唐人街]] / [[歌舞伎区]] / [[北区]]——沃森其他子区

## 世界观意义

荒坂海滨是 [[公司统治]] 时代**"港口政治"**的样本:

- **物流即权力**:
  夜之城的"地下经济"看似分散,实际通过此区**统一接入全球供应链**
  ——谁控制码头,谁就控制城市的"血管"
- **沃森崩塌的真正机制**:
  这里不是被遗弃,而是**被精心摧毁**——
  [[荒坂]] 不需要沃森繁荣,需要的是**沃森听话**
  让一个区"差点成功"再让它崩溃,
  是 [[公司统治]] 最彻底的统治方式
- **军方 + 公司 + 黑帮的共生默契**:
  - [[军用科技]] 提供货源情报
  - [[虎爪帮]] 提供执行人手
  - [[荒坂]] 提供港口默许
  - **港务局**承担"被绕过"的形式角色
  这是夜之城的标准合谋模式:**所有合法机构都是被穿透的形式**
- **与 [[太平洲]] 形成对照**:
  - 太平洲:被资本抛弃后变成废墟 + 巫毒帮宗教据点
  - 荒坂海滨:被资本占领后变成走私 + 共谋枢纽
  - 同样的"资本干预",留下完全不同的结局
- **港口的隐蔽性**:
  夜之城游客只看见霓虹与公司广场,
  没人去码头——但**全城每一笔毒品、武器、人口交易,都在这里上岸**
