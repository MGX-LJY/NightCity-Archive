# 沃森

> 别名:Watson / 沃森区

## 类型

[[夜之城]] 六大区之一 / **最经典的赛博朋克区** /
"**夜之城底层世界的入口**" / "高科技低生活"的样本

## 历史定位:从企业新区到资本废墟

沃森的核心叙事是"**差点成功**":

- **早期**:日本财团投资的企业新区 / 现代化都市计划 / 高级商业区
- **中期**:[[荒坂]] 回归夜之城,争夺港口控制权,
  通过金融打压 + 地产吞并 + 企业战争摧毁本地经济
- **现在**:被资本抛弃的贫民工业区

**沃森崩塌的真正原因**:不是无能,而是 [[荒坂]] 主动选择把它打碎。
这是夜之城叙事中**"资本能让一个区域崛起,也能让它消失"**的最完整样本。

## 整体特征

关键词:**亚洲移民 / 霓虹贫民窟 / 黑市义体 / 工业废墟 /
高科技低生活 / 帮派战争**

视觉风格:**香港九龙城寨 + 东京歌舞伎町 + 重庆魔幻楼**的混合体——
人很穷,但身上的义体可能比现实世界富豪还先进。

## 四大子区

沃森内部划分为四个具有强烈差异的子区,各代表一种"末日形态":

### [[小唐人街]](Little China)

- **沃森核心生活区** / [[V]] 主线起点
- Megabuilding H10 / [[米丝蒂]] 的店 / 维克托诊所 / [[来生]] 酒吧
- 主题:**"高科技贫民窟"** —— "High Tech, Low Life" 的最经典体现
- 控制:[[虎爪帮]] 部分街区 / [[清道夫]]

### [[歌舞伎区]](Kabuki)

- **夜之城最大黑市之一**
- Kabuki Market / 黑市义体医生街 / [[清道夫]] 活动区 / [[闪闪]] 生产据点
- 主题:**"人体商品化"** —— 买卖人体本身
- 控制:[[虎爪帮]] / [[清道夫]]

### [[北区]](Northside)

- **夜之城工业废墟** / [[漩涡帮]] 大本营
- Totentanz 夜店 / 废弃工厂群 / 荒坂废弃设施
- 主题:**"工业文明尸体"** —— 资本退场后的疯狂遗迹
- 控制:[[漩涡帮]]

### [[荒坂海滨]](Arasaka Waterfront)

- **沃森崩塌的真正核心** / 港口控制权 = 城市控制权
- 货运码头 / [[闪闪]] 原料走私链 / 仓储区
- 主题:**"港口政治"** —— 物流即权力
- 控制:[[荒坂]] / [[军用科技]] / [[虎爪帮]] 三方共谋

## 世界观意义

沃森是 [[公司统治]] 时代**"资本失败后的未来都市"**最完整的样本:

- **"差点成功"的反乌托邦**:
  沃森的悲剧不是"从未有过希望",而是**有过希望但被资本主动摧毁**——
  这比"一直贫穷"更绝望
- **"高科技低生活"的最经典体现**:
  即使未来拥有 AI、超级义体、智能城市——
  底层人的生活依然贫穷、痛苦、甚至更容易被剥削
- **同一区内的四种"末日"并存**:
  - [[小唐人街]](贫民窟)
  - [[歌舞伎区]](人体商品化)
  - [[北区]](工业邪教)
  - [[荒坂海滨]](资本侵占)
  四种不同的失败方式被压缩进同一个区,
  揭示 [[公司统治]] 的"末日"不是统一的,而是**多种形态并存**
- **与 [[市政中心]] 形成残酷对照**:同一城市,
  顶端在 AV 飞车上谈生意,底端在歌舞伎区拆器官
- **沃森是"夜之城底层世界的入口"**:
  几乎所有 [[V]] 的主线起点都在这里——
  这是叙事设计,让玩家从最赛博朋克的地方进入这座城市,
  以此确定整部游戏的情感基调
