# 北区

> 别名:Northside / 北区工业区

## 类型

[[沃森]] 子区域 / **夜之城工业废墟** /
[[漩涡帮]] 大本营

## 特征

### 工业末日废土

- 沃森的**原工业核心**——
  曾经的工厂、车间、码头延伸地段
- 工厂倒闭、企业跑路、工人失业后**彻底废弃**
- 整个区域:烟囱 / 铁锈 / 废工厂 / 化工污染
- 朋克废土 + 工业邪教美学

### 视觉风格

- 重金属铁皮 / 暴露管线 / 喷漆涂鸦 / 路障篝火
- 与 [[小唐人街]] 的霓虹密集形成对照——
  小唐人街是"过度装饰的贫穷",北区是"裸露的废墟"

## 控制帮派:[[漩涡帮]]

北区是 [[漩涡帮]] 的**核心大本营**。

漩涡帮与 [[虎爪帮]] 的根本差异:

| [[虎爪帮]] | [[漩涡帮]] |
|---|---|
| 企业化黑帮 | 赛博疯子 |
| 日式极道 | 工业邪教 |
| 生意优先 | 暴力优先 |
| 守规矩 | 无规矩 |
| 高层谈生意,底层施暴 | 全员都嗑义体上头 |

漩涡帮信奉**机械崇拜**——
把人体改造到极限,把痛觉关闭,把"作为人"剩下的部分都改掉。

## 核心地点

### Totentanz(死亡之舞)

- **漩涡帮核心夜店**
- 几乎就是 [[赛博精神病]] 聚集地
- 特点:
  - **重金属**——音乐与材质都是
  - **义体改造**——客人比成员还猛
  - **极端暴力**——打架是娱乐方式
  - **机械崇拜**——把"成为机器"作为审美与信仰
- 是夜之城**最不像"人类社交场所"**的夜店——
  在这里,"人"已经被解构

### 废弃工厂群

- [[V]] 与 [[杰克·威尔斯]] 早期任务地段:
  - **全力一搏**——与漩涡帮谈判,取回机器人 Flathead
  - 这是 [[V]] 主线第一次接触帮派
- 大量空仓库、废弃生产线、辐射区
- [[清道夫]] 也在此与漩涡帮共存(各取所需)

### Arasaka 废弃设施

- [[荒坂]] 战前在此布置的工业设施
- 现在多被漩涡帮或清道夫占据
- 部分仍可能藏有荒坂的旧实验数据

## 世界观意义

北区是 [[公司统治]] 时代**"工业文明尸体"**的样本:

- **当资本不再需要工人后,工业区会变成什么?**
  答案就是:**贫穷 + 暴力 + 毒品 + 朋克化疯狂**
- **漩涡帮的存在揭示一种特殊反抗路径**:
  - 既然身体早晚要被资本商品化,那就**主动把自己改造成机器**
  - 既然人性早晚要被消解,那就**主动消解自己的人性**
  - 这不是反抗,而是**"以更彻底的自我毁灭来表达拒绝"**
- **Totentanz 是夜之城的"反美学神殿"**:
  - [[虎爪帮]] 的 [[云顶妓院]] 卖"完美人格"
  - 漩涡帮的 Totentanz 卖"毁掉人格"
  - 两者是同一城市的两极——
    都在用极端方式回应**"人格已不值钱"**的事实
- **作为玩家的早期"反向锚点"**:
  [[V]] 在游戏前期就被丢进北区与漩涡帮接触——
  让玩家立即明白:
  这座城市里**有人选择把自己改造成怪物**,
  而这不是 bug,是 feature
- **工业的死亡 ≠ 工业的消失**:
  工厂倒了,但工厂的"美学"和"权力结构"依然在——
  漩涡帮继承了工业秩序的**残忍与机械感**,
  只是不再为公司生产任何产品
