# 小唐人街

> 别名:Little China

## 类型

[[沃森]] 子区域 / **沃森核心生活区** / [[V]] 主线起点 /
**"夜之城底层世界的入口"**

## 特征

- 超高人口密度的巨型公寓 + 高层贫民楼 + 小摊贩 + 霓虹广告
- 视觉风格:香港九龙城寨 + 东京歌舞伎町 + 重庆魔幻楼的混合体
- **Megabuilding(巨型建筑)**——"垂直贫民窟"系统:
  内部含住房、商店、黑市、医生、帮派、小吃摊——
  本身就是一个**小城市**
- 既是沃森最有"生活气"的地段,也是夜之城最压抑的居住样本

## 核心地点

### V 公寓(Megabuilding H10)

- 整个游戏最重要的"家"
- 小、乱、压抑——但有强烈的生活感
- 属于典型的"垂直贫民窟"住宅单元
- [[V]] 的主线 / 支线 / 同伴互动的核心枢纽

### Misty Esoterica(米丝蒂的店)

- [[米丝蒂]] 经营的神秘学店铺
- 位于维克托诊所**楼上**
- 夜之城少有的"**精神世界**" / 占卜 / 塔罗 / 神秘学聚集点
- 与楼下纯肉体改造的诊所形成**身心二元对照**

### 维克托诊所(Viktor Vector)

- 夜之城最有人情味的义体医生之一
- 代表**"老夜之城时代的街头道义"**——
  既不属于公司,也不属于帮派,在两端缝隙中提供低价改造
- [[V]] 的 [[Relic]] 植入手术即在此完成
- 与 Misty 楼上楼下的组合:**身体修复 + 灵魂安慰**的二人组

### [[来生]] 酒吧(Afterlife)

- 传奇雇佣兵酒吧
- **不属于公司、不属于政府、属于传奇**
- [[罗格]] 经营,雇佣兵接活的"中央集市"
- 详见 [[来生]] 独立节点

## 世界观意义

小唐人街是 [[公司统治]] 时代**"高科技贫民窟"**的最经典样本:

- **"High Tech, Low Life"** 的完美体现:
  人很穷,但身上的义体可能比现实世界富豪还先进
- **Megabuilding 是城市的城市**:
  公司不再需要管理底层人,所以把他们压缩进巨型建筑里——
  让他们在内部完成"住、消费、医疗、犯罪、死亡"的全循环,
  外部世界几乎不需要再为他们提供服务
- **Misty + Viktor 是夜之城的"人情味飞地"**:
  在公司化、帮派化、商品化的城市里,
  仍然保留**不收高价、愿意听你说话**的两个人——
  小唐人街因此成为夜之城叙事中
  少有的"还有人愿意把你当人"的地段
- **作为玩家的情感锚点**:
  几乎所有 [[V]] 的主线起点都在这里,
  这是叙事设计——
  让玩家从最赛博朋克的地方进入这座城市,
  以此确定整部游戏的情感基调
