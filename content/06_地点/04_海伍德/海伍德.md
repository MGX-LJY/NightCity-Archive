# 海伍德

> 别名:Heywood / 河谷区

## 类型

[[夜之城]] 六大区之一 / **最"有人情味"的区域** /
**"Night City 最大的卧室"(The Biggest Bedroom)** /
拉美裔人口集中地段

## 核心定位

如果说:
- [[沃森]] = 科技贫民窟
- [[西谷区]] = 欲望消费天堂
- [[太平洲]] = 废墟
- [[市政中心]] = 企业帝国
- **海伍德 = "真正的街区"——未来世界里的传统社区**

夜之城**大量普通人都住在这里**——
他们在这里**结婚、生子、成长**——
海伍德是夜之城最像"有真正生活"的地方。

## 整体特征

关键词:**拉美文化 / 社区感 / 家族 / 宗教 / 街头传统 / 低收入社区 / 帮派秩序**

### 为什么这里特别

很多区域已经被:
- 企业化
- 商品化
- 冷漠化

但海伍德依然存在:
- **邻里关系**
- **家族文化**
- **街头认同**
- **宗教信仰**

它不像 [[西谷区]] 那么梦幻、[[沃森]] 那么混乱、[[太平洲]] 那么绝望——
它**更接地气**。

## 三大子区

| 子区 | 本质 | 主题 |
|---|---|---|
| **[[谷地区]]**(The Glen) | 核心区 / 市长办公室所在 | 街头人向上爬后的生活 |
| **[[泉源区]]**(Wellsprings) | 商业 + 居民混合区 | 普通人最密集的居住地 |
| **[[帝景区]]**(Vista del Rey) | 街头冲突核心地带 | 瓦伦蒂诺 vs 六街帮意识形态战 |

### [[谷地区]](The Glen)

- 海伍德最"成功"的地方:高级公寓 / 酒吧 / 夜店 / 商业区
- 夜之城**市长办公室**所在地——政治权力的物理坐标
- **El Coyote Cojo(野狼酒吧)**:杰克母亲所开,游戏里最有"家"感的地方
- 主题:**"街头人向上爬后的生活"**

### [[泉源区]](Wellsprings)

- 海伍德最典型居民区——商店、小餐馆、修车店、公寓密集
- "**普通人特别多**"——不像市政中心全是 corpo、太平洲全是废墟、西谷区全是消费场所
- 主题:**真正像有人长期生活的地方**

### [[帝景区]](Vista del Rey)

- 海伍德最危险区域
- **[[瓦伦蒂诺帮]] vs [[六街帮]] 冲突核心地带**
- 拉美家庭式聚居样本
- 同时也是 [[科罗纳多]] 海抛尸地的临界——
  揭示海伍德的"人情味"外壳下也有城市级暴力
- 主题:**"社区街头文化" vs "军事化保守主义"** 的意识形态战

## 控制帮派:[[瓦伦蒂诺帮]]

**夜之城最有"家族感"的帮派**——也是 [[海伍德]] 的灵魂所在。

### 为什么瓦伦蒂诺很特殊

他们不是**外来殖民帮派 / 企业代理人**,
而是**"从社区长出来的帮派"**:
- 保护街区
- 维护社区
- 帮邻居办事
- 很多居民甚至**支持他们**

### 三大文化特征

- **极强社区绑定**——把自己当"家人",叛徒会被极度残忍处决
- **拉美 / 奇卡诺(Chicano) / 墨西哥文化核心**
- **标志元素**:金色十字架 / 圣母纹身 / 圣死神(Santa Muerte)/
  低底盘车(Lowrider)/ 金色枪械 / 彩色衬衫 / 宗教元素

详见 [[瓦伦蒂诺帮]] 节点。

## 核心人物

### [[杰克·威尔斯]] —— "海伍德的化身"

- 热情 / 讲义气 / 爱家人 / 爱朋友 / 有街头荣誉感——
  全是海伍德的核心精神
- 曾经是 [[瓦伦蒂诺帮]] 成员,后来退出
- 解释了他为何熟悉街头规则、和很多帮派有联系、但又不完全属于帮派
- 母亲在 [[谷地区]] 经营 El Coyote Cojo 野狼酒吧

### [[塞巴斯蒂安·神父·伊瓦拉]](Padre)—— "旧夜之城最后的道义"

- 海伍德 Fixer / 老派教父式人物
- 讲规矩 / 讲荣誉 / 讲街头秩序
- 与 [[瓦伦蒂诺帮]] 关系极深——曾经就是帮派成员
- 其影响力维系着海伍德的"秩序底线"

### [[杰佛逊·佩拉雷斯]]—— 市长候选人

- 在海伍德发起竞选活动
- 试图代表海伍德进入夜之城政治体系——
  但其竞选最终被吞噬

## 世界观意义

海伍德是 [[公司统治]] 时代**"未来世界里最后的街头人情"**的样本:

### 最深层主题:"社区"

很多区域表现的是科技 / 企业 / AI / 资本——
但海伍德在问的是:
> **当未来世界越来越冷漠,社区还能存在吗?**

### 为什么玩家最喜欢海伍德

因为这里**最像"人类社会"**:
- 会办葬礼
- 会喝酒聊天
- 会祭拜亲人
- 会讲街坊人情

不像其他区域那样完全企业化、完全商品化。

### 但海伍德依然是悲剧

它**仍然逃不过夜之城规则**:即使有家族、有社区、有信仰,
最后仍然**离不开暴力、离不开帮派、离不开犯罪**。

[[杰克·威尔斯]] 的死成为 [[V]] 主线的情感锚——
海伍德是夜之城档案中**最能唤起"失去家人"叙事**的地段。

### 与其他区的对照

- [[市政中心]]:**纯资本**
- [[西谷区]]:**纯消费**
- [[沃森]]:**纯生存**
- **海伍德:纯情感纽带**

### Cyberpunk 最残酷的一点

> **连"人情味"也需要靠黑帮维持。**

[[瓦伦蒂诺帮]] 也参与毒品、暴力、地下生意——
海伍德的家族文化是**犯罪秩序的另一种组织形式**。
[[公司统治]] 不直接覆盖海伍德,而是把秩序外包给本地黑帮——
社区温度的代价是地下经济。

### "市长办公室在 The Glen" 的讽刺

夜之城名义上的最高政治权力被安置在**最不像政治中心的地方**——
说明真正决策权早已不在市长手中。
