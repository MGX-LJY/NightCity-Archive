# 西谷区

> 别名:Westbrook

## 类型

[[夜之城]] 六大区之一 / **夜之城的"欲望区"** /
**"夜之城最想让外人看到的地方"**

夜生活中心 / 富人娱乐区 / 高端犯罪区——
[[公司统治]] 时代被资本完美包装的消费窗口。

## 核心定位

如果说:
- [[沃森]] = 底层赛博朋克
- [[太平洲]] = 被遗弃的废墟
- [[圣多明戈]] = 工业贫民区
- **西谷区 = 资本、欲望、奢侈、娱乐的中心**

这里聚集了**富豪 / 企业中层 / 明星 / 超梦产业 / 高端夜生活 / 性消费 / 赌博产业**。

很多游客第一次来到 Night City——
最先幻想的,其实就是西谷区:**最繁华、最霓虹、最干净、最"高级"**。

## 历史:从核爆废墟到资本天堂

很多人不知道**西谷区曾经也是废墟**。

### 2023 [[荒坂塔袭击事件]] 后

靠近 [[市政中心]] 的西谷区:
- 高楼倒塌
- 地震破坏
- 大量区域沦陷
- 尤其 [[日本街]] 与 [[宪章山]] 一度变成
  **难民区 / 战斗区 / 贫民聚集地**

### 亚洲资本重新投资

[[荒坂]] / [[康陶]] / 日资财团重新开发——
西谷区被重新包装成**"夜之城最成功的现代化区域"**。

> **重要事实**:西谷区的繁华不是天然的——
> 它是**资本主动选择重建的结果**。
> 同一场核爆中 [[沃森]] 被打碎、[[太平洲]] 被遗弃,
> 只有西谷区被资本"挑中",这是阶级选择,不是地段优势。

## 三大子区:阶级三层结构

西谷区内部呈现夜之城**最纯粹的阶级分层**:

| 子区 | 阶级 | 主题 |
|---|---|---|
| **[[日本街]]** | 消费者 + 欲望产业 | 资本包装后的欲望 |
| **[[宪章山]]** | 企业中产 | 被资本驯化的人生 |
| **[[北橡树]]** | 企业贵族 | 财富已能买到自然 |

### [[日本街]](Japantown)

- **西谷区灵魂所在** / [[虎爪帮]] 核心地盘
- 整个游戏最有"赛博东京"味的区域
- 核心地标:[[云顶妓院]] / 樱花市场 / 河原俱乐部 / 岐路司园区
- 主题:**"资本包装后的欲望"**——每个人都在消费空虚

### [[宪章山]](Charter Hill)

- **企业中产生活区**——白领、中层主管、上升期 corpo
- "看起来成功,但压力巨大"——配保镖、坐防弹车也照样睡不好
- 虎爪帮挖角对手时安置中层的地段
  (参见 [[对话记录 塔妮娅和平八]])
- 主题:**"被资本驯化的人生"**——更高级的公司奴隶

### [[北橡树]](North Oak)

- **夜之城真正的"天堂"**——最富、最安全、最奢侈
- 超级豪宅 / 私人花园 / 人工生态系统 / 微气候控制 / 私人 AV 停机坪
- **[[克里·欧罗迪恩]]** 的豪宅 + [[荒坂]] 家族资产
- **以前曾是核爆后的贫民窟**,被"打击犯罪行动"暴力清洗后变富人区
- 主题:**"财富已能买到自然"**——绿色植物在夜之城是奢侈品

## 世界观意义

西谷区是 [[公司统治]] 时代**"资本主义消费天堂"**的样本:

- 与 [[市政中心]] 互补:
  市政中心**生产权力**,西谷区**消费权力**
- 与 [[沃森]] 形成镜像:
  沃森是义体改造底层,西谷区是义体享受顶层
- 与 [[太平洲]] / [[圣多明戈]] 形成残酷对照:
  **同一次核爆,同一个城市——
  资本挑中的地段重建为天堂,被遗弃的地段沦为废墟**

### 为什么西谷区"最赛博朋克"

它同时拥有:
- 东京式霓虹
- 企业资本
- 极端消费主义
- 黑帮经济
- AI 人格产业
- 超级贫富差距

它不是"**科技改变世界**",而是:
> **"资本把科技变成欲望机器。"**

### 西谷区问题的"隐蔽性"

它不像 [[沃森]] 那么脏、不像 [[太平洲]] 那么乱、不像 [[圣多明戈]] 那么穷。

但它的问题**更隐蔽**——
- **欲望被包装成奢侈品**
- **人格被商品化**(参见 [[云顶妓院]])
- **情感被出售**
- **自然被资本垄断**(参见 [[北橡树]])

消费场所看似自由选择,实际上每一个夜店、超梦馆、云顶妓院、
甚至北橡树的花园,都嵌套在 [[虎爪帮]] → [[荒坂]] 的产业链中。

**富人区与红灯区在同一片区域共存**——
揭示**欲望消费需要邻近"被消费者"才能成立**。
