# 日本街

> 别名:Japantown

## 类型

[[西谷区]] 子区域 / **[[虎爪帮]] 核心大本营** /
**夜之城最强烈的"赛博东京"氛围地段** /
**西谷区"欲望区"的灵魂所在**

## 整体特征

- 夜生活中心 / 高级赌场 / 超梦馆 / 高级会所 / 性产业**全沾**
- 由 [[虎爪帮]] 实际经营与抽成
- 视觉风格:**霓虹日本 + 和风街道 + 武士刀 + 暴走摩托 + 日式街机 + 主机厅**
- 红灯产业链以 [[扭扭街]] 为枢纽延伸

## 为什么叫"欲望区"

这里的一切都为消费欲望服务——你能买到:
- **性**(参见 [[性偶]] / [[云顶妓院]])
- **情感**(云顶 Doll Chip 定制人格)
- **超梦**(包括非法 XBD)
- **赌博**
- **幻觉**(参见 [[闪闪]])
- **虚拟人格**
- **高端娱乐**

## 历史:核爆后的废墟与重建

参见 [[西谷区]] 历史 — [[荒坂塔袭击事件]] 后,日本街因靠近 [[市政中心]] 而遭重创:
- 高楼倒塌、地震破坏、一度沦为难民区与战斗区
- 后由 [[荒坂]] / [[康陶]] / 日资财团**重新投资重建**
- 现在的"赛博东京"美学是**资本重建的产物**,不是文化遗产

## 核心地点

### [[云顶妓院]](Clouds)

- 顶级 Dollhouse,虎爪帮性产业商品化的极限样本
- "**人格商品化中心**":通过 Doll 芯片让 AI 读取客户欲望、自动生成"理想人格"
- 是整个 Cyberpunk 世界观**欲望商业化 + 灵魂商品化**最典型的缩影
- 详见 [[云顶妓院]] 节点

### 樱花市场(Cherry Blossom Market)

- 典型日式商业街 / 高端游客区
- **白天看似安全**——日本商铺、街头小吃、纪念品
- 但背后:黑市、超梦、虎爪交易**到处都是**
- 是西谷区"**双面性**"最直观的样本——
  上下层共存:游客买樱花特产,楼上交易闪闪

### 河原俱乐部(Ho-Oh)

- [[正法承太郎]] 的酒吧
- 虎爪帮 XBD 产业的指挥所——表面合法,内部黑超梦生产
- 详见 [[正法承太郎]]

### 赤木街

- NCPD 调度命令重点警力布防区域
- 参见 [[NCPD]] 麦克斯·史密斯巡逻记录
- "警察重点关注"≠"治安最好"——只是利益最密集

### 岐路司园区 + [[刃]] 展厅

- 顶级光学植入体与武士刀工房集中地
- 参见 [[岐路司]] / [[刃]]
- **"资格需要争取"**的购买机制 —— 顶级义体准入的现实门槛

## 控制势力

- **[[虎爪帮]]**——完整经济与治安控制权
- **[[冈田和歌子]]**——日本街 Fixer / 虎爪帮深度绑定者 / 旧时代极道型人物
- **[[正法承太郎]]**——XBD 产业实际"导演"
- **荒坂资本**——背后的真实金主

## 与虎爪帮的关系

虎爪帮在日本街是真正的统治者——经营赌场、控制超梦产业、掌握夜店、管理妓院、收保护费。

但他们和普通黑帮不同:
**虎爪更像"企业化黑帮"**——
- 与 [[荒坂]] 有深度联系
- 非常商业化
- 重视利润
- 外表精致

(完整对比见 [[虎爪帮]] vs [[漩涡帮]])

## 世界观意义

日本街是 [[公司统治]] 时代**"用日式美学包装资本剥削"**的样本:

- 表面是文化区,内核是 [[虎爪帮]] 的产业链总部
- "赛博东京"的视觉风格不是文化输出,而是**营销外壳**——
  让欲望消费看起来"有美学",从而提高议价空间
- 与 [[小唐人街]] 的"亚洲贫民窟"形成对照:
  小唐人街是**赤裸的贫穷**,日本街是**包装过的腐烂**
- 是夜之城**消费侧**的最强地段——
  顶端在此享受性偶 / XBD / 高级义体,
  代价由别处([[歌舞伎区]]、[[太平洲]]、流浪者)支付
- "白天看似华丽,本质上每个人都在消费空虚"——
  这是西谷区所有子区的共同精神底色,而日本街是它的极致样本
