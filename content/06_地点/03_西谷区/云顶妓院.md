# 云顶妓院

> 别名:云顶 / Clouds / Dollhouse(玩偶屋)

## 类型

[[夜之城]] 高端情感陪伴会所 / **Dollhouse(人格玩偶馆)** —
表面是合法高端会所,实际是 [[虎爪帮]] 控制的**性产业核心据点 + 超梦消费场所**。

夜之城"欲望工业"的标志性缩影:
- 不只卖肉体——还卖**人格、情感、灵魂体验**
- 通过神经同步与 AI,**为客户定制理想人格**

## 位置

- **[[西谷区]]**(Westbrook)
- **[[日本街]]**(Japantown)
- **H8 巨型公寓 12 层**

属 [[虎爪帮]] 核心地盘——安保、经营、管理、收益全归虎爪帮。

## 核心技术:Doll Chip(玩偶芯片)

云顶最恐怖的环节,也是它区别于普通妓院的核心:

### 服务流程

1. 顾客进入 → 扫描大脑
2. AI 分析其欲望、空虚、孤独、恐惧
3. 匹配最合适的 Doll
4. Doll 被芯片接管,进入"理想人格模式"
5. 服务结束后,Doll 的记忆被清空

### Doll 的本质

服务期间,Doll 不再是自己——
而是 **AI + 芯片 + 客户欲望共同生成的人格容器**。

她们某种程度上已经不是"人",而是:
> **被租赁的人格容器。**

这是 [[朱迪]] 极度痛恨云顶管理层的根源。

## 提供的"商品"

不是肉体,而是情感:
- 爱 / 理解 / 安慰
- 母性 / 崇拜 / 救赎
- 击穿心理防线的"灵魂剖析"体验
  ([[V]] 与 **Skye / Angel** 的对话即典型样本——
  系统直接读取 V 的恐惧、空虚、孤独并据此生成人格)

## 管理层 / 核心人物

### Oswald "Woodman" Forrest(森林人)

- 云顶**人事主管 / "Doll 看护"**
- 披着管理外皮的人渣:压榨 Dolls、对 [[艾芙琳·帕克]] 施暴、
  与 [[虎爪帮]] 直接合作
- **整个云顶腐烂体系的人格化代表**
- 多数玩家在朱迪线第一次见面就会直接处决他

### Maiko Maeda(舞子 / 真希子)

- [[朱迪]] 前女友 / 前 Doll / 云顶**实际运营者**
- **已经企业化的理想主义反面**——
  深知"理想主义救不了云顶",因为云顶嵌套在:
  - 虎爪地盘
  - [[荒坂]] 体系
  - 夜之城资本链
- 选择**在体制内生存**,而非颠覆它
- 与朱迪的对立是"接管派 vs 解放派"的路线斗争

### [[正法承太郎]](条太郎)

- [[虎爪帮]] 高层 / 河原俱乐部老板
- 控制云顶上游的 XBD 产业链——
  被 V 解决后,**云顶虎爪帮群龙无首**,降低朱迪后续夺权难度

### Hiromi Sato

- 云顶管理层之一
- 体现虎爪帮对性产业的层级化管控

## 关键事件

### 艾芙琳·帕克事件

参见 [[艾芙琳·帕克]]——

- 艾芙琳曾是云顶的 Doll
- 同时也是**情报中介 / 野心玩家 / 想脱离控制的人**
- 参与 [[Relic]] 计划后被 [[巫毒帮]] + [[荒坂]] + [[虎爪帮]] 多方卷入
- 最终精神崩溃,被卖入 XBD 产业链至死

她的死成为朱迪夺权动机的根源。

### 朱迪夺权线("两个人的故事")

参见 [[朱迪]]:

- 朱迪联合 [[V]] 与 [[莫克斯帮]],试图把云顶从虎爪帮手中夺出
- **理想方案**:让 Mox 接管,Dolls 获得自由,云顶独立运营
- **现实结果**:无论如何选择都没有完美结局——
  - 舞子坚持企业化路线,与朱迪决裂
  - Mox 实力不足以稳守虎爪核心地盘
  - 虎爪帮背后的 [[荒坂]] 系统更是无法挑战

### Mox 接管失败的三大原因

1. **地盘问题**——云顶在虎爪核心区,强行接管等于宣战
2. **[[莫克斯帮]] 太弱**——本质是性工作者互助组织,
   不是军事级黑帮,无力与虎爪正面冲突
3. **背后是荒坂**——虎爪帮只是表面玩家,
   云顶真正面对的是**荒坂外围系统**

## 世界观意义

云顶是 [[公司统治]] 时代**"人格商品化"**的纯粹样本:

- **欲望工业的极限形态**:夜之城已经把肉体、情绪、人格、灵魂
  全部纳入可定价商品。"花钱买被理解"是最赛博朋克的一笔交易
- **顾客的清醒共谋**:云顶最可怕的不是它欺骗顾客——
  顾客**完全知道** Doll 的人格是 AI 生成、被芯片接管、事后会被清空,
  他们**仍然愿意付钱**——因为夜之城的人太孤独了
- **Doll 的非人化**:Doll 被芯片接管时"被关机"、
  服务后记忆被清空——这是**资本对人体最彻底的物化**:
  连"在场"的主体性都被剥夺
- **朱迪 vs 舞子的路线分歧**揭示 [[公司统治]] 下两条反抗路径:
  - 舞子(企业化):在体制内尽量减害——务实但被吞没
  - 朱迪(解放派):用接管行业作为对抗——浪漫但难以稳守
  二者都不能真正"赢"
- **典型 Cyberpunk 式叙事**:不是英雄拯救世界,
  而是**"你只能在腐烂的系统里,尽量少输一点"**
- **双重统治结构**:
  - 白天:[[荒坂]] 等公司统治夜之城
  - 夜晚:[[虎爪帮]] / 云顶统治欲望
  - 二者是同一权力体系的日夜双面
