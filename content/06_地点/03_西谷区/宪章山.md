# 宪章山

> 别名:Charter Hill

## 类型

[[西谷区]] 子区域 / **企业中产生活区** /
"被资本驯化的人生"样本地段

## 特征

这里住的**不是最顶级富豪**,而是:
- **企业白领**
- **中层主管**
- **高级打工人**
- **上升期 corpo**

宪章山是西谷区**中段阶级**的物理坐标——
比 [[日本街]] 更安静,比 [[北橡树]] 更"现实"。

## "看起来成功,但压力巨大"

这里的人:
- 有高级公寓
- 有豪车
- 有安保

但同时:
- 每天**拼命加班**
- 时时刻刻**怕失业**
- 被企业**全方位压榨**

很多富人必须:**配保镖 / 坐防弹车**——
夜之城再"高级",本质还是暴力都市。

## 与 [[市政中心]] 的关系

- 大量 [[市政中心]] 公司高管的下班居所
- "**白天在荒坂塔工作,晚上在宪章山睡觉**"——
  宪章山是 [[公司统治]] 时代**通勤型奴役**的物理证明

## 虎爪帮渗透:中层挖角的安置地

参见 [[对话记录 塔妮娅和平八]] / [[虎爪帮]]:

- [[虎爪帮]] 挖角对手帮派中层人员时
- 给的条件之一是:**"在宪章山安排地盘"**
- 钱"多到能换公寓的那种"
- 配保镖应对原帮派报复

这说明宪章山在帮派眼中是**"安全的中产掩护区"**——
帮派想让被挖角的中层有一个**看起来体面**的新身份。

## 世界观意义

宪章山是 [[公司统治]] 时代**"被资本驯化的人生"**的样本:

- **现代都市精英的"未来版本"**——
  不像 [[北橡树]] 那么遥远,它更接近读者自己可能的处境
- 这里的人已经不像 [[沃森]] 底层那样**挣扎求生**
- 但他们也**没有真正自由 / 没有真正安全**
- 他们只是**"更高级的公司奴隶"**——
  - 工资是更好的牢房
  - 保镖是更精致的监视
  - 高档公寓是更舒服的笼子
- 与 [[北橡树]] 的对照:
  - 北橡树是"**资本所有者**"
  - 宪章山是"**资本的高级仆人**"
  - 二者距离遥远,中间是几代人都难以跨越的玻璃天花板
- 与 [[海伍德]] 的对照:
  - 海伍德保留了**家族 / 社区 / 信仰**
  - 宪章山只剩下**绩效 / 加班 / 体检**
  - 物质条件天差地别,精神质量正好相反
