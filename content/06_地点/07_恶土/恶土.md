# 恶土

> 别名:Badlands

## 类型

[[夜之城]] 外围荒漠 / **无法地带** /
[[流浪者七大邦]] 主要活动区

## 特征

- 沙漠废土地貌
- 没有真正的法律 / 没有秩序 / 没有企业保护
- 反而**更像"真正的人类世界"**——
  公司、警察、广告都伸不进来
- 烈日 / 沙暴 / 废弃公路 / 货运劫案
- [[加利福尼亚墙]] 沿线
- 大量 [[新美利坚]] 的边境军事遗迹

## 核心势力

### [[流浪者七大邦]]

- **[[阿德卡多]]**——[[帕南·帕尔默]] 所属;
  与 [[V]] 主线深度绑定
- **[[蛇邦]]** / **[[乔迪斯]]** / **[[梅塔集团]]** /
  **[[瑟拉斯邦]]** / **[[民邦]]** / **[[血邦]]**
- **[[乱刀会]]**——七大邦驱逐者

流浪者价值观:重视家族、自由、生存——
与城市核心区"个人主义 + 消费主义"形成鲜明对照。

## 关键事件

- [[荒坂塔袭击事件]] 后,**原爆点清理**大量依赖 [[阿德卡多]] 流浪者
- [[V]] 在 V + [[帕南·帕尔默|帕南]] 路线中投奔阿德卡多——
  这是夜之城档案中少数"离开城市"的结局之一

## 世界观意义

恶土象征 [[公司统治]] 时代"**脱离资本系统后的荒野自由**":

- 是夜之城叙事中**唯一仍保留"前公司时代生活方式"的地段**:
  家族 / 部落 / 互助 / 真实劳动
- 与 [[市政中心]] 互为镜像:
  - 市政中心:无家族 / 高科技 / 抽象资本
  - 恶土:有家族 / 低科技 / 实物经济
- "自由"的代价是**贫困、暴力与极端生存压力**——
  CDPR 没有把恶土浪漫化:这里依然有抢劫、火并、内部背叛
- 流浪者的存在证明 [[公司统治]] 并非全覆盖——
  公司之所以"放过"恶土,不是因为人道,
  而是因为这片土地**没有资本能榨取的资源**
- [[V]] 的恶土结局("流浪者结局")是少数能**远离 [[夜之城]] 而活**的路径——
  代价是放弃所有城市资源,选择部落式生存
