# 夜之城

## 类型

巨型企业城邦 / 自由邦(Night City) /
**资本主义发展到极限后的终极都市实验场**

四条核心法则:
- 公司高于政府
- 金钱高于法律
- 技术高于人性
- 欲望高于道德

## 历史与命名

- 位于美国加利福尼亚海岸,前身为 [[科罗纳多市]]
- 由 [[理查德·奈特]] 创建为乌托邦之城,奠基者遇刺后乌托邦理想瓦解
- 城市更名为"夜之城"以纪念奈特
- 白天昏昏欲睡,夜晚疯狂活跃——一座"玩弄猎物"的城市
- 由各大公司实质统治,[[荒坂]] 是其中权势最大者之一

## 八大区域(Districts)

夜之城官方划分为七大区域,《[[往日之影]]》后新增 [[狗镇]]。

| 区域 | 本质 |
|---|---|
| [[市政中心]] | 资本心脏 / 企业统治 |
| [[沃森]] | 技术贫民窟 |
| [[西谷区]] | 欲望消费 |
| [[海伍德]] | 社区与家族 |
| [[圣多明戈]] | 工业剥削 |
| [[太平洲]] | 被资本抛弃 |
| [[恶土]] | 荒野自由 |
| [[狗镇]] | 军阀资本主义 |

### 简要导览

- **[[市政中心]]**(City Center)——资本心脏,荒坂塔与公司广场所在
- **[[沃森]]**(Watson)——最经典的赛博朋克区,含 [[小唐人街]] / [[歌舞伎区]] / 北区;
  [[漩涡帮]] + [[虎爪帮]] 主要活动区
- **[[西谷区]]**(Westbrook)——夜生活与富人区,含 [[日本街]] / 宪章山 / 北橡树;
  [[云顶妓院]] 与虎爪帮核心
- **[[海伍德]]**(Heywood)——拉美社区,[[瓦伦蒂诺帮]] 地盘,
  含 The Glen / Vista Del Rey;[[杰克·威尔斯]] 的故乡
- **[[圣多明戈]]**(Santo Domingo)——工业心脏,污染严重,
  含 Arroyo / Rancho Coronado;[[六街帮]] 据点
- **[[太平洲]]**(Pacifica)——被遗弃的烂尾度假区,[[巫毒帮]] 大本营
- **[[恶土]]**(Badlands)——城外荒漠,流浪者七大邦活动区
- **[[狗镇]]**(Dogtown)——汉森军阀飞地,《往日之影》主线舞台

## 关键事件

- [[理查德·奈特遇刺]]
- 科罗纳多市更名(详见本页"历史与命名")
- [[荒坂塔袭击事件]]——事后原爆点清理大量依赖 [[阿德卡多]] 流浪者
- **[[NCPD]] 私有化**:在一次新闻发布会后,NCPD 全面转为私有制——
  犯罪率飙升,私人安保需求增加百分之一千

## 体育历史

参见 [[夜之城橄榄球队]]:

- 21 世纪 20 年代:本土"夜之城游侠队"在动乱中解散,多年没有职业球队
- 后期:投资人为太平洲度假项目建立超级橄榄球队"夜之城夜鹰队"
  - 配 EBM 沛卓石化体育场(即今 [[狗镇]] 内市场体育场)
  - 几场比赛后即解散
- 夜之城以减税方式吸引萨克拉门托海盗队改换门庭——但海盗队仍在萨克拉门托打球
- [[杰佛逊·佩拉雷斯]] 竞选演讲承诺组建全新职业队,多数媒体视为空头支票

## 商业景观切片（传单档案）

夜之城的日常以铺天盖地的商业传单驱动。下列商家在档案中各只出现一次，
但共同构成 [[公司统治]] 时代城市生活的纵切面：

### 食、住、行

- **苏石化**（公开招聘传单）——
  自称"掌握有史以来真正的环保石油生产工艺"；
  集会以"**同志**"互称，明显沿用苏联式工人组织话术，
  与"环保石油"形成裸眼可见的矛盾（参见 [[苏石化 与我们共筑光明的未来]]）
- **CORP-BUD**（新员工入伙传单）——
  战后重建材料供应商，下辖**十二家分部**；
  广告宣传"全套体育与娱乐套餐 + **G-RAPID 排毒和放松项目**"；
  注意末尾免责条款**包括败血症、中毒性休克和"由于 G-RAPID 项目使用过度
  所产生的任何 [[赛博精神病]] 病例**"——
  即新员工等同于自愿放弃赛博精神病索赔权
  （参见 [[欢迎加入]]）
- **[[全食品]]**（合成食品广告 / 跨物种基因杂交肉）——已独立成节点
- **大帝国商场**（首日开业广告：全场七折 + 摩天轮 + 过山车 + 休息舱）——
  注意与 [[狗镇]] **大帝国俱乐部**（汉斯先生大本营）只是同名巧合，
  地理与性质完全无关；
  此商场位于夜之城常态商业区
- **霆威**（汽车广告 / 车主手册）——
  "极其可靠，十分舒适，价格也很亲民"；
  手册目录第 8 项"出现紧急情况应该如何处理"
  暗示该车型确实经常需要"出现紧急情况"
- **德拉曼：交通服务**（企业级装甲车队）——
  20+ 辆装甲车，自称"82% 的犯罪和事故都发生在大街上"；
  口号"我们拥有全部的安保需求资质！**我们不问问题！**"——
  把"不查货"写进广告语，相当于公开为商务客户提供合法运毒通道
- **沃得尔旅行社**——参见 [[水晶宫]] / [[第谷]]，主推太空与异国奢华度假
- **银色幕布**（扩充规模通知）——汽车影院 / 户外**车震场所**经营者：
  "**更多空间，更加私密，更多刺激！**"——
  说明在夜之城连"在车里独处"也是被商业化的体验
- **石脊山**（楼盘宣传）——
  毗邻夜之城的"新兴开发地"，号称
  "不用倾家荡产就能买得起 + 高速公路扩建带来的便利通勤"——
  典型郊区美国梦广告，移植到夜之城语境下显得格外脆弱

### 安保与暴力商品化

- **卡罗利全新保安机器人系列**（[[霍利斯科技]] 旗下）——
  其广告直接引用一则"动物帮的脑残认错人，把家里的园丁打了个半死……
  而且还不是头一次了"的真实场景作为购买理由；
  暗示在 [[公司统治]] 时代，**普通家庭被帮派误伤已是常态**，
  保安机器人是替代品——
  与 [[创伤小组]]、[[NCPD]] 私有化形成完整闭环：
  整条"被打 → 救命 → 拆赃 → 防身"都商品化了
  （参见 [[卡罗利全新保安机器人系列]]）

## 市政政策样本

### 鸟类灭绝法案（2063.5.4）

参见 《[[鸟类灭绝法案]]》——

- 由夜之城市议会**通过**
- 目的：面对日益频繁、愈发致命的人畜传染病爆发，
  市议会**决定彻底消灭城市 18 英里范围内的所有鸟类**
- 灭绝流程从 **2063 年 5 月 7 日**开始（一旦委托合同的招标和筛选结束）
- 这是夜之城"**公共卫生 = 招标合同**"治理模式的典型样本：
  公共危机的解决方案首先是**招标**，其次才是**对策**

### 阿尔文协议（2070）—— 太平洲独立区划

参见 《[[阿尔文协议的重新解释]]》—— 详见 [[太平洲]] 节点。

- 莱恩市长签署的**夜之城自由与自治协议**
- 同时把**太平洲划为独立区划**，从夜之城行政区切离

## 世界观意义

夜之城是 [[公司统治]] 的活体样本:一座以乌托邦为名建立、
却被资本与暴力改写成反乌托邦的城市。
名字本身即讽刺——纪念奠基者的方式,是延续他失败的事实。

**它的"真正主角"地位**:
官方明确表示《赛博朋克 2077》真正的主角不是 [[V]],而是夜之城本身——
每个区域都代表一种社会形态、一种资本结构、一种人类生存方式。
[[V]] 在游戏中只是一个穿过城市的人,**城市才是叙事核心**。

**最恐怖的不是帮派,也不是 [[荒坂]],而是这座城市会把所有人都"商品化"**:
- 肉体
- 情感
- 记忆
- 灵魂
- 身份
- 梦想

全部都能出售。
