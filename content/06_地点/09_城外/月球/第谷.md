# 第谷

> 英文原名:**Tycho**
> 别名:第谷城

## 类型

[[月球]] **核心殖民城市 / 月球第一大城** /
月球**政治 / 经济 / 旅游 / 医疗 / 工业**中心 /
夜之城上层"离开地球"梦想的目的地

## 基础信息

- **位置**:第谷陨石坑(Tycho Crater)内部
- **建立时间**:**1997 年**
- **建立者**:[[欧洲航天局]]
- **人口**:约 **4 万人**
- 是 [[月球]] 上规模最大的城市,
  也是月球商业化的**事实首都**

## 特征

- 21 世纪末月球商业化的**枢纽据点**
- 提供完整旅游基础设施:
  **葡萄园 / 餐厅 / SPA / 零重力泳池**
- 是夜之城档案中**被详细描写的月球地段**
- 详细行程可参见 [[第谷 旅游行程]]
- 《往日之影》中 [[宋昭美]] 最终前往的地方就是第谷城

## 与夜之城的关系

- **逃离样本**:夜之城上层把"去第谷度假"作为**社交身份标志**
  - 你能负担月球旅行 = 你不属于这座城市的底层
- **流浪者支线 V 路径的反面**:
  - [[V]] 流浪者结局 = 离开城市去 [[恶土]] 部落
  - 第谷 = 离开地球去月球享乐
  - 前者是逃避城市的人格,后者是消费城市的奖励

## 世界观意义

第谷是 [[公司统治]] 时代**"太空消费"**的样本:

- 月球已经从科学边疆变成**度假目的地**——
  揭示资本扩张的天然方向:**任何地方都能商品化**
- "零重力泳池 + 葡萄园"是太空殖民的反讽具象:
  - 人类登月不再是为了科学
  - 而是为了让上层享受"在月球喝酒"的炫耀价值
- 与 [[太平洲]] 的"被资本抛弃"形成镜像:
  - 太平洲:资本撤离 → 废墟
  - 第谷:资本到达 → 享乐
- 与 [[奥尼尔空间站]] 形成对照:
  - 奥尼尔:抗争的飞地
  - 第谷:消费的飞地
  - 太空的两面性=地球的两面性
