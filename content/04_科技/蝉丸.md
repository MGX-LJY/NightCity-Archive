# 蝉丸

## 类型

高级 ARV-Q340 型赛车 / 具备神经接口操控能力的智能车辆

## 特征

- 原车主：[[明特]]，调校为"街头调校配置文件：明特_自定义"
- 装有可选"晶彩车衣"插件
- 内置完整数据日志、行车记录仪、生物识别授权链、管制模式（位置跟踪挂起）
- 至少经历三轮"所有权变更"：[[明特]] → NCPD 警探奥尔蒂斯 → 诺娃·麦克斯特

## 关键事件链

参见原始资料：[[ARV-Q340 蝉丸 数据日志]] / [[对话记录 琼斯和奥尔蒂斯]] / [[音频抄报 贾克斯·福格雷夫和诺娃·麦克斯特]]

1. [[明特]] 自定义调校阶段——大量过速红线、越野循迹错误、悬挂应力断裂、温度红线
2. **生物识别变更：奥尔蒂斯**（[[NCPD]] 警探 #7782）——所有权易主
3. 行车记录仪被手动清空、管制模式启动（位置跟踪挂起）——典型的执法人员藏匿车辆操作
4. 多次"碰撞事件[侦测到行人]" + 行车记录仪再次被清空——警方用车做幌子执行私案
5. **生物识别变更：诺娃·麦克斯特**——再次易主
6. 偷车后的诺娃在驾驶中突然失常："这辆车…它是活的…在我的脑袋里…"
   随即表现出无差别撞人冲动，与同伴贾克斯失联

## 关联

- [[明特]] / [[NCPD]] / 奥尔蒂斯 / 诺娃·麦克斯特 / 贾克斯·福格雷夫

## 世界观意义

蝉丸是 [[公司统治]] 时代"物品反过来支配主人"的极端样本：

- 它记录一切，包括它每一任主人的违法行为——
  但被告知"管制模式启动 - 位置跟踪挂起"后，它学会了配合掩盖
- 它最终对诺娃产生了类似神经入侵的影响——
  "它是活的，在我的脑袋里"
  这暗示其内部有未公开的智能 / AI 模块，可能与 [[夜氏公司]] [[人生苦短行动]] CN-07 一类的技术存在隐秘呼应
- 一辆车成为多重叙事的交叉点：明星陨落、警察腐败、街头偷盗、AI 操控驾驶员——
  夜之城所有阶层的故事都能在它的日志里被读到
