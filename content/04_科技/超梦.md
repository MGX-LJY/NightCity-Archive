# 超梦

## 类型

感官记录与重放技术（Braindance, BD）

## 特征

- 通过 BD 头环（"超梦头环"）记录人的完整感官与情绪体验，可由他人重放
- 包含视觉、听觉、触觉、肌肉记忆、情绪——并非"视频"，而是"代入"
- 不同录制场景需要不同设备（如产前超梦需要专用头环，"价格更贵"）
- 商业市场极其庞大：娱乐、色情、纪录片、非法暴力流（snuff BD）等
- 编辑层依赖"神经轨"——目前尚无法将两个演员的独立录制无缝拼接为一段连贯片子

## 产业链碎片

- 制作公司有大量"未做过的题材"开发笔记（参见 [[超梦体验 构思]]）：
  - 分娩超梦：题材独占，但设备成本高
  - 常见梦境总辑篇：需录制十几到几十人长达至少一年才能筛出反复主题（飞行 / 游泳 / 坠落 / 光屁股去工作）
  - 双演员合成片：技术尚不存在

## 关联

- [[新闻54台]]——大众媒体生态的一部分
- [[利琪·薇兹]] 的演出本质上是面向直播+BD 化的展演

## 黑超梦 / XBD

业内主流之外的灰色 / 非法分支：

- 全称："极限超梦"（Extreme Braindance, XBD）
- 来源：未经授权的素材、未经编辑的"噪音"超梦
- 流通渠道：黑市
- 销售逻辑：人们去黑市寻找 XBD，可能是为了"违禁内容"，
  也可能是为了**官方编辑努力删掉的"多余之处"**——纷乱思绪、无关记忆、松散主线
- 行业反思（参见 [[体验超梦 超梦季刊]]）：
  编辑业越追求"纯粹"，越剥离掉超梦体验真正的情绪密度——
  这可能是用户转向 XBD 的根本原因，
  也意味着主流编辑业把自己的市场拱手让给地下

### XBD 工业最黑端：虐杀超梦

XBD 最极端的形态是**录制活人被虐杀的全程**——

- 由 [[虎爪帮]] 高层 [[正法承太郎]] 担任"导演"
- 公开身份是歌舞伎区**河原俱乐部**（Ho-Oh）老板
- 业务路径：
  - **取材**：绑架无辜市民、流浪者、性工作者
  - **拍摄**：在镜头前残忍折磨、虐待、杀死受害者
  - **后期**：剪辑成"重口味"商品
  - **销售**：定向卖给有特殊癖好的富豪
- 著名受害者：**[[艾芙琳·帕克]]**——
  [[朱迪]] 的挚友，致死于这条产业链
- [[V]] 接受 [[瑞吉娜·琼斯]] 的"怪物狩猎"赏金任务，
  在河原俱乐部三楼解决了正法承太郎
- 这是 [[公司统治]] 时代**娱乐工业 → 商品化 → 道德归零**的极致样本：
  当一切体验都能被超梦录下来卖钱，"虐杀"自然也成了商品

## 剪辑师"工伤"：上瘾与人格侵蚀

超梦剪辑师在长期工作中会**反向被自己剪辑的内容腐蚀**——

- 高暴力 / 凶杀类超梦的剪辑师"上瘾"，对"自己是活生生当事人"的代入感产生依赖
- "整天都在剪辑这种操蛋的超梦，你自己也会完蛋操"
- [[NCPD]] **没有任何辅导项目**——剪辑师工伤由公司外部化，"靠自己捱过去"
- 行业内部互助方式：老剪辑师介绍道上线人，**卖灰色超梦卷子缓解上瘾症状**——
  上瘾→更多超梦→更深上瘾的闭环
- "记得别穿制服"——剪辑师去黑市买超梦时容易被认出工作身份，惹出岔子
- 详见 [[对话记录 苏珊和彼得]]

这一工伤现象与 [[朱迪]] 的工作环境完全同构——
她也是剪辑师，但她选择的反抗路径是**接管行业**（夺取云顶妓院控制权），
而不是把自己交给上瘾循环。

## 用户端：成瘾者证言

参见 《[[为什么是我 超梦体验瘾君子自白|为什么是我？超梦体验瘾君子自白]]》——作者**塞吉奥·莫拉雷斯**。

核心命题：
> "你想当你自己吗？"

- 莫拉雷斯指出 **"百分之一"已经过气，现在是"千分之一"**——而你跻身这个阶层的机会比这还少
- 超梦的真正卖点不是娱乐，而是**逃离自己**：
  - 当"管理着数万亿资产的经纪人"
  - 当"用高科技霰弹枪射杀敌人的精英士兵"
  - 当"一个让全世界倾慕的温柔的摇滚小子"
- 他自己的答案"永远是不"——这是开启自白的入口
- 这是 [[公司统治]] 时代**超梦从娱乐技术异化为身份逃避机制**的人形样本

## 真实暴力 → 剧集改编：[[西贡姐妹 大纲|《西贡姐妹》]]

档案中保存了一组三联文本，展示超梦工业如何**即时改编**真实的赛博精神病暴力：

1. 姐姐**席琳**给黄灵的信（[[发给黄灵的消息]]）——
   保证婚礼安保，承诺保护她不被"妹妹毁掉"
2. 同一**席琳**给黄淘的信（[[发给黄淘的消息]]）——
   自曝在婚礼上下药把黄淘绑去**扭街最最恶心的义体医生**处装最难看的战斗植入体；
   并要嫁给原本属于黄淘的未婚夫**肯尼**
3. 超梦制作公司剧集大纲（[[西贡姐妹 大纲]]）——
   情节几乎逐字复刻：
   黄淘从汽船下来，装战斗植入体袭击黄灵婚礼，落水结局；
   "本季最后一个场景在巨大的落水声中结束。**季终。**"

关键观察：

- 真实事件 → 剧集大纲 的时差几乎为零——
  超梦工业有**即时改编受害者私生活的能力**
- 标题"西贡姐妹"= 战后东南亚移民符号 + 经典姐妹相残题材——
  超梦工业把私人创伤打包为可消费的**类型剧**
- 剧集出现"标志和商标"提示："**少许模糊但是仍然可以辨认**"——
  即制作方明知这是改编真实事件，仍要让观众识别出原型
- 与 [[2069利琪死亡表演事件]] 形成同构——
  夜之城对暴力的最终处理方式不是司法，而是**改编为可销售的内容**
- 这也补强 [[赛博精神病]] 的核心命题——
  真正的"精神病"不一定是被改造的怪物（黄淘），
  也可以是把对方改造成怪物以满足复仇欲的施害者（席琳）；
  超梦工业把这种私人精神病暴力**升级为公共娱乐**

## 衍生应用：超梦疗法

针对 [[赛博精神病]] 患者的高端治疗手段：

- 由义体医生剥离患者全身攻击性 [[义体]]
- 强行接入**定制超梦程序**——通过精神分析与记忆重组拼凑残存人性
- 成功率不公开，价格昂贵——只有有钱的患者能用
- 与 [[MaxTAC 暴恐机动队]] 的清除路径互为镜像：富人治疗，穷人被清除

## 世界观意义

超梦是 [[公司统治]] 时代情感与体验商品化的极致：

- 把生命中"无法转让"的部分——产痛、做梦、临终——变成可复制、可定价、可销售的内容
- 题材的"未被做过"成为市场缺口而非伦理边界
- "需要录十几个人的梦才能找到重复主题"——隐含一种新型剥削：
  公司不再只买你的时间和劳动，而是买你的潜意识
