# 义体

> 英文原名: **Cyberware**
> 类别: 赛博植入体 / 生物器官替换技术 / 主要制造商: [[摩尔科技]]、[[生物技术]]、[[泽塔科技]]

## 类型

赛博植入体 / 生物器官替换技术——夜之城最普及、也最具阶级性的核心科技。

## 原理与特征

义体泛指**永久植入体内、尤其与中枢神经系统对接**的赛博技术；全部为人工制品。
**生物增强属另一类，统称"生化改造"（Bioware）**——后者抗 EMP、难被扫描、引发赛博精神病的概率更低。

- 原本为医疗 / 实用目的开发，如今已成生活方式选择——**普及得如纹身、珠宝一般**，"风格就是一切"
- 虽仍昂贵，但多数中产乃至部分穷人都负担得起；工薪专业人士常有两三件
  （赛博义眼录会议、赛博听觉偷听八卦）——安装一台被视为像买笔记本 / 电视 / 车一样的大宗消费
- 在医疗紧急状态下，可由义体医生整体替换生物器官（见 [[2069利琪死亡表演事件]]）
- 顶级义体与用户身份绑定，无法被简单地"送出去"——既是技术限制，也是阶级标识
- 普及程度足以支撑 [[利琪·薇兹]] 在工厂袭击中"分发 1200 件给街上的人"

### 获取渠道与维护

- **获取渠道**（质量由低到高）：连锁店（Bodyshoppe / Fashion-Fusion / Parts'N'Programs，可即装即走）
  → 商场店（中档）→ 专科诊所（高质量）→ 医院（大手术，需恢复期）；
  而**义体医生**（ripperdoc）是地下医师，便宜但牺牲质量与安全，也负责安装非法义体
- 安装依赖**纳米技术**在模块与神经系统间建立接口，改造程度**无上限**
- **维护**：植入后需定期保养，部件随时间老化、体内化学微变会影响精度——建议**每半年体检一次**；
  2070 年代经受感染的个人链接传播的**神经病毒**也会破坏义体功能

## 已知活动 / 深度档案

### 形态分级

义体按形态可分为若干等级，越往上人性损耗越大：

- **子类**：生化改造（Bioware）、芯片（Chipware）、赛博听觉、赛博义肢、赛博武器、植入体、神经件
- **线性框架**（Linear Frame）——高科技外骨骼，不靠肉身借力即可举起小汽车、徒手掰弯钢筋；
  但无法游泳、会拖慢反应，且人性损耗是普通义肢的十倍以上，极易引发赛博精神病
- **身体装甲**（Body Plating）——把装甲板嫁接到皮肤之上，防护优于皮下装甲；可造型化（从极简到怪兽外形）
- **全身义体化**（Full Body Conversion）——除大脑外几乎替换一切：
  脊椎、大脑、肾上腺系统被移入充满营养液的支撑囊中；几乎**无法避免赛博精神病**，因此极为罕见

### 世代演进史

义体的技术史从医疗假肢一路演化为阶级符号——

- **零世代（Gen 0）**：21 世纪初的医疗假肢（牙、骨、关节）；1990 年代第一次中美洲战争伤兵潮推动发展；
  日本与德国领跑；笨重、第一只义肢手只有粗糙夹爪
- **一世代（Gen 1）**：战后小型化，为工人造强化脊椎 / 关节、为污染环境造空气滤器；
  2010 年代"工业义体革命"催生战斗义体（[[军用科技]] 强化士兵，与 [[荒坂]] 开启军备竞赛）；金属塑料质感，今多见于黑市与穷人
- **二世代（Gen 2）**：战后赛博医疗市场爆发，史称"**义体时代**"；
  抗排异疗法的副产品催生了**生化改造（Bioware）**；人造肌肉取代液压活塞；RealSkinn 成为身份象征
- **三世代（Gen 3）**：巨头 R&D 与企业"冷战"军备竞赛产物；碳纤维 / 陶瓷取代金属，
  黑色行动用隐藏式皮下装甲与可收纳武器；防弹 / 防刃 / 防火 RealSkinn；
  生化改造大兴（皮织、纳米外科、毒素结合剂、突触升级）——抗 EMP、难探测、低赛博精神病率
- **四世代（Gen 4）**：分两支——其一是企业高层的尖端隐藏式义体（神经处理器、四级赛博眼、压力分析仪 + 顶级 RealSkinn）；
  其二是**新媚俗**（Neokitsch）——刻意外露的奢侈设计义体，专供"百分之一"：
  流金白金织入 RealSkinn、轨道站培育的水晶义肢、贵过普通人一辈子工资的天然木瓦镀层——纯装饰的财富图腾

### 已知专项产品类型

- **疼痛编辑器**（[[泽塔科技]]）——抑制疼痛受体到大脑顶叶的信号传递；
  令使用者短时突破常人极限，但因察觉伤势能力被压制，2020 年起所有者死亡率达 60% 以上；
  雇佣兵是其主力客户群（参见 [[疼痛编辑器和死亡率]]）
- **岐路司**——已知义眼品牌；多例报告称换装不同型号义眼时出现永久性失明
  （参见 [[义体的使用及其副作用]]）

### 职场强制赛博化

- 21 世纪下半叶开始，许多雇主以提高绩效 / 职场效率为名，强制员工接受义体改造
- 强制范围覆盖皮肤、骨骼、肌肉、器官、眼部移植
- 极端情况：**安保部门员工被普遍要求进行全身义体化**（即"全身赛博化"）
- 参见 [[义体75年 高桥勉]]：这一现象被论述者高桥勉视为义体改写劳动法的转折点

### 公司破解器：义体的"越狱"黑产

顶级义体与用户身份绑定、无法被简单"送出去"(见上文「原理与特征」)——
这道**所有权锁**催生了一条专门的地下产业：**公司破解器**(亦称"万能钥匙")。
样本见 [[委托 莉娅·格拉登的解锁装置]]:

- **它是什么**——一套"能够给任何公司义体越狱的破解设备",
  可解除公司在配发义体上设的功能锁与身份绑定
- **谁需要它**——两类客户精准对应义体经济的两端裂缝:
  1. **想离职、却舍不得公司义体功能的公司人士**——
     公司义体本是"在职福利",离职即应失效/回收;破解器让叛逃者把身体里的公司资产据为己有
  2. **想卖二手义体捞外快的人**——绑定锁让顶级义体无法转手,破解后即可流入二手黑市
- **它有多值钱**——销赃手莉娅·格拉登"知道这东西值多少钱",
  与买家([[冈田和歌子]])反复议价良久;一台破解器足以让日本街老教母亲自下委托追回

这条产业链补全了义体"阶级标识"的另一面:
锁得越死,撬锁的黑产就越暴利;公司用绑定锁制造稀缺,黑市用破解器把稀缺变现。

### 副作用、并发症与反对意见

- 已知最严重的并发症：[[赛博精神病]]——超阈值后的精神错乱
- **人性 / 共情属性损耗**（TTRPG 设定）：
  每装一台义体都会损耗 Humanity（由 EMP 共情属性决定上限）；
  人性归零的人会把普通人类视为低等生物——这是渐进式而非突变式的边际累积
- 一般立场：公司倾向于把问题归为"个人滥用"，而非技术本身的外部性
- 处置机制：[[MaxTAC 暴恐机动队]] 负责清除爆发期患者；高端治疗手段是超梦疗法

#### 三类常见并发症

（来自《[[义体的使用及其副作用]]》临床总结）

1. **免疫反应**：身体排斥植入体——瘢痕组织持续增生，引发周遭组织疼痛炎症，并干扰设备电路
2. **心理作用**：神经植入体可对大脑造成不可预计的改变——抑郁、情感淡漠、出现幻觉、赌博等成瘾性行为激增
3. **过度依赖**：长期使用某些合成替代器官会改变大脑化学物质，使之对特定型号产生适应性——
   更换型号时可能出现永久性功能丧失（已知样本：[[岐路司]] 义眼换装失明案）

#### 主要宗教对义体的官方立场

参见 [[你的神明 你的岐路司]]——

| 宗教 | 官方立场 | 备注 |
|---|---|---|
| 天主教 | 默认接受 | 神职人员普遍可见的身体改造即立场背书 |
| 摩门教 | 严格禁止 | 仅在生命支持 / 严格医疗用途时例外 |
| 伊斯兰教 | 伊玛目反复公开反对，但**未官方禁止** | 言行不一的典型样本 |
| 犹太教 | 无规定 | 唯一例外是哈西德派，由派内**柴迪克**单独管理 |

- 标题以 [[岐路司]] 双关——"你的神明"=信仰，"你的岐路司"=赛博眼品牌；
  暗示在 [[公司统治]] 时代信仰本身已被一家义眼公司**接管比喻语义**
- 表面是"宗教与改造"的中立分析，实际是义体公司公关广告——
  其修辞效果是**安抚潜在客户的宗教焦虑**："天主教都不反对，你怕什么？"
- 唯一被详细标注的"严格"派别（摩门 / 哈西德）反而暗示：
  **真正拒绝义体的宗教在这个时代被边缘化为脚注**
- 与佛教比丘的立场（《[[佛教与义体 新观点]]》）形成对照——
  佛教比丘为求开悟而戒用义体，将赛博精神病视为身外物"污染心智"的实证；
  亚伯拉罕宗教被这份传单包装为"基本兼容"，而东方传统在文档中保持彻底拒绝

### 大众文化中的义体哲学

义体已渗透到大众小说与街头哲学：

- **匿名小说《[[义体与你 节选自匿名作者的小说]]》** 的核心宣言：
  > "你的身体只是个零件，你的存在可以不断升级，而你的现状也会不断淘汰。
  >  那么你到底是谁？你只是暂时的，可以消耗，可以替代。
  >  感受到这一点，明白这一点，然后你就能重获自由。"

  这是 [[公司统治]] 时代义体伦理被彻底内化的样本：
  把"被消耗"美化为"获得自由"，让用户主动接受身体的临时性
- **小说《[[一秒千跳]]》** 把义体推到极限：
  主角发现挚爱杰森·卡达勒斯（虚构"未来科技"CEO 的儿子）是**全仿生人**，
  并且其父能为儿子定制合成大脑——这一情节直指 [[Relic]] / [[灵魂杀手]] 同源的意识技术：
  当合成大脑也能商品化，"我爱的人是谁"这个问题就变成"它的算法版本号是多少"

## 世界观意义

义体是 [[公司统治]] 实现身体层级化的工具：

- 肉体降级为零件，公司掌握每一次"心跳重启"的权限
- 顶级义体绑定用户——既是技术限制，也是阶级标识
- 利琪试图把义体当作可分发的衣物，最终撞上"绑定"这堵墙：
  这一矛盾就是赛博朋克的核心，反抗的工具本身就是统治的产物
- **绑定锁与破解器是同一枚硬币**——公司用所有权锁把"身体里的资产"锁回公司，
  黑市用 [[委托 莉娅·格拉登的解锁装置|公司破解器]] 把它撬开变现；
  你以为装进身体的是"我的"增强，离职那天才发现连自己的眼睛和手都是租来的——
  而要真正拥有它，只能去犯法
- 与 [[赛博精神病]] 的关系也是公司话术的范本——
  病因由技术提供，治疗也只能由技术提供，"解药"与"病"由同一条产业链经营
- 与大众小说的合谋：匿名作者把"你只是暂时的"包装为解放叙事；
  公司不需要强迫，市场自己会替它布道
