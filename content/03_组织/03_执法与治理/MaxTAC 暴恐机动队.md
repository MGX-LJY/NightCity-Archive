# MaxTAC 暴恐机动队

> 英文原名: **MaxTac**（MAX-TAC，全称 Maximum Force Tactical Division，"最大武力战术部"）
> 类型: C-SWAT / 旧称: 赛博人压制单位（Cyborg Suppression Unit）、精神病小队 / 成立: 2000 年代 / 隶属: [[NCPD]]

## 类型

[[NCPD]] 战术部下辖的特种部队——一支专打赛博精神病的 **C-SWAT** 快速反应队。

## 核心业务

专门处置爆发期的 [[赛博精神病]] 患者：

- 配备针对重度 [[义体]] 化目标的重型武器（高口径穿甲弹为主，EMP 武器罕见——会同时重创队员）
- 街头出动通常意味着"现场清除"而非逮捕——被猎杀的赛博精神病患者**死亡是常态，活捉与康复极罕见**
- 在夜之城里出现 = 已有人开始无差别杀人；SWAT 搞不定时就轮到 MaxTAC
- 活捉者被送往**洛斯帕德雷斯监狱**（Los Padres）——夜之城唯一能关押赛博精神病患者的设施
- 与 NCPD 其余部门不同，MaxTAC **获准在 [[狗镇]] 行动**

## 公司历史

- **2000 年代**：赛博精神病在全美泛滥，普通执法无力应对，美国政府开始组建专门的赛博人压制单位；
  各地 SWAT 纷纷成立 C-SWAT（亦名 PSYCHE-DIV、CYB-Enforcement、MAX-TAC）。
  夜之城的单位以"赛博人压制单位"之名设在市政刑事司法大楼
- **2010**：暴走的赛博精神病患者**阿瑞斯**（Ares）在一场死伤逾三十名警员与平民的火并后被活捉，
  经漫长艰难的人格重塑后被收编进压制单位、并很快出任主管——开创了"收编赛博精神病者"的先例
- **四次公司战争后**：指挥官**马克斯·汉默曼**（Max Hammerman）凭意志维系住残余 NCPD（主要是 MAX-TAC），
  并将 MAX-TAC **带离 NCPD 独立**，铁腕管控全城疑似赛博精神病分子；2030 年压制队完全重建
- **2030 年代**：MAX-TAC 猎杀了当时 [[漩涡帮]] 的首领**赫克斯特拉**（Hextra）
- **2040 年代**：成为有大量合同（覆盖整片街区、政府乃至私人）的独立执法部门；
  汉默曼治下奉行"结束一切战斗、不论谁先动手"的中立铁律——MaxTAC 一到，放下枪、否则连你一起打
- **红色时代后**：MAX-TAC 重新并入 NCPD；2077 年仍是夜之城最危险的组织之一

## 代表人物

- **阿瑞斯**（Ares）——前赛博精神病患者 / 前士兵雇佣兵，2010 年被活捉改造后收编、并出任单位主管
- **马克斯·汉默曼**（Max Hammerman）——四次公司战争后的指挥官，铁腕、不可腐蚀，曾带 MAX-TAC 脱离 NCPD 独立
- SPAR 队长：布巴·麦卡蒂（Bubba McCarty）、加里森（Garrison）
- **[[马赛厄斯·马多克斯]]**——前 MaxTAC 成员、《[[暴恐机动队之路 马赛厄斯·马多克斯|暴恐机动队之路]]》作者（详见深度档案）
- 另有梅丽莎·罗里（Melissa Rory）等被活捉、重塑后收编的赛博精神病者

## 组织与装备

- 以 **SPAR 小队**（Special Purpose Assault Rescue，特殊用途突击救援）为单位行动，
  通常四人一组，由**突击 / 螳螂（近战）/ 重装（外骨骼）/ 网络黑客 / 狙击**等专精角色构成
- 成员全员配备军用级护甲、武器、义体与载具；许多人改造程度之深，自己也上了观察名单
  （部分甚至是全身义体）——NCPD 视这套"以毒攻毒"为有效战术
- 常用武器：军用科技 M-10AF 列克星敦、阿贾克斯、Crusher、Tsunami 阿修罗（狙击）等；
  常用义体：斯安威斯坦 Mk.3（Sandevistan）、Kerenzikov、螳螂刀、皮下装甲
- 载具：泽塔科技 Surveyor、军用科技地狱犬（MaxTac 版）、巨兽（MaxTac 特种型）等

## 已知活动 / 深度档案

### 内部讽刺：以毒攻毒

- 大量 MaxTAC 成员本身就是经过心理评估、并被体制化收编的赛博精神病患者
- 也就是说：清除赛博疯子的，常常是被驯化的赛博疯子
- 这种"以毒攻毒"的人员构成是公开秘密——
  对外它是夜之城最权威的暴力工具，对内它是公司科技副作用的回收站
- 其他 NCPD 部门对 MaxTAC 敬而远之，使其近乎"国中之国"：
  他们一到现场必有伤亡，而针对他们的内部调查则必被叫停

### 绕开 MaxTAC 的反例：公司内部处置通道

参见 [[军用科技]] / [[赛博精神病]] / [[对话记录 马丁·西普拉医生和莫厄尔中尉]] + [[命令]]——

军用科技自家员工**莫厄尔中尉**发病后**没有触发 MaxTAC**：

- 公司医生承诺把他送到偏僻地址自行隔离
- NCPD 同步签发"代码红色"突袭令 + 公司精英突袭队执行
- 全程不让 MaxTAC 上街——
  避免媒体拍到、避免赛博精神病数据进入公开统计、避免暴露军用科技员工义体过载比例

类似的"私下处理"在底层也存在——
[[赶紧派人]] 中工厂主威胁：
> "要么你赶紧派快速响应小队来解决他，要么我就报警。
>  嘿，我可不希望 NCPD 来问一些你我都不想回答的问题。"

这两个样本共同揭示 MaxTAC 的**实际边界**：

| 客户类型 | 处置主体 | MaxTAC 角色 |
|---|---|---|
| 公司员工发病 | 公司内部医生 + 突袭队 | 被绕过 |
| 工厂工人发病 | 私聘"快速响应小队" | 被威胁性绕过 |
| 街头黑市义体用户发病 | MaxTAC 街头清除 | 被使用 |
| 著名雇佣兵发病 | 暗中悬赏 / 雇佣兵互杀 | 通常不介入 |

MaxTAC 的"普世清除"形象实际上**仅适用于穷人** ——
对所有"清除发病者会损害自家利益"的实体，
夜之城都已经发展出比 MaxTAC 更便宜、更隐秘的替代方案。
这并不削弱 MaxTAC 的暴力性，而是揭示它的真正功能：
**展示性街头清场**，而不是城市赛博精神病的实际治理。

### 一线证言：马多克斯

参见 [[马赛厄斯·马多克斯]]——前 MaxTAC 成员、《[[暴恐机动队之路 马赛厄斯·马多克斯|暴恐机动队之路]]》作者。

- "**中过弹，数不清多少了**"——一线工作的常态
- 经手 **2063 年黄金泉购物中心人杀手**——案犯比一般人多更多钛合金骨架和合成皮肤
- 他全身装有**大量义体**，夜里睡不着觉的不是 PTSD，而是**"我会不会某天也变成赛博精神病"**
- 他与妻子约定：若他半夜尖叫或咆哮，妻子用上膛的手枪朝他头部射击直到子弹打空——
  **体制内人公开承认体制本身无法兜底，只能把生死交给亲密关系**

## 世界观意义

MaxTAC 是 [[公司统治]] 时代外部性回收机制的样本：

- 公司卖出 [[义体]]，制造 [[赛博精神病]]，再让公共执法机构清除症状
- 把社会成本转嫁给市政预算与个人生命，但产品销量不影响
- 成员本身被招募自"被治理的疾病人群"——
  让病人去清理同一种病的爆发者，意味着系统不需要解决病因
- 与 [[网络监察]] 共构夜之城的"系统副作用清理网"：
  一个清理失控的脑，一个清理失控的网络
