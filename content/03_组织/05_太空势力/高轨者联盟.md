# 高轨者联盟

> 英文原名: **Highrider Confederation**
> 人群称谓: **高轨者**（Highrider，地表国家对低地轨道高科技太空居民的称呼）；
> 高轨者则回称地表人为**地居者**（Groundsider）/ 独立战争: 七小时战争（2022）

## 类型

太空殖民政治联盟 / [[月球]] 真正的实际主人之一 /
脱离 [[欧洲航天局]] 控制的轨道居民集合。
"高轨者"既指这个政治体，也指其背后整个**太空居民族群与亚文化**（详见深度档案）。

## 核心业务

- **轨道治理**——为太空工人、轨道殖民者、空间站居民提供独立的政治架构
- **地月生活体系**——衣食住行、生产生活完全脱离地球-公司链条
- **对抗 [[欧洲航天局]] 控制**——将原本由欧洲航天局垄断的轨道资产转入联盟实际控制

## 代表人物

- **佐拉·普列沙科娃**（Zora Pleshakova）——已知的知名高轨者
- 联盟内部组织松散,接近"轨道居民共同治理体"形态,无强势单一领袖

## 关联科技 / 产品

- [[奥尼尔空间站]]——OD1 / OD2,联盟最重要的物理据点
- 各类轨道殖民地——联盟成员的日常居住与生产单位

## 关键事件

- **2022 七小时战争**——[[奥尼尔空间站]] 起义（O'Neill 战争的高潮），
  工人在七小时内控制 OD1 / OD2，随即宣布独立、接管奥尼尔轨道与月球城市 [[第谷]]、[[哥白尼城]]，
  联盟核心据点由此形成
- **持续脱离 [[欧洲航天局]]**——轨道居民逐步脱离欧洲航天局管辖,
  联盟实际统治力不断扩大
- **红色时代**——联盟作为非洲地居亲属的**远程保护者**，间接推动了非洲多座大城市与社会的技术跃升；
  此外对各国、公司与冲突一概保持**谨慎中立**

## 已知活动 / 深度档案

### 成员构成

- **太空工人**——奥尼尔站建造者与运营者,起义后掌握自治权
- **轨道殖民者**——长期居住在轨道空间站的居民
- **空间站居民**——分散在各级轨道飞地的人口

这是一个**没有地球公民身份的政治体**——
对联盟成员而言,地球只是"老家",真正的家园是轨道。

### 高轨者：人群与文化

"高轨者"作为族群有一整套独特的生理与文化特征——

- **出身与体质**：在太空出生或长期在轨工作；普遍高智商、受良好教育、反应快而冷静；
  多带适应零重力 / 低气压 / 辐射的**基因改造**；零 G 下体力略弱于地表人，但耐力与意志惊人
- **基因库**：轨道人口以**非洲 DNA** 为主——源于泛非世界与欧共体为 [[欧洲航天局]] 建轨道劳力的谈判
- **部落化社会**：以"**工作组**"（workgroup）为紧密单元，类似 [[流浪者七大邦|流浪者]] 部落、极度护短；
  阶层分"技术员"（technician）与"管理层"（managerial）；是热衷讲故事的群体，称太空生活为"**黑暗**"（The Dark）
- **方言"The Word"**：轨道版街头黑话，以多种非洲方言为主，混入法、德、日语成分
- **生活习俗**：空间狭小使裸体禁忌消失（但仍讲体面、忌盯视）；随身只带有用小物（辐射探测器、烧瓶、呼吸器）；
  多为武术好手，**重刀轻枪**——零 G 用枪危险，刀被视为更可靠的致命手段
- **义体与生化**：地表义体在轨道每周约 10% 概率严重故障，故多用轨道工厂造的**屏蔽义体**；
  **生化改造（bioware）比义体更普遍、也更便宜**
- **消遣**：忌毒、酒、烟（零 G 下风险倍增），改用短效高冲击的笑气等；兴奋剂取代抑制剂以促进社交；
  最普遍上瘾的是**超梦**
- **饮食**：以蔬菜、海鲜、藻类与米面为主；菜肴多裹**黏稠酱汁**防碎屑飘入设备；
  饮料用带吸管的真空包装；碳酸饮料因零 G 推进性危险，几乎只在 [[水晶宫]] 才有
- **七小时战争的遗产**：O'Neill 战争（尤其七小时战争）留下的愤怒与不信任至今弥漫——
  高轨者对陌生人与不明飞行器高度戒备、毫不留情

### 与 [[欧洲航天局]] 的脱离

- [[欧洲航天局]] 是奥尼尔等多座空间站的原始出资方
- 但建造完成后,管理层强加 18 小时工作日 + 全天候劳役
- 2022 起义后,工人在 **7 小时**内控制了 OD1 / OD2
- 此后欧洲航天局对轨道殖民地的实际控制不断削弱,
  最终演化为**高轨者联盟**这一独立政治体

### 在 2077 的真实地位

- [[月球]] **名义统治者** = [[欧洲航天局]]
- [[月球]] **实际影响力** = 高轨者联盟
- 整个轨道层的日常运作 + 资源调配 + 人口治理,
  事实上由联盟在主导

### 与超级企业的关系

- 联盟没有自己的工厂或舰队级武力
- 因此对 [[荒坂]] / [[军用科技]] / [[康陶]] 等超级企业上月持**谨慎合作**态度
- [[荒坂]] 在月球秘密建 [[质量投射器]] 时,
  联盟与 [[欧洲航天局]] 都没有第一时间发现——
  说明它对企业级行动的监察能力有限

## 世界观意义

高轨者联盟是 [[公司统治]] 时代**"被遗忘的成功反抗"**的延续:

- 与 [[奥尼尔空间站的抗争]] 互为因果——
  起义夺权是起点,联盟治理是延续
- 它的存在证明 [[公司统治]] **并非全球覆盖**:
  在物理距离足够远 + 基础设施足够独立的地方,
  公司的控制链条会断
- 与 [[阿德卡多]] 形成对照:
  - [[阿德卡多]]:逃离公司体制,在 [[恶土]] 求生
  - 高轨者联盟:不仅逃离,而且**接管了一整套基础设施**继续运行
  - 后者是更彻底的"另一条路"
- 与 [[水晶宫]] 的"消费的飞地"形成镜像:
  - 水晶宫:富人上太空享乐,公司统治的延伸
  - 高轨者联盟:工人上太空建国,公司统治的反面
  - 同一个轨道层被切成"穷飞地"和"富飞地"——
    但讽刺的是,联盟的"穷飞地"在政治上反而更自由
