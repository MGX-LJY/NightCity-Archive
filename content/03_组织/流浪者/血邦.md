# 血邦

## 类型

[[流浪者七大邦]] 之一 / 发源于佛罗里达州及迈阿密周边、风格**极其狂野**的大邦（Blood Nation）

## 起源

血邦最初诞生于两股暴力洪流的交汇——

- **加勒比海难民潮**
- **混乱的南部卡特尔暴力冲突**

这是七大邦中起源**最暴烈、最异质**的群体：
不是从城市出走，也不是从农业出走，而是从**整个加勒比 / 拉美的政治崩溃**里挤出来的。

## 核心特征

### 异质构成

- 强悍的**武装民兵**
- **无家可归的艺术家、乐手、马戏团演员、地下拳手**

这种"民兵 + 艺术家 + 表演者"的拼接构成是七大邦中独一无二的——
它把暴力与娱乐放在同一辆大车上。

### 狂野风格

- 与 [[阿德卡多]] 的"家庭纽带"风格相反，血邦更接近**移动嘉年华**
- 但这并不意味着他们更弱——
  狂野风格的背面是同样级别的暴力组织能力

## 主营业务

**整个北美最大的流浪娱乐供应商**——

- 移动**巨型超梦体验**
- **夜市**
- **赛博马戏团**
- **地下演艺场**
- 兼顾**南部边境的武装走私**

血邦所到之处，会搭建起一座**移动城市规模的娱乐综合体**——
这是七大邦中**唯一直接面向公众的业务模式**。

## 关联

- [[流浪者七大邦]]——所属体系
- [[超梦]]——其核心娱乐媒介
- [[公司统治]]——其娱乐产业与公司娱乐工业的灰色竞争对手
- [[NCPD]] / [[军用科技]]——其武装走私业务的潜在对手

## 世界观意义

血邦是 [[公司统治]] 时代"流浪者也能做大众文化产业"的样本：

- [[阿德卡多]] 卖技术，[[民邦]] 卖物流，血邦卖**情绪**
- 公司娱乐工业（[[超梦]] / 公司体育 / 公司明星）建立在**固定剧场 + 固定剧本**上
- 血邦的娱乐却**带着轮子**——
  没有固定地址、没有官方审批、没有公司剧本
- 这一商业模式使它能为以下两类人服务：
  - 城市边缘居民——城里看不到的演出，他们送到城外
  - 流浪者本身——为路上的族人提供文化消费
- 它的"民兵 + 艺术家"混合构成揭示一个事实：
  当娱乐工业被公司彻底接管，**真正的娱乐必须自带武装**
