# 梅塔集团

## 类型

[[流浪者七大邦]] 之一 / 七大邦中**规模最小、但最特殊**的一个（MetaCorp / The Meta）

## 起源

由前军队高官 **乔纳森·梅塔**（Jonathan Meta）建立——
兼具**流浪者家族性质**与**公司运作模式**的"企业化流浪者"。

- 名字中带"Corp"是有意为之——
  它公开表明自己是流浪者中的"反向公司"
- 创始人本身就是军队高官——
  把流浪者带入了**军事 + 企业**混合形态

## 核心特征

- 内部管理**高度军事化**
- 纪律严明、效率极高
- 与其他大邦的"家族散漫感"形成鲜明对比
- 是七大邦中**最像跨国公司**的流浪者群体——
  也因此最被传统派质疑"是不是还算流浪者"

## 主营业务

- 全北美**最顶级的商业武装护卫**
- **大型供应链物流**
- 高技术重装备维护
- 在**公海海域拥有自己的移动海上平台**——
  与 [[瑟拉斯邦]] 在海上业务上构成竞争 / 互补关系

## 关联

- [[流浪者七大邦]]——所属体系
- [[瑟拉斯邦]]——海上业务的同类
- [[军用科技]] / [[荒坂]]——其商业护卫服务的潜在客户 / 对手
- [[公司统治]]——其商业模型的来源 / 也是其客户来源

## 世界观意义

梅塔集团是 [[公司统治]] 时代"反公司组织自我公司化"的样本：

- 它揭示一个反讽：
  当流浪者想要在 [[公司统治]] 时代真正取得**商业地位**，
  最有效的路径就是**让自己更像公司**
- 它打破了"流浪者 = 反公司"的简单图式——
  流浪者也可以经营公司，只是这家公司是建在卡车上而不是大厦里
- 它能在公海建移动平台——
  说明流浪者的"机动性"不只是公路概念，
  在合适的资本规模下可以延伸到海上 / 太空 / 任何不被国家完整控制的地方
- 它是七大邦中**最不像家族**的家族——
  这也使它最能与 [[公司统治]] 系统兼容、最能被收编
