# 虎爪帮

> 英文原名: **Tyger Claws**（虎鉤衆，旧称 Tyger's Claw）
> 主要地盘: 日本街（西布鲁克 / 沃森）/ 成员规模: 约 5500 人（2077）/ 母级金主: [[荒坂]]
> 子组织: 鬼面组（Kimen-Gumi）/ 历史金主: 夜之城共荣圈（NCCS）

## 类型

[[夜之城]] 帮派 / [[日本街]] 主导势力 / **披着极道外皮的企业化黑帮**。

本质定位：

- 表面是讲规矩、讲生意、讲秩序的日式极道
- 实际是 [[荒坂]] 的**外围白手套**——
  接收荒坂资金、武器、义体、情报与外包任务

## 特征

- 视觉风格：荧光纹身 / 赛博和风 / 武士刀 / 暴走摩托 / 日式街机 / 霓虹广告——
  本质是**企业资本污染后的赛博东京幻想**，美学是营销外壳，内核是产业链
- **经济型帮派霸权**——靠产业链而非地盘暴力立足，信条**"战争不如赚钱"**
- 采用**日本极道 / 山口组式**层级体系，显著特征是**上下层断层**：
  上层企业化经营合法产业，底层是暴力街头混混，上层企业化越深，下层就越无序
- 与其他帮派对比：[[漩涡帮]] = 赛博疯子（纯暴力）；[[巫毒帮]] = 黑客技术邪教；
  [[瓦伦蒂诺帮]] = 拉美街头家族；**虎爪帮** = 商业化、制度化、资本化的"企业打手"

### 义体与武器

- 常用义体：反射加速器、强化义肢、止痛编辑器、**伪装成纹身的电子对抗（ECM）系统**
- 偏好**近战**：陶瓷 tanto 短刀与武士刀（最强者用碳钢正品）；也带手枪和冲锋枪
  （后者多为廉价塑料、花哨、不可靠）
- 摩托车采用高级纤维材质，配特殊植入体——能在狭窄空间高速穿行
- 用不可燃、防磨损的 **Realskinn** 替换皮肤，再覆以**内嵌微芯片的日本恶魔发光纹身**——
  芯片可**混淆敌方瞄准系统**，配合高速近战实现"对方还没反应过来就已被斩首"
- 在专属格斗场**穹顶**（The Dome）锤炼 MMA 技法，虎爪帮、极道家族与 MMA 明星在此混迹
- 多名成员身上有传统刺青（irezumi）——暗示其**前极道身份**（如 [[冈田和歌子]]）

## 已知活动 / 深度档案

### 历史沿革

#### 起源：荒坂的代理摩托帮（2020s）

- 始于一个由 [[荒坂]] 资助的**摩托车俱乐部**（Tyger's Claw）
- 到 2020 年已发展为小型战斗帮派，占据原日本街及周边日裔社区
- 靠荒坂资金偶尔保护当地日裔；成员主用反射加速义体 + 武术

#### 2023 核爆后：被共荣圈改组为守护帮派

- **2023 年夜之城核爆**后，荒坂被逐出北美，作为其代理帮派的虎爪帮残部自生自灭
- 随即被 **夜之城共荣圈**（NCCS，日资公司联合体，由演员**中川忍**领导）接洽，
  带到沃森开发区北部，**改组为守护帮派"Tyger Claws"**，主旨保护夜之城日裔社区
- 成立子组织 **鬼面组**（Kimen-Gumi）作为帮派**公开面孔**——
  注册为合法实体，承接安保合同，有时自任执法者、偶尔与 [[NCPD]] 合作
- 荒坂留下的潜伏间谍**大量混入虎爪帮**——一边为帮派工作，一边为荒坂做卧底
- 总部设在**中川歌舞伎剧院**，鬼面组提供好名声，虎爪帮则暗中抽成、收保护费

#### 2042 继承内战：忍二世上位

- 2042 年**中川忍神秘死亡**，引发虎爪帮内部争夺继承权的内战
- 大量流血后**中川隼人**胜出，继承中川基金会、成为新领袖，取名"**忍二世**"
- 他把基金会公司交给在内战中立功的妻子**藤原良子**（Ryoko Fujiwara）打理

#### 2045：四面受敌的帝国

- 良子谨慎理财，加之共荣圈成员公司逐渐疏远（转用自有安保），虎爪帮财源承压；
  传言其藏有 [[第四次公司战争]] 剩下的荒坂武器库
- 隼人为缓解压力加装更多义体止痛，感到苦心经营的帝国正在流失
- 同时 [[漩涡帮]] 试图扩张进旧日本街、与本地虎爪帮冲突，又与极道家族**神崎组**不和
- 即便如此，虎爪帮对沃森、日本街、南夜之城与宪章山仍有重大影响

### 地盘

主要控制区域：

- **[[日本街]]**（核心大本营）——夜生活中心 / 赌场 / 超梦馆 / 高级会所 / 性产业几乎全沾
- **歌舞伎区**（Kabuki）——闪闪生产线 + XBD 工业
- **沃森**部分区域、**小中国**
- **宪章山**——挖角对手的安置地段（参见 [[对话记录 塔妮娅和平八]]）
- 2077 已知产业据点：[[云顶妓院]]（Clouds）、小澳门赌场、坦克女郎俱乐部、
  河原俱乐部（Ho-Oh）、德拉瓦贾道场等

定位：**经济型帮派霸权**——靠产业链而非地盘暴力立足。

### 组织结构

虎爪帮采用**日本极道 / 山口组式**层级体系——显著特征是**上下层断层**：

#### 上层干部

- 谈生意、经营合法产业
- 控制赌场 / 超梦店 / 妓院
- 与公司合作
- 信条：**"战争不如赚钱"**

#### 底层成员

- 暴力街头混混、嗑药疯子、人贩子、施虐狂
- 随机袭击路人 / 绑架 / 虐待 / 性暴力
- 高层都认为这类行为"有辱帮派"——
  揭示**虎爪帮内部已开始失控**：上层企业化越深，下层就越无序

> 因体量庞大，虎爪帮内部长期有派系争夺钱、地盘与权力，但内斗**只在组织内部处理**；
> 一旦危险外人踏入地盘，全帮立即结成**统一战线**，处理完再恢复内斗。

### 收入来源

#### 合法外壳

- 酒吧、餐厅、赌场、超梦店、夜店
- 用于洗钱与税务遮蔽

#### 核心黑色业务

1. **人口贩卖**——性奴、强迫劳动、黑市人口，与下游性产业链直接整合
2. **色情产业 / [[性偶]] 会所**——
   [[性偶]] 会所的实际经营 / 抽成方（参见 [[性偶会所反馈]]）；
   会所表面"老板"只是日常管理者，奖金加薪都需"向虎爪帮申请"——真正财务话语权在虎爪帮手中；
   与 [[扭扭街]] 一带的红灯产业链高度重叠
3. **虐杀超梦（XBD）工业**——
   绑架弱势人群 → 镜头前虐杀 → 录制黑超梦 → 卖给富豪买家，
   完整产业链由 [[正法承太郎]] 担任"导演"角色
4. **[[闪闪]] 生产链**——
   参见 [[武士虎爪帮警察三角订货链]] 与 [[闪闪]]：
   采购规模 50 / 200 / 300 份按周翻倍——虎爪帮是夜之城闪闪市场**核心买家 + 生产者之一**；
   同时供应武士帮等友好帮派；**童工招募**系统性招募未成年人作为生产线工人；
   **[[NCPD]] 打掩护**直接付钱给警察购买生产线掩护权；
   原料走私链与 [[军用科技]] 内部人合作偷码头货箱（参见 [[对话记录 羽田凉芽中尉和浅井和晴]]）
5. **企业脏活外包**——[[荒坂]] 外包的暗杀、威胁、绑架、镇压

### 帮派挖角策略：策略性吸收对手中层

虎爪帮对其他帮派的中层人员有系统性的**挖角策略**——
样本：从 [[漩涡帮]] 挖走**塔妮娅**（参见 [[对话记录 塔妮娅和平八]]）：

- **谈判人**：虎爪帮成员**平八**（出面接洽）
- 给的条件：钱"多到能换公寓的那种" / 在**宪章山**安排地盘 /
  一帮小弟带她在城里跑腿 / **配保镖**（应对漩涡帮报复）
- 看中她的什么？——**人脉牵线**能力
- 平八的核心话术：
  > "**穿西装的我们拿下了，可他们的白痴小崽子们却还没有。
  >  这帮娃娃的市场潜力可不小**。"

揭示虎爪帮的**两层市场战略**：

- 上层市场（"穿西装的"——公司高管 / 决策者）：虎爪帮已经控制
- 下层市场（"白痴小崽子们"——公司高管子女）：正在用塔妮娅这类前敌人帮派的中层去渗透
- 后者是未来 10 年的"潜在客户"——他们父母现在掌权，他们以后掌权

漩涡帮反应：抓回 + 挖数据 + 处决示众（[[对话记录 凯尔和莫莉]]）——
塔妮娅最终下场可能很惨，但虎爪帮的挖角模式不会因此停止。

### 与 Mox 帮的世仇

核心事件：**[[利琪·薇兹|Lizzie]] 被虎爪帮杀害**（2067 年）

- 2067 年，一名妓女被虎爪帮成员残忍强奸杀害
- Elizabeth "Lizzie" Borden 为复仇杀了三名行凶者
- 当晚她被虎爪帮报复杀死
- 此事引爆**全城暴动**——虎爪帮成员与产业成为暴力主要目标，远超虎爪帮预料
- 暴动催生 [[莫克斯帮]]——本质上是**"为对抗虎爪帮压迫而成立的组织"**；
  虎爪帮事后与其达成协议、放过 Mox，但双方始终积怨

这条仇恨线决定了夜之城红灯产业的双线对立：

- 虎爪帮 = 性产业资本剥削方
- Mox = 性工作者自卫组织

### 2077 内部裂痕样本：芯片碎片

一批日本街委托与对话芯片，从侧面拼出虎爪帮"上层企业化、下层失控"的现状：

- **现任头目架空老教母**——[[委托 虎爪帮神社窃听器]]：实权头目**加须大木**
  企图摆脱 [[冈田和歌子]] 的幕后影响、独霸日本街，被和歌子反向监听。
  印证"内斗只在组织内部处理"，但这次的对手是同帮的幕后控制者
- **基层叛逃成风**——多人卷款/坑帮后出逃，引来全帮追猎：
  - 赌场荷官**旋风**私吞赌资潜逃（[[委托 偷旋风的信用芯片]]），
    且因良心不安想当**人口贩卖案第一证人**、向调查者交出"姓名、地址、照片"
    （[[对话记录 瑟盖·柯克和杰森·拉索]]）——直接威胁帮派核心黑业务
  - 网络客**小妖**搭伙打 [[岐路司]] 仓库后反水卷走整车货，被擒后宁烧脑也不松口
    （审讯方内部对话见 [[对话记录 金石和中谷]]，和歌子抢人见 [[委托 营救网络客小妖]]）
- **供应链被同行劫掠**——[[对话记录 斯坦尼斯劳斯·兹比斯科发给24个接收人]]：
  [[动物帮]] 伏击虎爪帮的运货人古斯，劫走整批高科技植入体转运给"俄联邦母亲"，
  还串供嫁祸——显示虎爪帮的走私链正被其他帮派蚕食
- **XBD 与人口贩卖的底层生态**——[[对话记录 杰达·阿彻和汤姆·克里斯托弗]]
  （定制虐杀超梦）与人口贩卖证据链，呼应 [[正法承太郎]] 主导的 XBD 工业

### 帝国承压：人质谈判、内腐与情报渗漏

芯片碎片拼出虎爪帮在持续外部压力下的三条内耗裂缝：

**人质-停战外交**。复仇者蒂亚戈·拉米雷斯连杀虎爪帮二十余人、令帮派"搞砸两三笔生意"后，指挥链陷入互责（[[对话记录 上野秀义和升田坚]]："就因为你，我们搞砸了两三笔生意"）。升田坚最终主动提出以归还人质女儿换取停战（[[对话记录 升田坚和蒂亚戈·拉米雷斯]]："是我们不好，我们想把她还给你"）——揭示虎爪帮的"统一战线"在持续失血时存在上限：当损失超过颜面成本，停战才是理性出口。

**内部腐蚀双轨**。账房层面：军火差价被账房私吞五个点，消息被外部合作者反向掌握用于讹诈（[[对话记录 阿诺德·哈帕尼克和苏珊·帕克]]）。成员层面：基层队员上班吸毒、行为失控，上司警告的边界只是"工作时别吸"（[[对话记录 加藤真嗣和铃木秀夫 帮派吸毒]]）——纪律底线已低至"不死人就行"。

**情报被动渗漏**。弗兰克替对手在虎爪帮车辆上装 GPS 追踪器被怀疑（[[对话记录 卡玛拉·史密斯和史蒂夫·赞恩]]），折射出运营链中的合作者都可能成为渗透口。三条裂缝同时运转：外部报复打乱收入、内部人员偷差价吸毒、合作外包者随时反水——正是上下层断裂加速的微观注脚。

## 世界观意义

虎爪帮是 [[公司统治]] 时代帮派与日本黑道传统结合的样本：

- **资本化黑帮**——已不再是传统街头帮派，而是企业外围组织 /
  半合法资本集团 / 夜之城灰色秩序维护者
- **"守护者"的堕落**：从中川忍时代"保护日裔社区"的守护帮派，
  一路滑向人口贩卖与 XBD 工业——
  这正是 [[荒坂]] 模式的微缩复刻：用援助与保护做包装，暗中尽可能攫取控制权
- 与公司不同：他们不通过合同管理身体，而是通过债务和恩义
- 与 [[清道夫]]、[[动物帮]] 这种纯暴力 / 化学路线相比，
  虎爪帮更接近"传统黑帮"——讲规矩、讲层级、靠固定产业链稳定盈利
- **现实型的恶**：相比漩涡帮的赛博疯狂、巫毒帮的技术邪教，
  虎爪帮做的事（人口贩卖、性压迫、妓院控制、女性剥削）
  更接近现实黑帮——玩家代入感更强，反感也更深
- **白天与黑夜的统治分工**：
  - 企业（荒坂）在白天统治城市
  - 虎爪帮在夜晚统治欲望
  - 二者本质上是同一套权力体系的日夜双面
- **垂直整合的极端样本**：
  性偶会所（活人 → 性产品）→ XBD 工业（活人 → 死亡内容）——
  当前者的需求饱和，后者就是同一资源的下一轮变现
- 由 [[正法承太郎]] 担任 XBD 导演的事实证明：
  虎爪帮的"日式美学"不只是文化包装，
  它在产业实操层也用日式黑帮的**层级 + 仪式感**包装最极端的暴力
- **内部撕裂**：上层企业化 vs 下层暴虐化的张力，
  揭示资本化黑帮的内生矛盾——
  当核心人物追求"赚钱"时，他们对底层的暴力已经失去管理意愿

- 虎爪帮的"理性商业"信条在极端压力下会主动退让（以人质换停战），说明"战争不如赚钱"不只是战略口号，也是止损底线——但这同样是它被对手反复消耗的漏洞
- 内腐与情报渗漏的并存，呼应 [[荒坂]] 帝国本身的衰朽逻辑：越庞大的组织越难防住内部蚕食，虎爪帮不过是其缩小版的镜像
