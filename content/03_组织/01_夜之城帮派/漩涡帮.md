# 漩涡帮

> 英文原名: **Maelstrom**
> 创始人: 锤子（Hammer）/ 成立: 2010 年代 / 总部: 陶坦兹大楼（Totentanz's Building）
> 成员规模: 约 1300 人（2077）/ 威胁级别: 极高 / 主要地盘: 沃森北区工业区

## 类型

[[夜之城]] 增强帮派 / 战斗帮派 / 极端义体化、崇拜暴力的"二逼神经病"。

## 特征

- 标志性义眼：**抠掉真眼，换上闪烁红光的护目镜式赛博义眼**——
  不仅是帮派标识，还能**黑入无人机**、在战斗中读取生命体征信息
- 自残式入帮仪式：挖出眼睛，剥皮，**不打麻药**——"只要你能活下来，就算入帮"
- 偏好**下臂螳螂刀**与**骨骼支撑架**——后者让他们能挥舞超重装备
  （重型火箭筒，或把工业机械改造成的杀人器具）
- 穿合成皮革夹克与裤子，契合死亡金属美学，也便于潜入敌区时藏刀
- 崇拜**赛博空间的奥秘**，混入大量**北欧神话与神秘学**元素（纹身、地盘涂鸦）
- 高度依赖刚改义体——但**拒绝使用协同处理器**（容易被黑）
- 约 **1/3 成员是登记在册的 [[赛博精神病]] 患者**，其余游走在发病边缘
- 分成小组运作：巡逻地盘时四五人一组，突袭 / 雇凶 / 护送贵重货物时可达三十人
- 其音乐口味只钟爱**耳鸣乐队**
- **越来越胆儿肥**：连 [[NCPD]] 都不敢直接管，其他帮派内部沟通时也提醒"最好别惹着他们"
  （参见 [[对话记录 刚一和佳奈]]："我担心的不是蓝皮狗，而是那些真正头脑短路的——漩涡帮"）

- **帕特里夏**（Patricia）、**嘟嘟**（Dum Dum）——2077 年的其他头目

## 已知活动 / 深度档案

### 历史沿革

#### 起源：金属战士的残党（2010s–2020s）

- 2013 年后某时，被金属战士帮（Metal Warriors）因违反战斗准则逐出的"**锤子**"创立漩涡帮
- 金属战士帮后被审判者帮（Inquisitors）几乎团灭，残部一部分投奔锤子；
  又吸收了红铬军团（Red Chrome Legion）、铁准星（Iron Sights）中与审判者有仇的人
- 帮派标志：**握着旧式锤柄、被旋风环绕的拳头**
- 锤子治下**没有任何规矩，一切皆可**；约 1/3 成员是登记在册的赛博精神病
- 据点：旧市中心一家废弃百货公司"**巴利商场**"（Barley's），靠近码头

#### 2023 核爆与陶坦兹（Totentanz）

- [[第四次公司战争]] 对漩涡帮造成毁灭性打击；2023 年**夜之城核爆**时，
  据点被海景公寓楼挡住免遭直接轰炸，但大批重度义体成员在爆炸后 **EMP 诱发的超暴力狂潮**中死亡，包括锤子
- 大火席卷地盘；**粉碎者**（Crusher）成为新首领，带幸存者前往伯尔森塔（Burleson Tower）
  顶层的**陶坦兹俱乐部**（Totentanz，又译"死亡之舞"）——
  与勇士心帮（Warrior Heart）争夺这座废楼，粉碎者杀其首领
- 漩涡帮把阵亡同伴（含锤子）的焦尸做成木乃伊，陈列在舞厅墙上——
  穿戴阵亡成员的旧义体（带可见的烧灼损伤）被视为一种荣誉

#### 热区岁月与术士崛起（2027–2040s）

- 2027 年粉碎者赛博精神病发作、屠杀 StormTech 车队后消失于热区（Hot Zone），由赫克斯特拉接任
- 赫克斯特拉后被 MaxTAC 击杀，年轻的**术士**（Warlock）接掌，Quake 与 Flenser 辅佐
- 术士把围着旅馆转的混混训练成热区最强拾荒力量；靠**毒品 + 义体交易**壮大；
  与众多义体医生达成"廉价零件换折扣服务"的交易

#### 2045 后：迁址与扩张冲突

- 伯尔森塔濒临坍塌，Flenser 负责找新址；漩涡帮选**旧日本街**为扩张目标，与当地 [[虎爪帮]] 冲突
- 在城北一座未完工烂尾旅馆开了**新陶坦兹**

#### 2070s–2077

- 信奉"**金属胜于血肉**"，控制**沃森北区工业区**大部，影响力南延
- 2077 年由**罗伊斯**废黜并囚禁前任老大**布里克**后领导

### 收入来源

- **主要**：走私违禁药品与毒品
- **雇凶**——手法离奇残忍：受害者常被肢解、活剥皮、或淹死在湿水泥里
- 对重兵护卫的**公司运输队**发动精心策划的劫案
- **陶坦兹俱乐部**：当时夜之城最火的帮派俱乐部与"喝酒 + 暴动"场所，设在废弃旅馆——
  一晚死亡人数不到一打就算"无聊"；只要服从漩涡帮的规矩，外帮也能进去蹦迪、听新死亡金属
- 传言制作黑市超梦（尤其离奇暴力的），传出一种叫"**麻木**"（Numbness）的情感真空超梦，
  在过度刺激的超梦用户中很受欢迎（[[NCPD]] 未找到证据）

### 常规活动

- 接买卖杀人（参见 [[身陷漩涡帮]] 中莫西干线人的暗示）
- 在死亡之舞俱乐部主办耳鸣乐队的演出——成为他们的固定客户群
- 频繁的酒吧群殴 / 街头袭击

### 叛徒被追杀样本：塔妮娅案

漩涡帮成员**塔妮娅**从昨天起改投 [[虎爪帮]]——

- 虎爪帮给的钱"多到能换公寓的那种"+ 配保镖
- 虎爪帮看中她的**人脉牵线**能力（"穿西装的我们拿下了，可他们的白痴小崽子们还没有"）
- 在宪章山给她安排地盘 + 一帮跑腿小弟
- 参见 [[对话记录 塔妮娅和安德烈]] + [[对话记录 塔妮娅和平八]]

漩涡帮的反应（[[对话记录 凯尔和莫莉]]）：

- **凯尔 + 莫莉** 立即派人追踪 → 抓住塔妮娅
- 塔妮娅求饶："我可以给你们情报，值钱的数据"
- 莫莉："我会亲手把数据挖出来 / 弄死那狗日的贱逼玩意，挂出去让外头的都瞧瞧！"
- 即"挖数据 + 处决 + 示众"三段式

这一案例说明：

- 漩涡帮对叛徒的处置极端化，与其义体崇拜暴力文化一致
- 虎爪帮策略性挖角——专门拉拢漩涡帮中**有公司圈人脉**的人
- 漩涡帮在帮派食物链上**被虎爪帮压一头**——
  虎爪帮可以"穿西装的我们拿下了"，漩涡帮只能在沃森工业区做生意

### 跨境偷渡顶级义体医生：蒙大拿·亨利案

漩涡帮为弄到神经视觉植入体领域的顶尖义体医生，不惜从 **南加利福尼亚**（新美利坚一侧）偷渡一位绰号"蒙大拿"的亨利·路易斯进城——

- 亨利开价"新美利坚这边最好义体医生"的三倍，还要帮派替他搬来整套诊所与设备；漩涡帮一口答应"漩涡帮一向付全款"（[[对话记录 亨利·路易斯和乔希·卢卡斯]]）
- 由乔希·卢卡斯派走私客内德·林奇护送过境，正赶上 [[军用科技]] 恶土巡逻加强（[[对话记录 内德·林奇和乔希·卢卡斯]]）

这说明漩涡帮的义体崇拜不止于"廉价零件换折扣"——为一台顶级神经植入手术，他们愿意付全款 + 冒跨境走私风险，与 [[乱刀会|夜游鬼]] 的偷渡网共用同一条恶土通道。

### 无人机武装化、抑制剂依赖与罗伊斯内斗清洗

三条芯片线索揭示了 2077 年漩涡帮运作的底层逻辑：

**无人机黑改流水线**。漩涡帮系统性地盗取或收购军用无人机原型机，再委托黑市技术员解锁安全系统、重校 IFF 敌我识别——[[对话记录 回形针和加藤秀树]] 记录"天上弄来的原型机"准备解锁后"整死对头"；[[对话记录 奥列格·奥尔洛夫和哈尔·坎托斯]] 则是催促技师完成飞蛾_RHT-1 的 IFF 重校，暴露出从盗货到武装再到部署的完整链路。

**抑制剂储备即软肋**。漩涡帮大量囤积义体狂热抑制剂来压制成员的赛博精神病发作，但存货本身成为他帮的打劫目标：[[对话记录 格里兹和赖德]] 显示另一帮派凭精准情报打了漩涡帮"个措手不及"，抑制剂得手后立刻转卖给等候的买主。义体依赖需要抑制剂续命，而抑制剂又是可被截断的命脉。

**罗伊斯清洗：扒义体、清血迹**。权力更迭远比"废黜囚禁"更血腥：[[对话记录 布里克和埃利斯]] 中布里克已自知是死人、劝忠心部下出逃；[[对话记录 胡夫和桑德斯]] 补完另一面——罗伊斯一侧的多尔命人扒走囚犯的旧义体、将其打残，再清理满地血迹以免影响生意。夺权不只是枪决，而是先剥夺对手的义体战力。

## 世界观意义

漩涡帮是 [[公司统治]] 时代义体文化最极端的负面样本：

- 把自残作为身份认证——这是 [[赛博精神病]] 群体的集体化形态
- 与 [[动物帮]] 的"用化学品突破肉体"形成对照：
  动物帮选择肉体，漩涡帮选择金属
- "拒绝协同处理器"——这是他们少有的清醒判断：
  既然要把脑子接到义体，那就拒绝可被黑客远程操控的中间层
  即便如此，他们自己用粉啊药仍然把脑子搞坏
- **"疯狂"是精心经营的外壳**：官方设定揭示，漩涡帮看似一群临近发病的疯子，
  实则一切都按"生意"运作——公开的残忍处决、离奇仪式都是经营策略，
  谣言越多，对他们越有利（[[杰克·威尔斯]] 与 [[V]] 在"接活儿"任务里打交道的就是这一面）
- 他们的存在使 [[夜之城]] 的"赛博朋克"标签具象化——
  当你看到一个抠眼装红灯的人，你才真的"看见"了这座城市

- 抑制剂即控制杠杆：漩涡帮的极端义体化并非无代价的自由——战斗力建立在对抑制剂的结构性依赖之上，任何人切断这条供应链，都能在无需正面交战的情况下瓦解整支队伍
- 夺权的"义体政治"：罗伊斯清洗布里克时优先扒走对方义体而非直接处决，说明在漩涡帮内部，义体既是战力又是身份——剥夺义体即剥夺人格，比死亡更彻底地宣告失败
