# 六街帮

> 英文原名: **6th Street**
> 别名: 退役军人帮派 / 创始人: 所罗门·"X"·赖特 / 成员规模: 约 2300 人（2077）
> 总部: 阿罗约（2077，旧总部为"军械库"）/ 主要地盘: 圣多明戈、海伍德、西布鲁克 / 威胁级别: 中

## 类型

[[夜之城]] 帮派 / 由 [[公司战争]] 退役军人、失业老兵聚合而成的准军事组织，
兼作私人治安承包商。

## 特征

- 穿着**军队制服、作战靴、战术背心、护膝、迷彩裤**，戴印有 [[新美利坚]] 国旗 / 鹰徽的棒球帽——
  容易被误认为是休假大兵
- 逮着机会就高喊"奥拉"作为帮派身份标识
- 实质是暴力、危险的混混——"杀你时眼皮子都不会眨一下"
- 常用义体：赛博义眼、止痛编辑器、健康监测器；军火由 [[军用科技]] 与剑菱（Kendachi）供应
- 招牌反义体武器：装有 **EMP + 穿钢尖刺**的伸缩棍——
  专破那些"自以为一身金属电子就刀枪不入"的帮派与公司打手
- **爱国但不限族裔**：崇拜传统爱国精神，却不效忠任何特定州 / 国 / 族群——
  其忠诚只属于**社区与街坊**，无论对方长相或出身
- 主要据点：圣多明戈、丽景区

## 代表人物

- **所罗门·"X"·赖特**（Solomon "X" Wright）——创始人；
  前美军情报军官，把一批 [[第四次公司战争]] 老兵聚合到一面旗下（详见深度档案）
- **里克·莫顿**（"General" Rick Morton）——保守派 / 老派首领，2076 年政变中被杀（详见深度档案）
- **威尔·火炮**（Will Gunner）——反公司派首领，2076 年政变上位（详见深度档案）
- **阿比特**（Arbiter）——赖特之子，2040 年代执法主力"戴维斯小队"队长

## 已知活动 / 深度档案

### 历史沿革

#### 起源：X 上校与"3-I"结构（2020s）

- 2020 年代中后期，**所罗门·赖特上校**（绰号"X"，前美军情报军官）
  把大批 [[第四次公司战争]] 老兵组织起来，保护战后混乱的 [[夜之城]] 市民
- 借用战时军衔搭起松散军事结构；X 坚持称其为"组织"以争取合法性，外人则视其为又一个帮派
- 用"**3-I**"原则分权：调查（Investigations，侦探）/ 打击（Impact，士兵）/ 内务（Internal，管理）；
  指挥层投票中若 2/3 反对 X，上校的命令即被推翻
- 早期靠**勒索公司高管**筹措资金；目标是取代腐败的 [[NCPD]]、把夜之城拉回美国版图
- 把北海伍德一座九层国民警卫队军械库改造成总部"**军械库**"
- 设**每月义体申报制**——成员须报告自身赛博改造量，超限即被开除（防止队员对平民赛博精神病发作）

#### 2040s：被授权为私人执法承包商

- 被正式任命为私人执法承包商，获北海伍德街道的官方保护权，徒步 + 摩托轮班巡逻
- 保护小欧洲的圣天使教堂；但因野心过大入不敷出，被迫转向勒索、走私、变卖"没收"财物
- 主力执法单位"**戴维斯小队**"由赖特之子**阿比特**统领；与邻近 [[流浪者七大邦|流浪者]] 关系良好

#### 2050s–2070s：腐化与地盘战

- 资源压力与腐败让六街帮放弃"服务公众"初心，沦为又一个滥权帮派——
  从收贿、收保护费，一路滑向逼商铺纳贡、偷车、制贩毒品、谋杀
- 战斗出租车（Combat Cab）在某个时点与六街帮挂钩
- 到 2070 年代控制圣多明戈大部，[[统一战争]] 老兵大量加入
- 2071 年与 [[瓦伦蒂诺帮]] 在西布鲁克爆发枪战，2074 年起为争夺丽景区升级地盘战
- **2076 年底突变**：因"是否与公司合作"分裂——反公司派由**威尔·火炮**发动政变、
  当众杀死时任首领**里克·莫顿**，随后血腥清洗莫顿亲信（详见下文领导层内战）；
  尽管打反公司旗号，火炮仍暗中与剑菱合作设计新武器线

### 武装升级：导弹发射车级别

六街帮的武装购物清单（参见 [[六街帮购物单]]）已达**城市恐袭级别**——

- **导弹发射车**（武装平台）
  - 强化车体装甲
  - 加大底盘
  - **GPS 制导火箭 2 组，每组 6 枚**
  - **最大射程：150 公里**
- 额外采购：4×6 带**高爆燃烧弹头**的火箭

供货方：EBM 体育场工厂线——
**拉塞尔·波拉** 接待 / **弗兰克·奥斯马尼** 来取货 / **查克·德门** 警卫
（参见 [[对话记录 弗兰克·奥斯马尼和拉塞尔·波拉]] +
[[对话记录 拉塞尔·波拉和查克·德门]]）

这一武装级别揭示：

- 六街帮已经从"街头帮派"升级为**准军事组织**
- 150 公里射程意味着可以从 [[夜之城]] 城外发射攻击城市目标
- 与"退役军人"身份完美契合——他们有人会用这种武器
- 这也部分解释了为什么 [[NCPD]] 私有化后犯罪率飙升时**没有人敢直接打六街帮**——
  对方的武器库已经能跟正规军平起平坐
- 而 [[狗镇]] EBM 沛卓石化体育场工厂是这种黑市武装的核心供应中心——
  [[汉森]] 默许下的工业级武器流通

### 领导层内战：莫顿 vs 火炮（2077）

一批芯片揭示了六街帮 2077 年前后的一场**内部分裂与火并**——
核心矛盾正是 [[军用科技]] 渗透引发的"理想 vs 金钱"路线之争。

#### 老派的控诉：托尼·凡尔赛蒂宣言

老成员 **托尼·凡尔赛蒂**（十年前为"和伟大祖国的敌人作战"入狱，刑满归来）
向全帮 3871 人群发宣言，痛斥**现领导层投靠 [[军用科技]]**：
"军用科技的钱！军用科技的武器！军用科技的订单！"——
他认定"真正的六街帮绝不会与公司同流合污"，
斥现领导层"病入膏肓，病就叫做贪婪"，号召"为信念而战"、"不自由，毋宁死"。
（参见 [[已发送给 3871 名用户 托尼·凡尔赛蒂]]）

随即，公司派系派打手去"教训"托尼——
**克里斯托弗·瓜尔蒂耶里 + 詹姆斯·阿龙松** 受命把这个"老杂碎"
"萌芽扼杀在摇篮里"，理由是他"不愿接受公司狗腿子的施舍"。
（参见 [[对话记录 克里斯托弗·瓜尔蒂耶里和詹姆斯·阿龙松]]）

#### 两大首领：莫顿与火炮

- **莫顿**（Morton）——**保守派 / 老派**首领，代表反公司的"真正六街帮"路线
- **威尔·火炮**（Will Gunner）——现领导层首领，亲 [[军用科技]] 路线；
  日常发号施令、对欠保护费的农场店铺"好好榨油水"
  （参见 [[对话记录 大卫·本尼和威尔·火炮]]）

#### 火并爆发

- **火炮的人杀了莫顿**——巴勃罗·席尔瓦惊呼"事情闹大了！都他妈乱套了"，
  连夜带家人出城、并要把文件送交一名 [[NCPD]] 内线
  （参见 [[对话记录 巴勃罗·席尔瓦和萨尔玛·席尔瓦]]）
- **火炮下令清洗莫顿余党**："莫顿的人，[[军用科技]] 监狱里关着的那些，必须消失"，
  "对保守派零容忍"——计划黑入监狱系统、断电制造暴动，趁乱灭口
  （参见 [[对话记录 莱姆·马丁和大卫·麦克布赖德]]）
- 双方互扣"叛徒 / 公司走狗"的帽子：
  贾克·德赖弗 群发檄文，宣称巴勃罗·席尔瓦"和激进的叛徒为伍""为公司办事"，
  "他将尝到他和其他人对莫顿所做的一切"
  （参见 [[已发送给 47 名用户 贾克·德赖弗]]）
- 同时四处追杀"跟莫顿走得太近"的人
  （参见 [[对话记录 奥尔加·伊丽莎白·隆米德和安妮·布朗]]）

这场内战印证了托尼宣言的判断：
**当退役老兵帮派被 [[军用科技]] 的钱收买，"爱国"与"生意"就再也无法两全**——
六街帮从"反公司的退役军人共同体"裂变为"自相残杀的公司外包武装"。

### 毒品复仇链：迪恩·西蒙斯案

一条完整的"六街帮孩子被毒死 → 报复链启动"的样本：

- 毒贩 **迪恩·西蒙斯** 给六街帮的"那帮孩子"卖了一批本该干净的货
- 但货被人**做了手脚**——孩子们死了
- 六街帮认定迪恩是凶手 / 告密者，**追杀启动**
- 朋友"比尔"急促警告迪恩跑路：
  > "他们不可能就这么算了 / 你必须走 / 我认真的"
- 迪恩问"我还有家人呢"，比尔答"不用管他们，他们会没事的，我保证"——
  典型的安抚谎言
- 参见 [[对话记录 迪恩·西蒙斯和比尔]]

#### 复仇链的下游：弗罗斯特·李案

但迪恩可能根本不是告密者——
另一组人物 **弗罗斯特·李 + 克里斯·詹姆斯** 透露真相：

- 弗罗斯特·李的几个人去抢"帮公司运货的"那批货
- 结果**被公司的军队埋伏 + 配备无人机**反伏击
- 是谁告诉他们去拿那批货的？——**迪恩·西蒙斯**
- 克里斯："你知道该怎么办"
- 参见 [[对话记录 福雷斯特·李和克里斯·詹姆斯]]

#### 真相推断

- 迪恩可能是无意中**给两边都通风报信**——
  既告诉六街帮孩子们去拿这批货，也告诉弗罗斯特·李去抢公司军队的货
- 一个普通毒贩 / 中间人在多线之间踩雷
- 复仇队从六街帮和弗罗斯特·李两边同时来——
  迪恩"我还有家人呢"的求救，背景是**夜之城信息中转人的标准死法**

### 内部出卖样本

六街帮内部出现过**叛徒**——
一个成员把自己以前的兄弟出卖给中间人**高里一木**：

- 他出卖兄弟、还搭上"那么多尖货"以换取脱身
- 中间人按约定**送他上一艘去巴拿马的船**跑路
- 但中间人也警告："要当心他那些六街帮的兄弟们，估计会找过来"
（参见 [[对话记录 高里一木和小场次郎]]）

这一案例说明六街帮内部并不全是"军人荣誉"——
当退役老兵失去公司发薪渠道，
**出卖战友 + 偷运货物**也是一种生存方式。
"巴拿马跑路"成为夜之城叛徒的标准出路——
与流浪者部落的"投奔他邦"形成对比：
帮派叛徒不能投奔同行，只能远走他国。

### 被栽赃的样本：剃刀史蒂夫案

冈田俊 + 千叶英子两位夜之城中间人执行了一起精心设计的栽赃——

- 杀死 [[乱刀会]] / 夜游鬼成员"剃刀"史蒂夫·科瓦尔斯基
- 现场刻意做得像六街帮所为
- 目的：让夜游鬼"以为六街帮要开战"，挑起两家全面火拼

这暴露了六街帮一个结构性弱点——
作为"看起来像兵的混混"，他们的暴力风格容易被**别人模仿**；
任何其他帮派只要穿件旧军服动手，都能把锅扣给六街帮。
六街帮的身份标识（旧军服 / 平头 / "奥拉" 口号）
反而成了**最容易被栽赃的身份**——
这是 [[公司统治]] 时代退役军人帮派的额外代价。

### 日常胁迫活动样本

除武装与内战外，多份芯片记录了六街帮的街头日常：

- **保护费 / 强占店铺**——强迫 蒂亚戈·费罗 的酒吧不许打烊；
  成员 卢克·安德森 失手打死"头儿的朋友"蒂亚戈，连夜把尸体运到工地埋掉
  （参见 [[对话记录 祖里亚·费罗和蒂亚戈·费罗]] + [[对话记录 卢克·安德森和麦克]]）
- **工地恐吓**——受开发商 威利斯（原 [[军用科技]] 背景）指使，
  去圣阿马罗工地恐吓工人、阻止施工
  （参见 [[对话记录 凯文·洛汗和克罗克斯·阿尔瓦拉多]]）
- **毒品分销**——用"那帮孩子"做带货与收钱的隔离层，
  货存熊果街车库（密码 1313）、每周二补货——头目从不亲自交易
  （参见 [[杰科 命令]]）
- **地盘垄断**——抓住在地盘上做生意的外来贩子当众处决，
  逼迫"员工"只能从六街帮进货（参见 [[对话记录 约翰·奎德和艾丹·拉琴斯]]）

### 官方神话 vs 现实：《六街帮的爱国者》

一篇媒体软文（[[六街帮的爱国者]]）把六街帮包装成丽景区的救世主：[[第四次公司战争]] 摧毁小微经济、[[荒坂]] 抢走本地生意、新帮派横行而 [[NCPD]] 束手无策之际，退伍老兵回到丽景区、储备 [[军用科技]] 武器、把作战本领教给街坊、向野蛮帮派复仇，组成"准军事部队"；通篇宣扬"骄傲、年轻、热盼各州重新统一"的国家主义话术，把他们的走私与抢劫斥为"敌人的污蔑"。这套自我神话恰是上文"腐化与内战"的反面镜像——它记录了六街帮**希望被如何看待**，而其余档案记录了他们**实际是什么**。

另有两份零散样本：NCPD 在 [[谷地区]] 对六街帮成员发起的无人机拦截调查（[[命令 六街帮所属犯罪分子]]）；以及中间人乔·斯卡洛尼的受贿台账里，"麦克（六街帮）"作为长期加价对象在列（[[我的文档 乔·斯卡洛尼]]）。

### 军事化执法的日常工具箱

六条芯片合并呈现出一套连贯的准军事执法逻辑——不是随机暴力，而是有指挥链、有分工的系统：

**指挥层级**——"火炮将军"通过中间人逐级下达追捕令："我接到的命令是带上你的人，不行也得行"（[[对话记录 阿尔佛雷德·麦尔斯和达瑞斯·马克斯]]）。将军头衔背后是真实运转的命令链。

**酷刑取供**——情报获取是标准化程序：泰勒尔逐根切断手指，"到第九根的时候他开始求饶""但我觉得活儿最好还是做全套"，最终拿到坐标（[[对话记录 泰勒尔和亚当 酷刑]]）——带职业自豪感的流程作业。

**地盘驱逐**——斯派克确认夜游鬼毒贩侵入地盘后下令"快点把人解决掉，利落点，不要声张"（[[对话记录 斯派克·戈德布卢姆]]）。

**低烈度威慑**——布雷克的雇佣清单包括"废几副膝盖"和"去收拾别人的老婆、男人、孩子"（[[对话记录 布雷克·克洛伊尔和提姆·奥特里]]）——家属是施压筹码。

**武力商品化**——雅沙接到保镖任务先骂命令，看到保护费金额后立刻"只要银子到位什么都好说"（[[对话记录 雅沙·伊万诺夫和路卡·莫罗佐夫]]）；而六街帮改装好的车辆已成他人眼中可掠夺的财产（[[对话记录 法蒂玛和夏维]]）。

### 丽景区毒品战的另一面：古斯塔沃案

2077 年六街帮与 [[瓦伦蒂诺帮]] 争夺丽景区控制权的地盘战，在街头落到一桩具体仇杀上——六街帮把瓦伦蒂诺帮次级头目 **古斯塔沃·奥尔塔** 的女人"玛"打成重伤住院（古斯塔沃为此雇黑客 24 小时守病房防其被补刀），并迫使古斯塔沃在丽景区加紧毒品备货、自知"搞不好要打最后一仗"。古斯塔沃随即出大价钱找杀手 **卡鲁波** 报复六街帮，被以"这是要跟六街帮开战，你找错人了"婉拒。这条线从瓦伦蒂诺一侧补全了六街帮在丽景区的施压方式：不只抢地盘，也直接打击对手头目的家人以逼其退让。详见 [[古斯塔沃·奥尔塔的消息]]、[[对话记录 古斯塔沃和卡鲁波]] 及 [[瓦伦蒂诺帮]] 节点"古斯塔沃案"。

## 世界观意义

六街帮是 [[公司战争]] 余波的人形载体：

- 当 [[新美利坚]] / [[军用科技]] 把退役军人扔回 [[夜之城]] 后，
  这些人没有合适的安置，也没人收编他们——
  于是他们自己穿着旧军服结成了帮派
- "看起来像兵，其实是混混"——
  这种身份混淆本身就是 [[公司战争]] 后军队边界模糊的样本
- 他们不像 [[动物帮]] 那样表演兽性，也不像 [[巫毒帮]] 那样追求灵性——
  他们只是把"军纪"变成"街头规则"
- 与 [[公司统治]] 时代的退役保障真空形成镜像：
  公司可以雇佣兵打仗，但不会负责他们之后的人生
- 六街帮的"军事纪律"不是荣誉遗产，而是把酷刑、家属威胁、外包保镖系统化的暴力产业链——退役军人的职业技能在 [[公司战争]] 后找到唯一买家：街头
- 暴力定价（见钱眼开的保镖、卖命前先问酬劳的打手）揭示 [[公司统治]] 对兵源的消耗逻辑：战争结束后军事能力不消失，只是换了甲方，从国家换成出价最高的人
