# 创伤小组

## 类型

私营紧急医疗与战术救援公司（Trauma Team）

## 核心业务

- 为高端会员提供"战场级医疗救援"——
  收到求救信号后，武装医疗小队会以战术规模介入战区
- 服务对象按会员级别分层——普通市民几乎接触不到
- 是 [[公司统治]] 时代私人化医疗的极致样本

## 已知活动

### 桑德拉·多塞特救援
- 桑德拉·多塞特是创伤小组的**高级会员**
- 被 [[清道夫]] 绑架后，[[V]] 与 [[杰克·威尔斯]] 完成解救
- 这次任务是 [[V]] 与杰克合作的开端，也是 V 进入 [[来生]] 雇佣兵生态的敲门砖

### 南街区贫民区劫药事件
- [[夜之城]] **南街区**——超级摩天楼贫民区，居民集中生病、缺药
- 居民代表**玛格达琳·尤西奇克** 找到武装人员**豪尔赫·罗恩** 帮忙
- 一名邻居的少年黑客**几下操作就黑入了创伤小组的派送系统**——
  定位到一辆装载药物的浮空车
- 计划：用 EMP / 武器把浮空车打下来劫药
- 豪尔赫的反应：":D 你们死定了 / 真是命都不要了" + 仍然答应帮忙
- 玛格达琳的报酬要求："不要钱，我只想认识一下你隔壁那个天才儿童"
- 这是 [[公司统治]] 时代**草根反创伤小组**的样本：
  - 公共医疗失能 → 贫民区生病无药可拿
  - 富人 / 公司员工的派送车却装满救命药从头顶飞过
  - 一个少年黑客 + 一群武装居民 + 一个老兵 ≈ 一次劫药行动
- 玛格达琳提到："我本来以为 [[瓦伦蒂诺帮]] 会帮忙，帮助普通老百姓"
  - 暗示瓦伦蒂诺帮在海伍德/南街区一带的"罗宾汉"叙事**实际并不兑现**
- 这次行动可能就是 [[飞行记录 3287-AFH]] 中那架"被 EMP 击中、失去高度、坠落"的浮空车的对应视角
- 参见 [[对话记录 豪尔赫·罗恩和玛格达琳·尤西奇克]]

## 黑暗面:救护资源走私黑货

参见 [[交货情报 创伤小组黑货]]——

街头交易短讯直接称呼"**创伤的人给我们带了新货**":

- 时间表:"我一小时内过来"——
  创伤小组的医疗车速度被用作**黑货专递**
- 交易方式:"把钱给他们就是了"——
  现金面交,无任何医疗记录
- 警告:"千万别冲动,别犯傻"——
  这暗示来送货的是装备齐全的武装医疗组,得罪不起

这条线揭示创伤小组**第三层身份**:

- 公开身份:私营战术救援公司
- 商业身份:富人保命合同提供方
- **隐藏身份:利用救护车优先通行权 + 不被检查权 + 武装跨城运输能力,
  暗中替黑市运毒 / 运义体 / 运芯片**

这种黑货生意的逻辑闭环:

- 救护车 / 空中医疗机享有**全城最高优先通行权**——
  NCPD 不会拦截、海关不会开箱
- 武装医疗组配枪+战术护甲——
  比帮派马仔安全得多
- "1 小时内送达"——
  比一切走私渠道都快
- 客户付钱 = 救命会员费的隐性增项,
  富人客户拿到的"额外服务"

与之前 [[定制急救服务]] 中"客户死亡可通过倒卖器官与植入体带来收入"
的指控形成闭环——
**创伤小组从抢救到尸体处理,整条链都是商品**。
活人是 VIP 服务,死人是器官来源,运输能力是黑货载体。

## 价格与公开批判

据《[[定制急救服务]]》：

- 2020 年起，民众已认同每月 **500 欧元**的创伤小组保费"价格合理"
- 私有化医疗在 [[公司统治]] 时代被视为"无替代方案"——文章作者讥讽："放屁。"
- 对照：太平洋彼岸的**俄联邦** 提供公共医疗——技术精湛医生 + 高精度纳米手术套件 + 现代浮空救护车，"不会逼任何人去公司里交买命钱"
- 该文核心指控：创伤小组**把投保人视为"有待治疗的潜在患者和有待交易的潜在产品"**——
  得救者是回头客；客户死亡可通过倒卖器官与植入体带来收入

## 世界观意义

创伤小组是 [[公司统治]] 时代医疗私有化的样本：

- "急救"在这个时代是商品——
  你有合同就能在交火中被空降救援，没合同你死在街上
- 与 [[NCPD]] / [[MaxTAC 暴恐机动队]] 同构——
  公共安全 / 公共医疗早已被职业化、私有化、阶级化
- 与 [[清道夫]] 互为镜像：
  创伤小组用枪保护客户的肉体不被拆，
  清道夫用枪把陌生人的肉体拆来卖——
  两端都把人体看作有合同的物
- "你的会员级别决定你今天能不能活到明天"——
  这是这家公司最诚实的广告语
- 南街区劫药事件揭示创伤小组的另一面：
  它不只是"私人化医疗的极致"——
  当公共医疗彻底失能，创伤小组的派送车成为
  **唯一可见的、装满救命药物的、从穷人头顶飞过的目标**——
  劫药因此从犯罪变成"看见即出手"的本能
