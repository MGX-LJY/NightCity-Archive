# 六街帮

## 类型

[[夜之城]] 帮派（6th Street）/ 退役军人 / 失业老兵聚合体

## 特征

- 穿着**军队制服、作战靴**，留小平头——容易被误认为是休假大兵
- 逮着机会就高喊"奥拉"作为帮派身份标识
- 实质是暴力、危险的混混——"杀你时眼皮子都不会眨一下"
- 主要据点：**丽景区**

## 武装升级：导弹发射车级别

六街帮的武装购物清单（参见 [[六街帮购物单]]）已达**城市恐袭级别**——

- **导弹发射车**（武装平台）
  - 强化车体装甲
  - 加大底盘
  - **GPS 制导火箭 2 组，每组 6 枚**
  - **最大射程：150 公里**
- 额外采购：4×6 带**高爆燃烧弹头**的火箭

供货方：EBM 体育场工厂线——
**拉塞尔·波拉** 接待 / **弗兰克·奥斯马尼** 来取货 / **查克·德门** 警卫
（参见 [[对话记录 弗兰克·奥斯马尼和拉塞尔·波拉]] +
[[对话记录 拉塞尔·波拉和查克·德门]]）

这一武装级别揭示：

- 六街帮已经从"街头帮派"升级为**准军事组织**
- 150 公里射程意味着可以从 [[夜之城]] 城外发射攻击城市目标
- 与"退役军人"身份完美契合——他们有人会用这种武器
- 这也部分解释了为什么 [[NCPD]] 私有化后犯罪率飙升时**没有人敢直接打六街帮**——
  对方的武器库已经能跟正规军平起平坐
- 而 [[狗镇]] EBM 体育场工厂是这种黑市武装的核心供应中心——
  [[汉森]] 默许下的工业级武器流通

## 毒品复仇链：迪恩·西蒙斯案

一条完整的"六街帮孩子被毒死 → 报复链启动"的样本：

- 毒贩 **迪恩·西蒙斯** 给六街帮的"那帮孩子"卖了一批本该干净的货
- 但货被人**做了手脚**——孩子们死了
- 六街帮认定迪恩是凶手 / 告密者，**追杀启动**
- 朋友"比尔"急促警告迪恩跑路：
  > "他们不可能就这么算了 / 你必须走 / 我认真的"
- 迪恩问"我还有家人呢"，比尔答"不用管他们，他们会没事的，我保证"——
  典型的安抚谎言
- 参见 [[对话记录 迪恩·西蒙斯和比尔]]

### 复仇链的下游：弗罗斯特·李案

但迪恩可能根本不是告密者——
另一组人物 **弗罗斯特·李 + 克里斯·詹姆斯** 透露真相：

- 弗罗斯特·李的几个人去抢"帮公司运货的"那批货
- 结果**被公司的军队埋伏 + 配备无人机**反伏击
- 是谁告诉他们去拿那批货的？——**迪恩·西蒙斯**
- 克里斯："你知道该怎么办"
- 参见 [[对话记录 福雷斯特·李和克里斯·詹姆斯]]

### 真相推断

- 迪恩可能是无意中**给两边都通风报信**——
  既告诉六街帮孩子们去拿这批货，也告诉弗罗斯特·李去抢公司军队的货
- 一个普通毒贩 / 中间人在多线之间踩雷
- 复仇队从六街帮和弗罗斯特·李两边同时来——
  迪恩"我还有家人呢"的求救，背景是**夜之城信息中转人的标准死法**

## 关联

- [[夜之城]] 丽景区——主要地盘

  目的是挑起两帮内战（参见 [[对话记录 冈田俊和千叶英子]]）

## 内部出卖样本

六街帮内部出现过**叛徒**——
一个成员把自己以前的兄弟出卖给中间人**高里一木**：
- 他出卖兄弟、还搭上"那么多尖货"以换取脱身
- 中间人按约定**送他上一艘去巴拿马的船**跑路
- 但中间人也警告："要当心他那些六街帮的兄弟们，估计会找过来"
（参见 [[对话记录 高里一木和小场次郎]]）

这一案例说明六街帮内部并不全是"军人荣誉"——
当退役老兵失去公司发薪渠道，
**出卖战友 + 偷运货物**也是一种生存方式。
"巴拿马跑路"成为夜之城叛徒的标准出路——
与流浪者部落的"投奔他邦"形成对比：
帮派叛徒不能投奔同行，只能远走他国。

## 被栽赃的样本：剃刀史蒂夫案

冈田俊 + 千叶英子两位夜之城中间人执行了一起精心设计的栽赃——

- 杀死 [[乱刀会]] / 夜游鬼成员"剃刀"史蒂夫·科瓦尔斯基
- 现场刻意做得像六街帮所为
- 目的：让夜游鬼"以为六街帮要开战"，挑起两家全面火拼

这暴露了六街帮一个结构性弱点——
作为"看起来像兵的混混"，他们的暴力风格容易被**别人模仿**；
任何其他帮派只要穿件旧军服动手，都能把锅扣给六街帮。
六街帮的身份标识（旧军服 / 平头 / "奥拉" 口号）
反而成了**最容易被栽赃的身份**——
这是 [[公司统治]] 时代退役军人帮派的额外代价。

## 世界观意义

六街帮是 [[公司战争]] 余波的人形载体：

- 当 [[新美利坚]] / [[军用科技]] 把退役军人扔回 [[夜之城]] 后，
  这些人没有合适的安置，也没人收编他们——
  于是他们自己穿着旧军服结成了帮派
- "看起来像兵，其实是混混"——
  这种身份混淆本身就是 [[公司战争]] 后军队边界模糊的样本
- 他们不像 [[动物帮]] 那样表演兽性，也不像 [[巫毒帮]] 那样追求灵性——
  他们只是把"军纪"变成"街头规则"
- 与 [[公司统治]] 时代的退役保障真空形成镜像：
  公司可以雇佣兵打仗，但不会负责他们之后的人生
