# 虎爪帮

## 类型

[[夜之城]] 帮派（Tyger Claws / 虎鉤衆）/ [[日本街]] 主导势力 /
**披着极道外皮的企业化黑帮**

本质定位:
- 表面是讲规矩、讲生意、讲秩序的日式极道
- 实际是 [[荒坂]] 的**外围白手套**——
  接收荒坂资金、武器、义体、情报与外包任务

## 历史起源

最初由 [[荒坂]] 扶植的**日裔保护帮派**——
- 早期形态:日裔社区治安组织 / 摩托暴走族 / 街区保护团体
- 演化方向:夜之城日式黑帮 → 企业代理人 → 地下资本势力

与其他帮派的对比:
- [[漩涡帮]] = 赛博疯子(纯暴力)
- [[巫毒帮]] = 黑客技术邪教
- [[瓦伦蒂诺帮]] = 拉美街头家族
- **虎爪帮** = 商业化、制度化、资本化的"企业打手"——
  本质上替企业处理"脏活"

## 地盘

主要控制区域:
- **[[日本街]]**(核心大本营)——
  夜生活中心 / 赌场 / 超梦馆 / 高级会所 / 性产业几乎全沾
- **歌舞伎区**(Kabuki)——闪闪生产线 + XBD 工业
- **沃森**部分区域
- **宪章山**——挖角对手的安置地段(参见 [[对话记录 塔妮娅和平八]])

定位:**经济型帮派霸权**——靠产业链而非地盘暴力立足

## 组织结构

虎爪帮采用**日本极道 / 山口组式**层级体系——
显著特征是**上下层断层**:

### 上层干部

- 谈生意、经营合法产业
- 控制赌场 / 超梦店 / 妓院
- 与公司合作
- 信条:**"战争不如赚钱"**

### 底层成员

- 暴力街头混混、嗑药疯子、人贩子、施虐狂
- 随机袭击路人 / 绑架 / 虐待 / 性暴力
- 高层都认为这类行为"有辱帮派"——
  揭示**虎爪帮内部已开始失控**:上层企业化越深,下层就越无序

## 收入来源

### 合法外壳

- 酒吧、餐厅、赌场、超梦店、夜店
- 用于洗钱与税务遮蔽

### 核心黑色业务

#### 1. 人口贩卖

- 性奴、强迫劳动、黑市人口
- 与下游性产业链直接整合

#### 2. 色情产业 / [[性偶]] 会所

- **[[性偶]] 会所** 的实际经营 / 抽成方
  (参见 [[性偶会所反馈]])
- 会所表面"老板"只是日常管理者,
  奖金加薪都需"向虎爪帮申请"——真正财务话语权在虎爪帮手中
- 与 [[扭扭街]] 一带的红灯产业链高度重叠

#### 3. 虐杀超梦(XBD)工业

绑架弱势人群 → 镜头前虐杀 → 录制黑超梦 → 卖给富豪买家——
完整产业链由 [[正法承太郎]] 担任"导演"角色

#### 4. [[闪闪]] 生产链

参见 [[武士虎爪帮警察三角订货链]] 与 [[闪闪]]:
- 采购规模:50 份 / 200 份 / 300 份按周翻倍——
  虎爪帮是夜之城闪闪市场**核心买家+生产者之一**
- 同时供应武士帮等友好帮派
- **童工招募**:系统性招募未成年人作为生产线工人
- **[[NCPD]] 打掩护**:直接付钱给警察购买生产线掩护权
- 原料走私链:与 [[军用科技]] 内部人合作偷码头货箱
  (参见 [[对话记录 羽田凉芽中尉和浅井和晴]])

#### 5. 企业脏活外包

[[荒坂]] 外包的暗杀、威胁、绑架、镇压

## 帮派挖角策略:策略性吸收对手中层

虎爪帮对其他帮派的中层人员有系统性的**挖角策略**——

样本:从 [[漩涡帮]] 挖走**塔妮娅**(参见 [[对话记录 塔妮娅和平八]]):

- **谈判人**:虎爪帮成员**平八**(出面接洽)
- 给的条件:
  - 钱"多到能换公寓的那种"
  - 在**宪章山**安排地盘
  - 一帮小弟带她在城里跑腿
  - **配保镖**(应对漩涡帮报复)
- 看中她的什么?——**人脉牵线**能力
- 平八的核心话术:
  > "**穿西装的我们拿下了,可他们的白痴小崽子们却还没有。
  >  这帮娃娃的市场潜力可不小**。"

揭示虎爪帮的**两层市场战略**:

- 上层市场("穿西装的"——公司高管 / 决策者):虎爪帮已经控制
- 下层市场("白痴小崽子们"——公司高管子女):正在用塔妮娅这类前敌人帮派的中层去渗透
- 后者是未来 10 年的"潜在客户"——他们父母现在掌权,他们以后掌权

漩涡帮反应:抓回 + 挖数据 + 处决示众([[对话记录 凯尔和莫莉]])——
塔妮娅最终下场可能很惨,但虎爪帮的挖角模式不会因此停止。

## 与 Mox 帮的世仇

核心事件:**[[利琪·薇兹|Lizzie]] 被虎爪帮杀害**

- 一名妓女被虎爪帮成员残忍虐杀
- Elizabeth "Lizzie" Borden 为复仇杀了几个虎爪成员
- 当晚她被虎爪帮报复杀死
- 后续:她的支持者成立 [[莫克斯帮]] —— 本质上是
  **"为对抗虎爪帮压迫而成立的组织"**

这条仇恨线决定了夜之城红灯产业的双线对立:
- 虎爪帮 = 性产业资本剥削方
- Mox = 性工作者自卫组织

## 世界观意义

虎爪帮是 [[公司统治]] 时代帮派与日本黑道传统结合的样本:

- **资本化黑帮**——已不再是传统街头帮派,而是企业外围组织 /
  半合法资本集团 / 夜之城灰色秩序维护者
- 与公司不同:他们不通过合同管理身体,而是通过债务和恩义
- 与 [[清道夫]]、[[动物帮]] 这种纯暴力 / 化学路线相比,
  虎爪帮更接近"传统黑帮"——讲规矩、讲层级、靠固定产业链稳定盈利
- **现实型的恶**:相比漩涡帮的赛博疯狂、巫毒帮的技术邪教,
  虎爪帮做的事(人口贩卖、性压迫、妓院控制、女性剥削)
  更接近现实黑帮——玩家代入感更强,反感也更深
- **白天与黑夜的统治分工**:
  - 企业(荒坂)在白天统治城市
  - 虎爪帮在夜晚统治欲望
  - 二者本质上是同一套权力体系的日夜双面
- **垂直整合的极端样本**:
  性偶会所(活人 → 性产品)→ XBD 工业(活人 → 死亡内容)——
  当前者的需求饱和,后者就是同一资源的下一轮变现
- 由 [[正法承太郎]] 担任 XBD 导演的事实证明:
  虎爪帮的"日式美学"不只是文化包装,
  它在产业实操层也用日式黑帮的**层级 + 仪式感**包装最极端的暴力
- **内部撕裂**:上层企业化 vs 下层暴虐化的张力,
  揭示资本化黑帮的内生矛盾——
  当核心人物追求"赚钱"时,他们对底层的暴力已经失去管理意愿
