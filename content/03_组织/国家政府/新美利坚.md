# 新美利坚

> 英文原名：**New United States of America（NUSA）**
> 旧称:美利坚合众国(United States of America)的合法继承者
> 体制特征:军政融合制 / [[军用科技]] 一体化国家 /
> 总统集权制 / 联邦情报局(FIA)国家
> 正式建立:2053 年,由 [[伊丽莎白·克雷斯]] 总统主导重组
> 2077 年现任总统:[[罗莎琳德·迈尔斯]]

## 类型

后公司战争时代的美国残余政治体 /
**[[军用科技]] 扶持下的军事联邦国家** /
[[公司统治]] 时代"国家"形态的样本。

要点:

- 名义上是"美国唯一合法继承者"
- 实际上是 [[军用科技]] 借国家壳运行其战略意志的载体
- 与现实中"美国是企业的国家"不同——
  2077 的 NUSA 更接近**"军工集团的国家"**

## 核心业务

- **国家级军备 / 军工**——通过 [[军用科技]] 实现全国国有化军工链
- **联邦执法 / 国家情报**——以 联邦情报局(FIA) 为核心,
  统一原 CIA / NSA / 特种作战司令部式职能
- **领土统一战争**——以"重新统一美国"为长期国策,
  对 自由州(Free States) 持续施压
- **太空主权宣示**——在 [[月球]] 多个殖民地公共设施飘扬 NUSA 国旗
- **跨国黑色行动**——以"非法但合法"的方式执行国家利益,
  典型即 [[荒坂塔袭击事件]]
- **边境物理化**——在国内与"自由州"之间筑墙(如 [[加利福尼亚墙]])

## 国家历史

### 旧美国之死(1990 年代-2020 年代)

要理解 NUSA,必须先理解旧美国的死亡。

旧美利坚连环灾难:

- **经济崩溃**——股市崩盘 / 银行体系崩溃 / 失业率暴涨
- **企业战争**——[[荒坂]] / [[军用科技]] / 生物动力(Biotechnica) / 生物技术(Biotechnica 系)
  陆续建立私人军队,资本已比州政府强大
- **中美洲战争**——美国为控制资源介入,
  财政赤字 / 社会动荡 / 大量退伍军人失业;
  参见 [[拉美战争]] 链条
- **流浪者危机**——数百万农民失去土地,
  形成后来著名的 **游牧民家族(Nomad Nations)**——
  即 [[流浪者七大邦]],包括 [[阿德卡多]]、蛇族、[[梅塔集团|梅塔家族]] 等

### 自由州运动(2030 年代起)

进入 30 年代后,大量州判定"华盛顿已失去统治能力",
开始脱离联邦,形成**自由州(Free States)**。

著名自由州:

- **北加州自由州**——首府 萨克拉门托
- **南加州自由州**——含 洛杉矶 / 圣地亚哥
- **德州**——事实上接近独立国家
- **亚利桑那**——拥有极高自治权

后果:**美国从 50 州联邦国家,逐渐变成多个自治政治实体**。
这是 NUSA 终其一生想要逆转的状态。

### 战后奠基(2024–2045 动荡期)

参见 《[[战后的美国]]》——

- **[[第四次公司战争]] 末尾**,**[[伊丽莎白·克雷斯]] 总统**为了建立联邦政府的相对秩序,
  对 NUS 成员州**实施军事管制**,并将国内武器制造业巨头 [[军用科技]] **转为国有**
- 由于持续处理国内动荡,多数欧洲国家和日本**并没有关注北美的事态发展**——
  这给了 NUSA 一个对外封闭的窗口期来稳住自身
- **2024–2045 年是公开档案中明确的"动荡期"**
- 同期 21 世纪 40 年代,[[网络监察]] 建造 [[黑墙]]——
  NUSA 的国土秩序与全球网络秩序在同一时段被重塑

### 2053 NUSA 正式建立

克雷斯路线的最终成果:

- **2053**——正式建立 **新美利坚合众国**,
  宣布自己是美国唯一合法继承者
- 制度核心:紧急状态常态化 / 强化总统权力 / 扩大军队规模 /
  与 [[军用科技]] 深度合作
- 自此 **"美国"** 这个名字保留下来,但内核已经被改写为军政融合体

### 罗莎琳德·迈尔斯路线

参见 [[罗莎琳德·迈尔斯]]——

- 出身 [[军用科技]] 高层,后进入政府,最终在 2070 年代任 NUSA 总统
- 唯一政治目标:**重新统一美国**——
  自由州的存在被其视为"国家耻辱"
- 她的总统任期是 [[军用科技]] 与 NUSA 之间**界限最模糊**的时期

### 统一战争(2069-2070)

NUSA 在 2077 之前最大的战争。

战争目标:收回 北加州 / 南加州 / [[夜之城]] / 其他自由州。

战争主力:NUSA 军队 / [[军用科技]] 军团 / 联邦特种部队。

战争进程:

1. 开战阶段非常顺利,多个自由州被迫妥协
2. **夜之城问题出现**——夜之城面临"投降 NUSA"或"请求 [[荒坂]] 介入"二选一
3. 夜之城选择 [[荒坂]],
   原因极简单——**企业不喜欢 NUSA**,
   因为 NUSA 要限制企业权力
4. [[荒坂]] 派出舰队 / 特种部队 / 安保力量进驻夜之城
5. 迈尔斯判断:若继续打,极可能直接升级为 **第二次公司战争**——
   于是停战

### 统一条约(Treaty of Unification)

统一战争的政治结晶,
**2077 年地图格局的法律基础**。

主要条款:

- 夜之城保持独立(成为 [[夜之城|自由市]] 而不归属任何州)
- 自由州保留自治
- NUSA 停止进攻
- [[荒坂]] 撤出部分军事力量

意义:这是 NUSA "重新统一美国"叙事的**正式破产证书**,
也是 [[荒坂]] 在北美最后一次以"国家级玩家"姿态登场。

## 已知活动 / 深度档案

### 月球主权(参见 [[第谷 旅游行程]])

- 月面殖民地多个公共设施前飘扬"新美利坚国旗"
- 但日常经济(葡萄园、SPA、矿场)由旅游业接管
- 名义主权 vs 实际治理脱节

### 海军作战

- 在 [[第四次公司战争]] 中,新美利坚 / [[军用科技]] 的船队对抗 [[荒坂]] / 自由州海军
- 荒坂部署 AI 控制的自动鱼雷反制
- AI 鱼雷敌我不分("既然挂着友军旗帜的船上也可能存在敌军")——海运因此被彻底瘫痪

### 国家黑色行动

- [[荒坂塔袭击事件]] 的真实主导方:[[军用科技]] + 美国(新美利坚)政府的联合"非法黑色行动"
- 真实目标:摧毁 [[荒坂]] 数据基础设施 + 夺取 [[灵魂杀手]]
- 公开叙事:将责任推给"第三方恐怖分子"
- 调查委员会最终裁定 [[荒坂]] 有罪——新美利坚成功转嫁了核打击的政治成本

### 南北边境的物理隔离

- 在南北加利福尼亚之间建造 **[[加利福尼亚墙]]**
- 名义功能:"保证自由和安全"——阻挡流浪者、非法移民、暴力罪犯
- 实际功能:永久军事化提醒 + 海关 + 监控节点
- 守墙工程被外包给 [[军用科技]]——
  这是 NUSA 与公司一体化的最具象化形态

### 与军用科技的体制融合

2077 时期,[[军用科技]] 已不是普通企业,
而更像:**国家军工体系 + 国家军队 + 国家情报部门 的三合一**。

- 很多总统来自 [[军用科技]](包括迈尔斯本人)
- 很多军官来自 [[军用科技]]
- 很多装备来自 [[军用科技]]
- 很多战争由 [[军用科技]] 策划

学界共识:

```text
名义上:NUSA 控制军用科技
实际上:军用科技影响 NUSA
```

这是 NUSA 与 [[荒坂]] 在"公司-国家"问题上的镜像:
[[荒坂]] 是"公司假装成家族",NUSA 是"国家被改装为公司"。

### 联邦情报局(FIA)

- 全称:Federal Intelligence Agency
- 职能合并:CIA + NSA + 特种作战司令部
- 行动风格:**高度黑色化 / 反 [[黑墙]] / 跨国潜伏**
- 核心人物:[[所罗门·李德]] / [[百灵鸟]] / [[艾利克斯·谢纳基斯]]
- 战略重点之一:**夺取与 [[黑墙]] 相关的战略资产**——
  [[百灵鸟]] 即典型例子

### NUSA 为什么想要夜之城

迈尔斯不是因为"面子"才执着于夜之城,
而是因为 [[夜之城]] 的资产组合本身就是西海岸经济命脉:

- **北美最大港口之一**——海运咽喉
- **太平洋贸易中心**——东亚 / 太平洋金融枢纽
- **[[轨道航空]] 发射基地**——上行轨道的少数节点
- **企业总部聚集区**——超级企业的事实立法权所在地
- **[[水晶宫]] 航线节点**——通往轨道城市的接口

拿下夜之城 = 重新控制西海岸经济命脉。

### NUSA 的结构性问题

虽然官方宣传"恢复美国荣光",但 2077 现实暗面:

- **企业影响过大**——[[军用科技]] 权力超出宪法控制
- **总统权力集中**——远超历史上美利坚总统的权限
- **情报机构扩张**——FIA 拥有极高权限,几乎不受外部审查
- **自由州不服从**——很多地区只是名义上承认 NUSA
- **从未真正统一全国**——这是迈尔斯最大的政治失败

2077 NUSA 的权力结构:


### 流浪者的国家级起源

参见 《[[战后的美国]]》——

- 早在 20 世纪 90 年代,公司就已开始**积极向农民购买大片耕地**,部分人被迫卖地
- 这些失地农户**彼此团结,组成"族群"**,四处迁移寻找可靠工作,**专门承接运输工作**
- 战火停息后,他们的车队成了**唯一可靠安全的州际运输手段**
- 也就是说:**[[流浪者七大邦]] 阶层不是文化浪漫,而是 NUSA 战后物流真空被失地农民填补的结果**

## 世界观意义

新美利坚是 [[公司统治]] 时代"国家"形态的样本:

- 国家与公司的边界几近消失——
  美国政府的"非法黑色行动"可以由 [[军用科技]] 执行,
  公司战争与国家战争已无法区分
- 主权的去向:能在月面挂国旗、能在海上派军舰、能在荒坂塔投核弹——
  但这些行为里没有一件真正服务于公民
- 与 [[荒坂]] 这种"家族 + 公司"形态形成镜像:
  荒坂是"公司假装成家族",新美利坚是"国家假装成公司"
- 它的存在本身证明 [[公司统治]] 不是"公司取代国家",
  而是"公司形态吞噬国家形态"——
  国家名字保留下来,国家功能被改写
- **2077 三方权力一句话总结**:

  > [[荒坂]] 想用企业统治世界;
  > [[军用科技]] 想用国家统治世界;
  > 而 NUSA,则是 [[军用科技]] 实现这一目标最重要的工具。

- **统一战争的真正教训**:
  当一个"国家"必须依靠一家公司去打一场内战,
  并且最终还是要靠另一家公司来终结——
  那么这个国家是不是真的还存在,本身就是开放问题
- NUSA 与 [[欧洲航天局]] 的对照同样关键:
  欧航局是"国际机构在公司时代被绕过",
  NUSA 是"国家机构在公司时代被吃掉"——
  两条曲线都通向同一个结论:**公司时代不再需要主权,只需要承包商**
