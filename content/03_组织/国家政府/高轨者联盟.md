# 高轨者联盟

> 英文原名：**Highrider Confederation**

## 类型

太空殖民政治联盟 / [[月球]] 真正的实际主人之一 /
脱离 [[欧洲航天局]] 控制的轨道居民集合

## 核心业务

- **轨道治理**——为太空工人、轨道殖民者、空间站居民提供独立的政治架构
- **地月生活体系**——衣食住行、生产生活完全脱离地球-公司链条
- **对抗 [[欧洲航天局]] 控制**——将原本由欧洲航天局垄断的轨道资产转入联盟实际控制

## 已知活动 / 深度档案

### 成员构成

- **太空工人**——奥尼尔站建造者与运营者,起义后掌握自治权
- **轨道殖民者**——长期居住在轨道空间站的居民
- **空间站居民**——分散在各级轨道飞地的人口

这是一个**没有地球公民身份的政治体**——
对联盟成员而言,地球只是"老家",真正的家园是轨道。

### 与 [[欧洲航天局]] 的脱离

- [[欧洲航天局]] 是奥尼尔等多座空间站的原始出资方
- 但建造完成后,管理层强加 18 小时工作日 + 全天候劳役
- 2022 起义后,工人在 **7 小时**内控制了 OD1 / OD2
- 此后欧洲航天局对轨道殖民地的实际控制不断削弱,
  最终演化为**高轨者联盟**这一独立政治体

### 在 2077 的真实地位

- [[月球]] **名义统治者** = [[欧洲航天局]]
- [[月球]] **实际影响力** = 高轨者联盟
- 整个轨道层的日常运作 + 资源调配 + 人口治理,
  事实上由联盟在主导

### 与超级企业的关系

- 联盟没有自己的工厂或舰队级武力
- 因此对 [[荒坂]] / [[军用科技]] / [[康陶]] 等超级企业上月持**谨慎合作**态度
- [[荒坂]] 在月球秘密建 [[质量投射器]] 时,
  联盟与 [[欧洲航天局]] 都没有第一时间发现——
  说明它对企业级行动的监察能力有限

## 世界观意义

高轨者联盟是 [[公司统治]] 时代**"被遗忘的成功反抗"**的延续:

- 与 [[奥尼尔空间站的抗争]] 互为因果——
  起义夺权是起点,联盟治理是延续
- 它的存在证明 [[公司统治]] **并非全球覆盖**:
  在物理距离足够远 + 基础设施足够独立的地方,
  公司的控制链条会断
- 与 [[阿德卡多]] 形成对照:
  - [[阿德卡多]]:逃离公司体制,在 [[恶土]] 求生
  - 高轨者联盟:不仅逃离,而且**接管了一整套基础设施**继续运行
  - 后者是更彻底的"另一条路"
- 与 [[水晶宫]] 的"消费的飞地"形成镜像:
  - 水晶宫:富人上太空享乐,公司统治的延伸
  - 高轨者联盟:工人上太空建国,公司统治的反面
  - 同一个轨道层被切成"穷飞地"和"富飞地"——
    但讽刺的是,联盟的"穷飞地"在政治上反而更自由
