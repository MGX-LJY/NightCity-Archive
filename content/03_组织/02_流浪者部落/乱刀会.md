# 乱刀会

## 类型

[[流浪者七大邦]] **永久驱逐**的亡命徒与强盗联盟（Raffen Shiv）

## 关键判定

**乱刀会绝对不属于流浪者七大邦。**

- 他们是因严重违反**流浪者道德律令**、被七大邦永远驱逐并剥夺身份的人
- 七大邦视他们为**耻辱**
- 双方一见面往往是**不死不休的火拼**
- 这与"七大邦内部分歧"完全不同——
  乱刀会是流浪者体系的**对立面**，不是内部派系

## 已知分支

- **夜游鬼**（Wraiths）——在恶土活跃的乱刀会派系
  - 经常袭击 [[阿德卡多]] 的营地和商队
  - 是 [[V]] 与 [[帕南·帕尔默]] 在恶土的主要敌人之一
  - 已知成员："**剃刀**" 史蒂夫·科瓦尔斯基——
    被神秘中间人 **冈田俊**+**千叶英子** 派人**残忍杀害并栽赃 [[六街帮]]**，
    目的是挑起夜游鬼 + 六街帮全面开战（"两虎争食"+"狐假虎威"）。
    （参见 [[对话记录 冈田俊和千叶英子]] + [[对话记录 千叶英子和冈田俊]]）
    这一案例表明：**乱刀会 / 夜游鬼也会被夜之城中间人操控以制造帮派内战**——
    他们不只是无组织的暴徒，也是别人棋局中的棋子

## 把人当工具的样本：阿德卡多"人肉探测器"

参见 [[对话记录 乱刀牛B 和死_是乱刀鬼]]——

两名乱刀会成员讨论一个被绑的 [[阿德卡多]] 俘虏：

- 俘虏"根本不肯开口"——审问失败
- 死_是乱刀鬼提议利用街头传说："**听说阿德卡多的人不管多深都能找到水**"
- 操作方案：把俘虏绑车前 → 让他自己挖 → 既验证传说也省事
- "**不是，让他来挖，省得他要什么花招**"——决定让俘虏拿铲子下场

关键观察：

- 乱刀会把 [[阿德卡多]] 的传说能力（探水）当作**可压榨的功能特征**——
  人本身被降级为"探测器"
- 把活人**拖在车前**绑去恶土是日常操作语气，没有任何犹豫
- 反向印证 [[阿德卡多]] 在街头神话中的地位——
  "找水的能力"被视为**几乎超自然的部族特技**
- 乱刀会自我评价："**反正他们都那么说，我们正好试试真假**"——
  人命被消耗以验证一个城市传说
- 与 [[乱刀会]] 对 [[阿德卡多]] 商队的常态袭击形成**质性补充**：
  不只是抢劫，也包括**绑架活人作为消耗品**——
  与 [[公司统治]] 时代对人体的"功能化"是同一种逻辑的底层街头版本

## 夜游鬼的恶土走私战争

夜游鬼不只是袭击 [[阿德卡多]] 商队的强盗——他们也是 [[恶土]] 上一张成规模的**跨境走私网**，并因此在 2077 年成为 [[军用科技]] 恶土清剿的头号猎物（详见 [[军用科技]]「恶土军事化与边境清剿」一节）。

**走私生意**

- 跨 **南加利福尼亚** 边境走私 CHOOH2、义体与人口，并收买军用科技内部员工供货——技术员史蒂夫·哈灵顿侵吞 CHOOH2 转卖夜游鬼，被夜之城上诉法庭处决（[[需清除的目标]]）
- 替 [[漩涡帮]] 等帮派承接"把义体医生偷渡过境"的单子
- 靠沙尘暴掩护穿越边境，必须黑入军用科技天气系统才能预测沙暴；军用科技升级后锁死权限，夜游鬼黑客只得爬上风力涡轮机重新黑入（[[对话记录 哈里·沙利文和吉姆·杰罗尼莫]]、[[报告 立刻阅读情况不妙]]）

**反无人机战术**

- 用自制天线 +"病毒鸡尾酒"把军用科技 / 南加州无人机从天上拽下来——"砰地一下就从天上掉下来，就跟打鸟似的"，黑客头目"约翰"是这套天线的内行（[[对话记录 克里斯·派克和巴里·奥内尔]]）

**内部生态**

- 强迫义体医生免费修车，否则灭门——连"我们的人杀了他儿子"也照逼不误（[[对话记录 费伊·鲍尔萨姆和伯特·罗林斯]]）
- 自带无证医生鲁弗斯·麦克布赖德（曾致三人永久伤残、伪造自杀案），混在夜游鬼中行医（[[对话记录 西蒙·迪亚斯和鲁弗斯·麦克布赖德]]）
- 走私客死于军用科技伏击时，靠同伴远程"陪聊"撑到断气（[[对话记录 埃迪·基特和吉尔伯特·帕达尔]]）；也有浮空车中弹坠毁却侥幸生还、捡回大半货的（[[对话记录 迈克尔·马尔辛科夫斯基和马利·安德森]]）

被军用科技与 NCPD 双重通缉——[[消息 NCPD 调度员悬赏通缉]] 中，布鲁斯·沃德、保罗·克雷文、鲁弗斯·麦克布赖德等多名"夜游鬼帮派"成员被列入全城悬赏。

## 核心标记

- **无道德底线**——不遵守流浪者间通行的礼节、不接待客、不护族
- **被剥夺族名**——任何七大邦的家族都不会再认他们
- **永远的暴力关系**——加入乱刀会意味着所有流浪者都会与你为敌

## 世界观意义

乱刀会是 [[公司统治]] 时代"反抗者也有反抗者"的样本：

- 七大邦是公司体系的对立面——
  乱刀会则是七大邦的对立面
- 这一二级对立结构破除了一个简单图式：
  "反公司 = 善"或者"公路上的人 = 自由战士"
- 流浪者体系**主动驱逐**乱刀会——
  说明这个体系不是无原则的"自由人聚集"，
  而是建立在严格的**家族 / 互助 / 道德律令**之上的组织化群体
- "永久驱逐"作为一种制度——
  比公司的雇佣合约更具人格惩罚力：
  你不只是失业，你**失去了所有可以投奔的人**
- 也正因如此，乱刀会变成最危险的存在——
  他们没有任何退路，唯一能做的就是更加暴力
