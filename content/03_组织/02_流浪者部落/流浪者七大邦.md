# 流浪者七大邦

## 类型

北美大陆规模最大、最具政治和军事影响力的七个超级流浪者联盟（Seven Nations）

## 起源

**大崩溃**（The Collapse）之后——
数以百万计因 [[公司统治]] 迫害与自然灾害背井离乡的人们在公路上联合起来，
逐渐形成七个超级联盟。

## 流浪者社会结构（自上而下）

```
邦（Nation）
  └── 部族（Tribe）
        └── 氏族（Clan）
              └── 家族（Family）
```

七个大邦的**总人口超过 400 万**——每一个大邦都由无数个子部族组成。

## 城市视角的认知偏差

参见 [[顽强的流浪者]]（夜之城本地传单）——

这份匿名的"城市人入门指南"显示，
**夜之城主流媒体对流浪者的描述几乎全是胡编乱造**：

- 最常见的错误："流浪者是一种职业"——
  作者直接否定："不对。**流浪者是一种生活方式**"
- 部族识别：可以通过**甩色、夹克、车子、摩托的贴花**判断对方的邦 / 部族 / 家族
- 强调**部族归属感极强**——"流浪者十分看重这种归属，
  所以除非你的下巴不想要了，否则我建议你也尊重他们的风俗"
- 正本清源 [[乱刀会]] 与七大邦的区别（详见 [[乱刀会]] 节点）
- 七大邦"什么工作都干"，具体业务由部族 / 家族方针决定：
  - 农业公司田里采收
  - 公司货物处理 / 运输队保护
  - **边境走私**——"如果你想往边境另一头走私点东西，去找流浪者"
  - **跑路藏身**——"流浪者会把你带到穷乡僻壤的地方，
    让你拉屎的时候逗蝎子玩"
  - 交易模式："你付钱，他们干活，买卖做完，就各奔东西"

这份传单证明：
- 七大邦在夜之城本地舆论场里**长期被城市叙事曲解**——
  需要专门的反主流传单来"科普"
- 真正知道流浪者怎么活的人，
  在城市里属于**自费做信息纠偏**的少数派
- 夜之城对流浪者的认知不是无知，而是**被城市媒体加工过的偏见**——
  与 [[公司统治]] 时代"反公司经济"被系统性贬低的舆论结构一致

## 与公司体系的对立

七大邦不只是"在公路上生活的人"，而是 [[公司统治]] 时代少数：

- 不依赖城市基础设施
- 不签公司合同
- 不进公司公寓
- 通过部落 + 家族网络维持自给

的群体。

它们的存在使"反公司"在 [[公司统治]] 时代不只是政治宣言——
而是一套**可运行的物质生存方式**。

## 世界观意义

七大邦揭示 [[公司统治]] 时代的**对立结构**：

- 公司组织人——靠合同 / 工资 / 公寓
- 七大邦组织人——靠**家庭 / 道德律令 / 互助协议**
- 公司战争 + 大崩溃使"公司"失去了道德合法性，
  但同时也使七大邦获得了道德高地：
  他们不是回到部落，而是**用部落的形式回应公司的失败**
- 七大邦内部的差异（农业 / 海运 / 娱乐 / 工程 / 武装护卫）
  说明**反公司经济也可以分化**——
  你可以不进城，但你仍然要决定自己卖什么
- "**永久驱逐**"的存在（[[乱刀会]]）证明：
  在最自由的群体里，仍然需要明确的边界——
  没有规则的群体不会自由，它会被最暴力的人接管
