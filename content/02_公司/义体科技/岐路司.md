# 岐路司

> 英文原名：**Kiroshi**（Kiroshi Opticals / Matsushima-Kiroshi Optics）
> 别名：岐路司集团（The Kiroshi Group）
> 总部：日本长野县上诹访（Kamisuwa, Nagano）/ 创始人：松岛一树
> 控股方：藤原家族 / 员工：约 24,759（2020）

## 类型

源自日本长野山区的**光学植入体头部品牌** /
全球公认的**光学义体头号专家** /
由"岐路司综合赛博"与"岐路司光学"两家公司组成的**岐路司集团**(光学占绝大部分业务)

## 核心业务

- **光学植入体**——
  从基础视觉增强到军用扫描功能的全系产品
- **赛博眼**——夜之城几乎所有雇佣兵 / 军人 / 公司打手的标配
- 与 [[刃]] 公司是**长期合作伙伴**——
  双方在 [[西谷区]] 的**岐路司园区**共建展厅
- "资格需要争取"的客户筛选式销售机制
- 大力投资亚洲与美洲的**轨道项目**,2077 时多数制造在轨道站完成

## 公司历史

- 前身是长野县上诹访的一家**钟表制造商**"Kiro-shiya",1980 年代起扩张
- **2013 年**更名"Kiroshi"(岐路司);借助 JAB 与 Kenjiri 科技建成**轨道工厂**获得最大跃升
- 凭轨道制造的赛博眼及 Optishield、光学 HUD、远程赛博摄像头、防眩光 Opti-Flash 等产品**垄断光学义体市场**
- 与 Kenjiri 长期紧密合作,在轨道共设设计公司以贴近制造
- **四次公司战争**期间与欧洲**蔡司(Zeiss)公司**短暂交火,战后签和约划分势力范围——但此后长期处于**冷战**:互相刺探、甚至可能破坏对方项目
- 2077 时宣布研发**四色视觉(tetrachromatic)义眼**,声称能拓宽可见光谱

## 代表人物

- 松岛一树（Matsushima Ikki）——创始人
- 若本典子（Wakamoto Noriko）——业务经理(常以"亲自试用新品"示人)
- 藤原家族——公司控股方
- [[V]]——装备 Kiroshi 光学植入体的代表性客户（可读取数据、夜视、扫描敌人）

## 关联科技 / 产品

- Kiroshi 全系赛博眼——基础视觉增强到军用扫描
- 岐路司机器人代理——通过 Kiroshi 光学植入体远程操控,客户用以进入 [[刃]] 专属展厅

## 关键事件

- 被 [[天光]] 攻破——客户资料与产品技术数据失窃,与 [[泽塔科技]] / [[生物技术]] 同期被攻

## 已知活动 / 深度档案

### 园区与展厅（夜之城分部）

- 总部在日本长野;[[夜之城]] 仅为其分部之一,园区/展厅位于威斯特布鲁克 / [[日本街]] 区
- 性质:不直接零售,**资格需要争取**——
  顶级义体准入的现实门槛

### 名人营销与名字双关

- 岐路司是精明的营销者,长期签约名人/流行艺人打广告——
  最大手笔之一是签下日本偶像团体 **Us Cracks**(以古怪独特的义眼造型闻名)
- 名字趣闻:"Kiroshi"与日语"过劳死"(Karōshi,過労死)仅一字之差;
  也近似"着る視"(可穿戴之眼)——旧名"Kiro-shiya"则近似"着る視野"(可穿戴的视野)
- 通过岐路司园区展示 [[刃]] 公司的经典车型(草薙 CT-3X / 和平卫士 / 村正 ASM-R250)

### 被天光攻破

参见 [[天光]]:

- 天光攻破岐路司数据库,获取其客户资料与产品技术数据
- 岐路司作为 [[刃]] 公司的合作伙伴,被攻破意味着:
  顶端客户的身份与购买记录全部外泄
- 这是 [[泽塔科技]] / 沛卓石化 / [[生物技术]] 数据连锁失窃的一环

### 家族铁腕与防火长城：内部忠诚管理

[[对话记录 伊藤沙都子和伊藤旭雄]] 与 [[对话记录 伊藤沙都子杀子事件]] 以双视角还原同一事件：岐路司高管伊藤沙都子以母亲身份给离叛的儿子发去小女儿的照片，实则植入追踪文件，待儿子下载后立刻锁定坐标，随即通知干部荒木——"弄死。他是叛徒，是岐路司的敌人。"当被问起"你儿子怎么样"，她答："他不再是我的儿子了。他把我们的数据出卖给了竞争对手。"亲情话语不过是诱饵，组织忠诚凌驾于血缘之上。

外部渗透同样无从得手：[[对话记录 时代思潮和豪尔赫]] 记录雇佣黑客"时代思潮"的抱怨——"低估了岐路司""没法从外部破解""得靠近点连上本地子网"，必须物理直连才能渗透，导致价码临时翻番。这与 [[天光]] 被迫用物理接触突破其他公司的手法如出一辙，印证岐路司的信息防御足以将多数远程入侵拒之门外。

### 董事失势：塔克·阿尔巴赫毁证案

[[塔克·阿尔巴赫的收件箱]] 与 [[对话记录 纳西姆·珀尔曼和塔克·阿尔巴赫]]、[[对话记录 纳西姆·珀尔曼和奥尔多·施罗德]] 三份档案串起岐路司光学一名董事的丑闻与失势：

- 董事 **塔克·阿尔巴赫** 的母亲醉驾肇事，后备箱里还放着一沓**公司机密文件**——足以给岐路司"惹上非常大的麻烦"
- 塔克为掩盖，命中间人 **纳西姆·珀尔曼** 把肇事车辆"绝对认不出来"地销毁灭证（纳西姆办事麻利、深得其欢心）；而纳西姆的上司却建议**偷偷留下毁车证据作为日后把柄**
- 事情仍捅到高层。CEO **雅各布·兰** 直接去信把塔克**踢出董事会**、降职为专家经理，并取消其安保计划、[[创伤小组]] 白金套餐、公司公寓等董事待遇，撂话"我就应该炒了你，甚至让你消失……但我决定再给你一次机会"
- 失势的连锁反应：宿敌 **亨特·麦克弗森** 趁机补上空出的董事席位、发来嘲讽"谢谢你把我抬上去"；保险公司（资产保障有限公司）告知"即时响应"增援仅限**董事会成员**专享，塔克的宅邸不再受额外保护；塔克本人也正卷入与某人（马隆·富西诺）的报警纠纷

此案是岐路司"家族 / 董事会铁腕"的另一面写照：对**叛徒儿子**是亲令处决，对**捅娄子的董事**则是即时剥夺一切特权、令其"消失"只在一念之间——身份与待遇全系于董事席位，一旦失去庇护，连私人安保都即刻断供。

## 世界观意义

岐路司是 [[公司统治]] 时代**"科技公司商品化"**的中端样本:

- 与 [[刃]] 的"武术与企业仇杀"叙事不同,
  岐路司纯粹是**赚钱的光学技术供应商**——
  没有道德立场,只有市场份额
- 但其**"资格需要争取"**的购买机制证明:
  顶级义体本质上是**身份商品**而非工具——
  谁能装备 Kiroshi,谁就是夜之城精英
- "光学植入体"是夜之城的**信息特权**——
  普通人看到的是城市,装了 Kiroshi 的人看到的是数据流——
  这是 [[公司统治]] 时代"信息阶层"的物质载体
- 被 [[天光]] 攻破暴露了一个悖论:
  你卖给客户的"视觉特权",最终成为你自己的安全漏洞——
  客户的视觉数据反过来变成攻击你的入口
- 岐路司的家族式管控揭示 [[公司统治]] 的极端形态：当公司利益与血缘共情冲突，高管选择把亲情当武器而非庇护——"光学之神"的内部秩序比任何防火墙都更冷酷
- 防火墙迫使黑客物理直连的设计，与其"资格需要争取"的销售哲学呼应：岐路司始终把**接入门槛**视为核心竞争力，无论客户端还是安全端
