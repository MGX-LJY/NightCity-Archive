# 泽塔科技

> 英文原名：**Zetatech**
> 总部：北加州库比蒂诺(硅谷) / 口号："Think ahead"(想在前面)
> 领导：鲍勃·罗斯蒙特 / 员工：约 12,000 / 子公司：鹰科技(Eagletech)

## 类型

[[义体]] / 计算机软硬件 / 湿件(wetware) / 航空与运输研发公司 / 2077 势力增长极快的科技公司
- 起家于库比蒂诺的小公司,靠间谍与"有的放矢的暴力"挤进行业
- 神经处理器、微芯片、机器人的美国主要供应商之一;后扩张为航空载具与航运巨头

## 核心业务

- **神经协同处理器**——意识层运算芯片
- **斯安威斯坦**（Sandevistan）——招牌反射加速义体,
  让用户在战斗中以慢动作感知世界,
  夜之城雇佣兵与杀手的主流选择
- **疼痛编辑器**——疼痛抑制类植入体（用户死亡率超 60% 的隐性问题件）
- **军用无人机 / 飞行器**——航空载具(aerodyne)、侦察 / 战斗 / 工具型无人机,被各大超企广泛使用
- **航运**——2077 时已是重要的航运企业
- **战术设备**——夜之城战斗者的技术供应商之一

## 公司历史

- 起家于加州库比蒂诺的高科技小公司,靠传统手段(间谍 + 暴力)在巨头夹缝中切出一块市场
- **第一次公司战争**:与 [[轨道航空]] 结盟,对欧洲商业机器(EBM)发动大规模网络攻击,被 EBM 击退,2004 年 10 月出局
- **四次公司战争后**:趁对手衰败大举承接重建期政府合同,以平价 3D 打印机与 Agent(智能助手,产量超越 Segotari)成为家喻户晓的品牌,并切入运输业、生产经济耐用的飞行器
- **2076**:从最小的超企之一持续扩张到航空、AV、无人机、机器人;对所有超企与各国政府保持中立,导致其产品同时出现在战场两侧
- **2077**:义体与空中运输的世界领导者,旗舰飞行器 Atlus(供 [[创伤小组]] 与 [[新闻54台]])、Surveyor(供 [[康陶]] 与 [[MaxTAC 暴恐机动队]]),以及 Sigma K.54 赛博臂
- **2079(《往日之影》结局后)**:实现北美市场 **80%+ 垄断**,并**宣称用革命性免疫增强技术(ImmunoAid Plus)彻底消除了赛博精神病**;据《夜之城询问者》,这份霸权来自持续的秘密测试与同城市高层的私下协议

### 主要产品线（义体黑医通用记录）

通过夜之城地下义体医生的患者档案可证实泽塔科技的实际产品分布——

#### 内部脏器植入体
- **IO-3 肾脏植入体**：合成肾，可调整透析强度
  - 副作用：通过 [[岐路司]] 传输数据负荷较高，
    神经退化患者可能无法跟上处理速度
  - 患者样本：费奥多尔·德米特里耶夫（36 岁，肾脏受损 + 慢性创伤性脑病变）
  - 参见 [[患者资料 费奥多尔·德米特里耶夫]]

#### 第二代手臂植入体
- 在底层市场流通的版本——**山寨货**比正版更常见：
  > "第二代手臂植入体，**泽塔科技的山寨货** - 要进行校准"
  - 山寨货需要黑医额外校准 + 视觉皮质支持 + 内存升级
  - 患者样本：米沙·索罗金（25 岁，身体健康）
  - 参见 [[患者资料 米沙·索罗金]]
- 山寨货流通暗示：
  - 泽塔科技在底层市场的销量被仿冒大量蚕食
  - 黑医靠"修山寨"成为泽塔产品供应链下游的一环——
    公司想堵也堵不住，因为最终是黑医在帮山寨货续命

### 疼痛编辑器研究

参见 [[疼痛编辑器和死亡率]]

- 内部研究承认：自 2020 年起，疼痛编辑器所有者的死亡率超 60%
- 副作用机制：用户在白热化战斗中无法察觉伤势严重程度，继续战斗直至濒死
- 主要客户群：[[夜之城]] 的雇佣兵——既是最忠实也是最致命的用户
- 报告目的："如何从本该避免的死亡中更好地保护泽塔科技的客户"——
  即削减赔付压力，而非根本停售产品

### 泽塔要塞 / 网络安保

- 公司拥有传说级网络要塞（俗称"恶魔岛"）
- 防御层级：每个进入端口装有改装"斗牛犬"ICE，访问点设"减速夹子""回老家"
- 入口监控配"要你命"主动反制
- [[蜘蛛墨菲]] 曾单人攻破其要塞，留下"蜘蛛墨菲到此一游"签名（参见 [[法术书 蜘蛛墨菲]] 2021.12.12）

### 强占小商家不动产：第 23HT/15 号止赎样本

参见 [[第 23HT15 号止赎通知]] + [[别 千万别买]]——

泽塔科技对小商家执行不动产征收的标准流程：

- 一份冷淡的法律通知书：
  > "由于您未能遵守第 UPL/12064 号协议的条款，
  >  并且未能按照上述协议第 628 段的规定及时回复第 11055 号索款通知书，
  >  因此该不动产将于收到本文件后的**两天内**成为泽塔科技的财产。
  >  **本决议不可上诉**。"
- 关键样式：
  - 极端短的执行窗口（2 天）
  - 法条编号像迷宫（UPL/12064 / 第 628 段 / 第 11055 号 / 第 23HT/15）
  - **不可上诉**

被这套合同坑过的店主在 [[别 千万别买]] 中详细自白：

- 黄金地段、一流设备 → 实际签的合同**所有设备照旧不是你的**
- 三次连续转手——前任店主"全消失得无影无踪"，债却留下
- 自评经验："**从来没有谁能像泽塔科技的那些西装狗一样把我坑得这么惨**"
- 道上兄弟 / 收保护费 / 一锤子买卖 / 抢劫都没坑得这么狠
- 终局选择：**"一扳手砸他脸上，再拿老虎钳子卸他手指头"**

这条线证明：

- 泽塔科技用合同条款 + 短执行窗口 + 不可上诉条款**系统性吞并小商家**
- 受害者最终走向**暴力反扑**——
  与本节点桑德拉·福西特案（被开除→被高利贷追杀）一同显示：
  泽塔科技每条业务线都把对方逼到"要么破产要么变成杀手"
- 这也解释了泽塔科技为什么需要"恶魔岛"级网络要塞——
  公司不只防黑客，也防被它逼成赛博精神病的前客户找上门

### 黑客椅子事故链:萨姆·米尔顿案

参见 [[我早就知道会这样]]——

第一人称发病自述：

- 萨姆·米尔顿在家**测试黑客椅子**——只有"半秒钟没注意"
- "电网短路，线圈也爆了。老婆出来看是怎么回事，结果一切全完蛋"
- "那道 ICE 本来可以帮我们挡住后门网络攻击，
  因为敌人只能从那里攻进来"——
  即黑客椅子的入侵防护层（ICE）在测试中临时关闭，被人趁机攻入
- 妻儿被反向通过电网烧死
- 萨姆进入爆发期，准备同归于尽

"黑客椅子"作为家用产品的存在暗示泽塔科技或类似公司在**家用神经接入界面**线
（在线下完整作品中"网络椅"是 [[蜘蛛墨菲]] 等顶级黑客的标配）
已经下沉到**普通公司白领家庭可购买的程度**——
但消费版的安全等级远低于专业要塞级，
家用市场的网络安全失败可能直接通过电网杀死全家。

### 被开除员工被高利贷做掉的样本：桑德拉·福西特

泽塔科技前员工**桑德拉·福西特**——
被泽塔科技开除后陷入财务危机，
欠夜之城高利贷 **巴托洛梅奥·莫得里尼**（也是社交圈雇主级人物）一笔款：

- 她唯一能拿到钱的方式是回公司停车场取放在车里的钱
- 但被开后她**进不去公司**——临时通行证申请也不会被处理
- 她哀求宽限 48 小时
- 巴托洛梅奥回应：
  > "以前是以前，现在是现在，宝贝儿。
  >  你之前是我的客户，现在我是你的债主。"
- 巴托洛梅奥另托嘉耶当·泽列夫斯基把她做掉——
  > "得让大家知道我可不是搞慈善的。"

这一案例揭示泽塔科技对员工的**社会性遗弃**：

- 开除后**门禁系统连私人物品都不允许取回**
- 公司不只是不养你，还把你与你**自己存放的钱**隔离开
- 被开员工的死亡风险因此暴增——
  他们再也无法用公司资源解决任何外部债务

### 工程师携数据叛逃：马文·希尔顿案

与"公司遗弃员工"互为反面的，是**员工反过来掏空公司**——
泽塔科技工程师**马文·希尔顿**的叛逃案展示了这条暗线：

- **叛逃动机**——他"在打包公司的钱和数据"，想去 [[太平洲]] 经由**蛇头**偷渡到委内瑞拉，
  与女友团聚（[[委托 新生活]]）
- **受控的逃亡**——叛逃者并非孤身上路，背后有一套**类证人保护的接应机制**
  （[[对话记录 马文·希尔顿和已删除]]）：接应方（姓名已删除）反复叮嘱他
  "不要改变日常作息、只用这部电话、不准喝酒、不要碰 [[超梦]] 与毒品、
  不连接任何不明网络、避免接触陌生人"，且只在抵达每个换乘点时才下发下一段坐标——
  一套**为防泽塔科技追查而设计的反侦察流程**
- **三方猎杀**——讽刺的是，最先要他命的不是泽塔，而是**他自己的妻子**：
  妻子怀疑他出轨、雇 [[冈田和歌子]] 跟踪，意外查到他与蛇头的联系，
  遂下委托追杀亲夫、连同他打包的公司钱与数据一并夺走

这条线补全了泽塔"安保偏执"的另一半成因——
它的"恶魔岛"级要塞与反侦察焦虑，**不只防外部黑客，也防内部工程师卷着钱和数据消失**；
而一旦叛逃，公司、配偶、Fixer 会同时盯上同一个人，叛逃者的"新生活"几乎不可能抵达。

### 员工被绑架，客服回以自动模板：义体杀狩劫案

参见 [[邮件 义体杀狩绑架赎金案]] + [[节约光荣 浪费可耻]]——

清道夫团伙"**义体杀狩**"劫持了一支泽塔科技公司车队，绑架了一名员工向**泽塔科技客户服务部**勒索赎金（先要一百万、后降到五十万），扬言寄手指耳朵：

- 客服全程只回复**毫无感情的自动模板**——"我司的顾问将会核实处理您的问题……本条为自动发送信息，请勿回复"
- 绑匪被官僚式冷处理逼到崩溃（"操你妈逼玩儿是吧，复读机是吧？"），最终**谈崩**，决定"把那个逼拆了，义体摘下来算完"
- 受害员工的义体、首饰、名表、金牙被悉数摘取回收（"让他们赤条条地来，也赤条条地走"），赃物经清道夫销赃链转手 [[幽冥犬|已知领域清道夫]]

这是泽塔"安保偏执"叙事的黑色反面——
公司能为防黑客修筑"恶魔岛"级要塞，却对**一名被绑架员工的生死无动于衷**，
一条人命在客服系统里只是一张需要"自动回复"的工单。

## 世界观意义

泽塔科技是 [[公司统治]] 时代"危险产品仍能存续"的样本：

- 它内部清楚自己的产品会让 60% 用户死掉
- 但只要客户是"雇佣兵"——一个本来就死亡率高的群体——
  公司可以把死亡归因于"使用场景"，而非产品本身
- 与 [[摩尔科技]]、[[生物技术]] 那种面向公开市场的厂商不同：
  泽塔的客户死了不会上头条，因此它可以承担更激进的副作用
- 网络要塞的存在又显示出它对自身知识产权与黑历史的高度警惕——
  内部研究报告越敏感，外部要塞越坚固
- **终极反讽**:这家明知疼痛编辑器害死 60% 用户的公司,到 2079 年却**宣称已彻底消除赛博精神病**(ImmunoAid Plus),并借此垄断北美 80% 市场——
  从"放任客户因副作用死亡"到"出售对副作用的免疫",泽塔把自己制造的问题再次卖了一遍;
  而这份霸权据称来自秘密测试 + 与城市高层的私下协议,说明"消除赛博精神病"更像一桩政治-商业交易,而非纯粹的医学突破
