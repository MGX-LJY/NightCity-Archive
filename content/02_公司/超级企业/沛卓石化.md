# 沛卓石化

> 英文原名：**Petrochem**（Petrochemical Associates International / PAIC）
> 旧译名：生物动力公司(约定俗成误译,本仓库已统一改用官方本地化"沛卓石化")
> 总部：美国得州达拉斯(欧文区) / 创立:20 世纪末 / 创始人:路易斯·帕克
> 口号："我们的星球正向前迈进——多亏了沛卓石化"

## 类型

能源与农业超级企业——
赛博朋克世界的**全球燃料命脉**,夜之城及 [[新美利坚]] 经济运行的物理底层之一。

- 全球最大的 **CHOOH2**(合成酒精燃料)生产商,占世界供应的约 **60%**
- 坐拥 NUSA 数百万英亩耕地,也是仅次于 [[苏石化]](SovOil)的世界级产油商
- 2020 年估值约 €$3810 亿(全球第 8);员工 2020 年约 45 万、2045 年约 33.8 万

## 核心业务

- **CHOOH2 燃料生产**——事实上的全球能源帝国,垄断从作物到燃料的全链条(专利由 [[生物技术]] 持有,生产授权归本公司)
- **石油**——仅存的两家产油巨头之一(另一家是 [[苏石化]]),油料多用于制塑料与合成材料
- **农业种植**——超大型 CHOOH2 原料农场(基因改造小麦 Triticum Vulgaris Megasuavis);粮食业务藏在子公司"大陆农业"名下
- **化工与先进材料**——化学品、合成聚合物、陶瓷、纳米材料
- **制药**——子公司 **XOMA**(佐玛)研发药物,涵盖赛博精神病等顽疾的治疗
- **化学武器 / 战斗药物**——与 [[军用科技]] 在该领域既竞争又供货
- **炼化 / 全球运输**——自有精炼厂网络 + 车队 / 油轮 / 跨州管线

## 公司历史

### 帕克家族与 CHOOH2 豪赌

- 公司前身是得州的**帕克石油**(Parker Petrochemicals)——一个靠石油发家的家族企业
- 石油枯竭前夕,家主**路易斯·帕克**(Louis Parker)在投资人**艾伦·特里斯特**(Ellen Trieste)的巨额注资下,
  与初创的意大利基因公司 [[生物技术]] 签下许可协议,成为全美**唯一**获准商业化种植改造小麦、生产 CHOOH2 的公司
- 这场豪赌曾连亏五年,直到福特、通用等车企转产 CHOOH2 引擎,沛卓石化一举垄断美国燃料供应

### 与苏石化的石油战争(2010)

- 与宿敌 [[苏石化]](SovOil)争夺南海油田的战争中失败,苏石化就此成为全球最大原油商
- 沛卓石化转而稳坐 CHOOH2 与化工霸主之位;此役失利至今仍是公司心结

### 四次公司战争后

- 沛卓石化未直接参战,但为保卫油田农田、抵御苏石化袭扰而元气大伤
- 战后多数跨国燃料公司崩溃,沛卓石化"维持了世界运转",并维持着堪比小国的私人武装

### 2077:旱灾与东扩

- 仍是最大 CHOOH2 生产商,但 2076 年严重旱灾使大豆、玉米(CHOOH2 主料)减产创纪录
- 巴西、哥伦比亚(其最大种植园所在)政府一度计划没收收成以平息饥荒动乱;
  靠游说团队阻止了没收,但 2076 年底股价仍暴跌 11%
- CEO **拉尔斯·穆罕默德**(Lars Muhammad)宣布将在原苏联的哈萨克、土库曼、达吉斯坦地区收购百万英亩耕地

## 关联科技 / 产品

- **CHOOH2 燃料**——其商业帝国基石(专利属 [[生物技术]],生产授权属本公司)
- 子公司 **XOMA(佐玛)制药**——总部位于 [[夜之城]],研发含赛博精神病在内的多种药物
- **大陆农业**(Continental Farms Agricorp)、Good Earth Foods——隐藏其身份的食品子公司
- 跨州管线 / 车队 / 油轮全套物流;化学武器与战斗药物

## 关键事件

- **南海石油战争(2010)**——败于 [[苏石化]],失去全球最大油田
- **2076 旱灾 + 股价暴跌 11%**——CHOOH2 主料减产、产粮国威胁没收
- **EBM 沛卓石化体育场**(冠名球场)——位于 [[狗镇]],是 [[往日之影]] 的核心舞台:
  [[航天专机一号]] 坠毁于此、[[汉森]] 把 [[神经矩阵]] 锁在球场最深处、[[百灵鸟]] 引 [[V]] 至此
- 旗下数据多次被黑客 [[天光]] 盗取(与 [[泽塔科技]]、[[生物技术]] 同批)

## 已知活动 / 深度档案

### 与 [[生物技术]] 的关系

CHOOH2 本身是 [[生物技术]](Biotechnica)发明的——核心原料是改造小麦 Triticum Vulgaris Megasuavis。
但真正把 CHOOH2 变成**全球产业**的是沛卓石化:

| 角色 | 分工 |
|---|---|
| [[生物技术]] | 掌握核心专利 / 改造小麦基因 / 酵母配方 |
| **沛卓石化** | 掌握超大型农场 / 精炼厂 / 全球运输网络 |

生物技术把 CHOOH2 生产许可证**授权**给沛卓石化。两家关系:

- **盟友 + 商业合作伙伴 + 互相防备**
- 沛卓石化是生物技术最大的授权合作伙伴,**一直想彻底掌握 CHOOH2 技术**
- 但生物技术握着核心基因——必要时可**让相关作物失效**,所以沛卓石化**不敢轻易翻脸**

### EBM 沛卓石化体育场:从地标到黑市

- 球场本是为标榜 [[太平洲]] 新身份而建的标志性现代场馆,曾为引入橄榄球队(萨克拉门托海盗队)而修
- 但球场位于 [[狗镇]] 黑市、太平洲帮派的避风港,球队转会停留在纸面——居民始终不认它是"咱们的球队"
- 到 2077,旧球场沦为狗镇"想买什么都能买到"的黑市集散地;
  并在《往日之影》中成为 [[汉森]] 囤积 [[神经矩阵]]、[[航天专机一号]] 坠毁的核心舞台

### 在 [[公司统治]] 时代的定位

夜之城两大生物/能源巨头一句话概括:

- **[[生物技术]]（Biotechnica）控制食物和基因**
- **沛卓石化（Petrochem）控制燃料和能源**

整个 [[新美利坚]] 的经济体系,**很大程度上建立在这两家公司的合作之上**——
谁掌握了 CHOOH2,谁就掌握了 2077 世界的内燃机、发电厂、卡车队。

### 译名说明

中文圈长期把 **Petrochem 误译为"生物动力公司"**;游戏官方本地化实为 **"沛卓石化"**(原始资料中可见"EBM 沛卓石化体育场""沛卓石化的合成面粉"等)。本仓库已统一采用"沛卓石化"。

- "Petrochem" = "Petrochemical"(石油化工)的缩写,业务与"生物"无关
- 区分姐妹巨头:**[[生物技术]]** = Biotechnica(基因 / 食品 / 克隆 / 70 人案);**沛卓石化** = Petrochem(CHOOH2 / 燃料 / 能源 / 本节点)

## 世界观意义

沛卓石化是 [[公司统治]] 时代**能源垄断**的样本——
它没有 [[军用科技]] 的战争话语,也没有 [[荒坂]] 的灵魂技术,
但它掌握了所有这些公司**车队烧的燃料**。

- "石油枯竭→CHOOH2 救世→沛卓石化垄断"——完整展示了一次"危机变商机"的公司主义周期
- 与生物技术的关系是 [[公司统治]] 时代典型的**专利-生产分工**:
  上游靠基因卡脖子,下游靠物流和炼厂规模锁死,两端各自不可替代,因此能长期"互相防备"地合作
- 一旦两家彻底翻脸,CHOOH2 体系瓦解,夜之城的所有车队 / 工厂 / 发电厂同时停摆——
  这种"互相人质"结构是赛博朋克版的相互保证毁灭
- 而 2076 旱灾几乎一举掀翻这个帝国——说明再庞大的能源垄断,根基仍是**会被天气摧毁的庄稼**:
  把全球燃料押在一种转基因小麦上,本身就是公司主义把自然风险系统化的极致
