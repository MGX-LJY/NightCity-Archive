## 已知活动 / 深度档案

### 与 [[生物技术]] 的关系

CHOOH2 本身是 [[生物技术]]（Biotechnica）发明的——
核心原料是改造小麦 **Triticum Vulgaris Megasuavis**。
但真正把 CHOOH2 变成**全球产业**的是生物动力：

| 角色 | 分工 |
|---|---|
| [[生物技术]] | 掌握核心专利 / 改造小麦基因 / 酵母配方 |
| **生物动力** | 掌握超大型农场 / 精炼厂 / 全球运输网络 |

生物技术把 CHOOH2 生产许可证**授权**给生物动力。

两家关系：

- **盟友 + 商业合作伙伴 + 互相防备**
- 生物动力是生物技术最大的授权合作伙伴
- 生物动力**一直想彻底掌握 CHOOH2 技术**
- 但生物技术握着核心基因——
  必要时可以**让相关作物失效**，
  所以生物动力**不敢轻易翻脸**

### 在 [[公司统治]] 时代的定位

如果用一句话概括夜之城的两大生物巨头：

- **[[生物技术]]（Biotechnica）控制食物和基因**
- **生物动力（Petrochem）控制燃料和能源**

整个 [[新美利坚]] 的经济体系，
**很大程度上建立在这两家公司的合作之上**——
谁掌握了 CHOOH2 谁就掌握了 2077 世界的内燃机、发电厂、卡车队。

### 译名说明

中文圈长期把 **Petrochem 误译为"生物动力公司"**——
这是约定俗成的错译,但已经深入大量中文资料。
本档案保留这一中文译名,
但请注意 Petrochem 本身与"生物"业务无关,
其业务是**石油化工 / 能源 / 燃料**——
"Petrochem" = "Petrochemical"（石油化工）的缩写。

**历史性命名混乱**：
本档案早期把 [[生物技术]]（Biotechnica）也错译成了"生物动力"——
导致 2077 大量条目里"生物动力"实际指的是 Biotechnica 而非 Petrochem。
2026 年统一修正：
- "生物技术" = Biotechnica（基因 / 食品 / 克隆 / 70 人案 / 乔安妮·科奇所属）
- "生物动力" = Petrochem（CHOOH2 / 燃料 / 能源 / 本节点）

## 世界观意义

生物动力是 [[公司统治]] 时代**能源垄断**的样本——
它没有 [[军用科技]] 的战争话语，也没有 [[荒坂]] 的灵魂技术，
但它掌握了所有这些公司**车队烧的燃料**。

- "石油枯竭→CHOOH2 救世→Petrochem 垄断"——
  完整地展示了一次"危机变商机"的公司主义周期
- 与生物技术的关系也是 [[公司统治]] 时代典型的**专利-生产分工**：
  上游靠基因卡脖子，下游靠物流和炼厂规模锁死，
  两端各自不可替代，因此可以长期"互相防备"地合作
- 一旦两家彻底翻脸,
  CHOOH2 体系瓦解,夜之城的所有车队 / 工厂 / 发电厂同时停摆——
  这种"互相人质"结构是赛博朋克版的相互保证毁灭
