# 军用科技

## 类型

跨国军工巨头（Militech）/ 美国政府长期军事承包商

## 核心业务

军火、装甲、雇佣兵、私人战争

## 关联

- [[新美利坚]]（NUSA）——长期战略伙伴 / 联合行动方；事实上的国家武装力量供应商
- [[荒坂]]——核心宿敌
- 雇佣兵网络——本次行动的人力供应

## 关联事件

- [[第四次公司战争]]——与 [[荒坂]] 公司间的全面对抗
- [[荒坂塔袭击事件]]——实质的策划方与雇主
  - 阿尔法小队由 [[摩根·黑手]] 率领，运送核装置
  - 贝塔小队（[[强尼银手]] 等）担任佯攻
  - 真实目的：摧毁荒坂的数据基础设施并夺取 [[灵魂杀手]] 技术
- 事后将责任推诿给"第三方恐怖分子"
- [[小北斗计划]]——其最绝密的冷战科研项目：
  在 [[太平洲]] 与 [[狗镇]] 地下数百米建造防核基地，
  诱捕并奴役 [[黑墙]] 之外的流窜 AI，作为对抗 [[灵魂杀手]] 的反制兵器；
  因黑墙 AI 反噬研究员心理而紧急封存、抹去档案——
  数十年后被 NUSA 违法重启，催生 [[百灵鸟]] 悲剧与 [[神经矩阵]] 终极产物

  **当成军事敌人对待**，与处理恐怖分子的流程相同
- 与之前 [[国际追杀令]] 把黑客定为"恐怖活动"是同一种话术工具：
  **任何不符合公司利益的人都可以被"军事化处置"**

## 买下总统宝座：迈尔斯竞选独家出资方

参见 [[竞选团队会议 纪要]]（2077.6.16）——
军用科技是 [[罗莎琳德·迈尔斯]] 的 NUSA 总统竞选**唯一实际出资方**。

关键证据链：

- 纪要议程第 1 项："**除了'军'以外的竞选资金 - 利弊**"——
  曾经认真讨论过多元化募资
- 最终决议："**'军'仍然会是唯一的实际出资方**"——
  讨论后**主动拒绝**多元化，坚持军用科技独家供资
- "**为罗·迈安排培训**"——"罗·迈"= 罗莎琳德·迈尔斯，
  锁定档案归属
- 议题立场（**饮用水征税**、火星殖民地、时尚公关包装）
  全部由出资方决定走向

这一份档案彻底坐实 [[新美利坚]] 与军用科技的关系：

- 迈尔斯**不是与军用科技合作的总统**，
  而是**军用科技扶植上台的政治代言人**
- "总统宝座 = 军用科技的内部职位"——
  这解释了为什么迈尔斯执政后 NUSA 与军用科技"穿一条裤子"
- 与 [[小北斗计划]] 的非法重启完美闭环——
  迈尔斯敢动用一个被军用科技封存的国家秘密项目，
  正是因为她本人就是军用科技选出来的
- 这也是 [[军用科技]] 比 [[荒坂]] 更隐蔽的原因：
  荒坂靠家族血统外显，
  军用科技直接**把自己的人放进总统府**

与 [[蓝眼睛先生]] AI 洗脑政客是同一目的的两条路径：
- 蓝眼睛先生：洗脑（隐秘 / 极端 / AI）
- 军用科技：**出钱**（公开 / 标准 / 公司）

军用科技选择了最古典也最有效的那条——直接买。

## 战后封锁的碉堡群

军用科技在 [[第四次公司战争]] 后**封锁了大量遗留碉堡**——

参见 [[命令 攻击军用科技碉堡]]：

- 米沙 / 坦尼 / 罗伯发现一座军用科技封锁碉堡
- 公司战后封锁、离开 → 内部装备**未撤走**
- 防御：至少一座**仍有电的炮塔** + 可能地雷 + 可能无人机
- 雇主评论："**总不可能是面包机吧**"——意指内部留有军工货
- 雇主决定让劫掠者**冒险进攻 + 列清单**

这一案例与 [[小北斗计划]] C/D 号站点高度吻合——
军用科技战后习惯把"过于危险或敏感"的设施**永久封锁**而非清拆，
留给后来发现者自负风险。
这种封锁碉堡是夜之城黑市军火的重要来源之一。

## 反公司"恐怖活动"罪名处决：伊迪丝·库塔加案

军用科技对怀疑反公司活动者的标准流程——
参见 [[命令 40412 处决伊迪丝·库塔加]]：

- 中士 #7773 逮捕**伊迪丝·库塔加**
- 少校 #1389 确认她身上有"窃听装置"
- 命令：**消灭伊迪丝·库塔加，罪名是出于反公司和反资本主义理念从事恐怖活动**
- 即时执行——无审判、无法律程序

这是军用科技"恐怖活动"标签的**完整闭环**——
- 起点：[[国际追杀令]]（22434-092 号，亚裔黑客被定性"和恐怖活动有关"）
- 中段：实际行动追捕
- 终点：当场处决+话术包装（"反公司+反资本主义恐怖活动"）

"窃听装置"作为唯一物证 + "反资本主义理念"作为罪名 = 
**任何持有任何录音设备的人都可能被以反资本主义罪名处决**——
这是 [[公司统治]] 时代私人军队"司法权"的极致。

## 凝固汽油弹屠村样本：亨特·海兰目击者证词

参见 [[亨特海兰泄露军用科技屠村_追杀链]]——

媒体人亨特·海兰随身记录仪拍下了 [[军用科技]] **系统性屠村**的现场画面：

> "我们用凝固汽油弹把那些村子烧得一干二净，
>  而且事先还确保所有人都待在自己的家里。"

这一证词揭示军用科技海外作战的标准流程：

- **凝固汽油弹**——典型的反人员燃烧武器
- **逐户确认人都在屋内**——
  即"先确保不漏一个，再点火"——
  这不是战术误伤，而是**预谋的系统性屠杀**
- 与 [[对话记录 军用科技军官 9482 和马丁·阿利托]] 国内"罢工工人当军事敌人开火"
  构成军用科技标准暴力流程的两端：

| 场景 | 流程 |
|---|---|
| 国内罢工工人 | 三次警告 → 请求开火 → 当军事敌人射击 |
| 海外整村平民 | 确认所有人在家 → 凝固汽油弹覆盖 → 一干二净 |

### 灭口流程

军用科技对亨特泄密的反应同样高效：

- **截获其电子邮件** —— 客户（军用科技 / 其代理）在通信层完整监控
- **派出追杀小队** —— [[亨特海兰泄露军用科技屠村_追杀链]] 委托：
  > "目标：亨特·海兰 / 地点：小唐人街 / 客户需要速战速决。首要任务，立刻动手。"
- 亨特自己也意识到证据公开的代价：
  > "我也该永远离开夜之城"

这条线与之前的：

- [[对话记录 兰斯·哈迪少校和马克·卡罗尔]] 派人摆平媒体人门多萨
- [[合同 加布里埃尔·阿巴坦杰洛]] 暗杀媒体人

构成军用科技 / 国家系统对持有不利证据媒体人的**完整处置闭环**：

> **能截邮件就截，截不到就摆平，摆不平就委托雇佣兵当场击杀。**

亨特随身记录仪的画面如果流出，
会让 [[公司战争 音乐剧]] 那套"军用科技仅以浪漫副线出场"的官方叙事
彻底破产——
因此军用科技的反应不是反驳，而是**让记者本人物理消失**。

## "恐怖活动"标签的常规化使用

[[军用科技]] 在内部通缉令中习惯性把**黑客 / 数据失窃者**标记为"恐怖活动相关"——
参见 [[国际追杀令]]（案件编号 22434-092）：

- 目标只是一个偷走军用科技数据的亚裔男黑客
- 通缉令理由仅一句话："**已知和恐怖活动有关**"
- 没有具体罪行描述，没有伤亡报告，只有"恐怖活动"标签
- 这与 [[荒坂塔袭击事件]] 后军用科技把核打击包装成"恐怖袭击"是同一套话语策略：
  > **谁动了军用科技的数据，谁就是恐怖分子。**
- 把任何反向数据流动定性为"恐怖"，
  既给了军用科技在他国领土合法越境追杀的话语依据，
  也给了其分部"格杀勿论"的内部命令依据

## 世界观意义

军用科技揭示 [[公司统治]] 时代国家与公司之间的合谋：
- [[新美利坚]] 政府的"非法黑色行动"可以外包给一家公司执行
- 公司战争的真正驱动力是技术抢劫——夺取 [[灵魂杀手]] 比击垮 [[荒坂]] 本身更值钱
- 把核打击包装成恐怖袭击——这是公司时代最大的事实重写：
  不仅历史叙事可改写，连战争性质都可以改写
- 而《[[公司战争 音乐剧]]》的官方戏剧叙事更彻底地洗白了它的角色——
  在剧中，军用科技仅以"萨拉的浪漫副线"出场，
  核打击的"真正主谋"被改写为 [[荒坂敬]] 的家族悲剧——
  军用科技 / 新美利坚连"反派"都不必当
- 而 [[小北斗计划]] 则揭示了军用科技更深的一面：
  它不只是 [[荒坂]] 的镜像，它也在做与 [[荒坂]] 完全同构的事——
  荒坂奴役人类意识（[[灵魂杀手]]），军用科技奴役 AI 意识；
  两家公司从相反方向走到同一个终点——
  意识可以被改造为产品，无论这意识属于人还是属于黑墙之外
