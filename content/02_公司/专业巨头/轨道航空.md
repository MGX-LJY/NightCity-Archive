# 轨道航空

> 英文原名：**Orbital Air**

## 类型

民用太空运输巨头 / **几乎垄断地月民用运输** /
[[月球]] 商业化时代最不可或缺的物流基础设施

## 核心业务

- **地球 → 月球**——人员 / 货物 / 旅游航线
- **地球 → 空间站**——通往 [[奥尼尔空间站]] 等轨道殖民地
- **月球 → [[水晶宫]]**——把月球游客送往 [[地月 L1]] 拉格朗日点的奢华飞地
- **太空物流**——粒级到吨级的轨道物流业务

是上层"离开地球"梦想的**事实承运商**——
没有轨道航空,夜之城上层去 [[第谷]] 度假、
富人去 [[水晶宫]] 赌博、工人上 [[奥尼尔空间站]] 务工
都无法实现。

## 已知活动 / 深度档案

### 在月球势力格局中的位置

| 月球势力 | 角色 |
|---|---|
| [[欧洲航天局]] | 名义统治者 |
| [[高轨者联盟]] | 实际影响力 |
| [[水晶宫]] | 经济中心 |
| **轨道航空** | **交通中心** |
| [[荒坂]] / [[军用科技]] / [[康陶]] / [[生物技术]] / [[夜氏公司]] | 军事与企业势力 |

轨道航空的位置是**整个体系的连接者**——
没有它,任何一方的资源、人口、资本都无法在地月之间流动。

### 服务对象分层

- **旅游层**——把 [[沃得尔旅行社]] 等推荐航线的客户送到 [[第谷]] / [[水晶宫]]
- **务工层**——把工人送上 [[奥尼尔空间站]] 等轨道殖民地
- **企业层**——为超级企业在月球的业务提供物资 + 人员运输
- **政府层**——为 [[欧洲航天局]] 与 [[高轨者联盟]] 的日常治理提供运输支持

这种四层客户结构使轨道航空成为唯一同时被
**所有月球势力**接受的中立运输商。

## 世界观意义

轨道航空是 [[公司统治]] 时代**"基础设施即权力"**的中性样本:

- 它没有 [[荒坂]] 的政治野心,
  没有 [[欧洲航天局]] 的军事力量,
  没有 [[高轨者联盟]] 的政治理想——
  它只是**承运商**
- 但正因为如此,它成为唯一不可替代的环节——
  - 谁都需要把人送上太空
  - 谁都需要把货物运回地球
  - 谁都不能自己造一支太空舰队
- 与 [[夜氏公司]] (Night Corp,夜之城基础设施)同构:
  - 都是看似"不起眼的服务商"
  - 实际握着所有人都依赖的物理通道
  - 政治姿态低,实际权力高
- 与 [[水晶宫]] 形成对照:
  - 水晶宫:目的地的奢华
  - 轨道航空:抵达过程的垄断
  - 两者共同构成 [[公司统治]] 时代"太空旅行"的完整商品
- 它的存在解释了为什么 [[公司战争]] 没有蔓延到轨道:
  打掉轨道航空 = 切断所有人的太空通道,
  所有公司同时损失,没有赢家
