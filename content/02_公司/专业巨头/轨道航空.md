# 轨道航空

> 英文原名：**Orbital Air**（OA）
> 总部：肯尼亚内罗毕(约 2000–2008)→ 澳大利亚海曼岛(2008 年起)
> 创立:21 世纪初 / 员工:约 104,000(含约 1 万武装人员)
> CEO:安托万·杜布瓦(2020)/ 莱斯利·瓦乌达(2077)

## 类型

源自肯尼亚的民用太空运输巨头 / **世界最古老的地月运输公司、几乎垄断轨道运输** /
[[月球]] 商业化时代最不可或缺的物流基础设施
- 拥有大批法制 Hermes(赫尔墨斯)航天飞机,承担几乎全部轨道运力
- 控制全球多数太空港,含摩加迪沙(Mogadishu)的世界最大航天发射场

## 核心业务

- **地球 → 月球**——人员 / 货物 / 旅游航线
- **地球 → 空间站**——通往 [[奥尼尔空间站]] 等轨道殖民地
- **月球 → [[水晶宫]]**——把月球游客送往 [[地月 L1]] 拉格朗日点的奢华飞地
- **太空物流**——粒级到吨级的轨道物流业务

是上层"离开地球"梦想的**事实承运商**——
没有轨道航空,夜之城上层去 [[第谷]] 度假、
富人去 [[水晶宫]] 赌博、工人上 [[奥尼尔空间站]] 务工
都无法实现。

## 公司历史

- 21 世纪初创立于肯尼亚内罗毕,是最古老的太空运输公司;与 [[欧洲航天局]]、日本宇宙局(JAB)、新苏维埃等合作
- 2020 年代:深度绑定 [[欧洲航天局]] 的 [[水晶宫]] L-5 殖民地(若无 OA 输送客流,这座太空酒店早已倒闭);最大股东兼 CEO 安托万·杜布瓦为应对中国与 Euro-flight 的竞争,大举投入隐秘资源保住垄断
- **2008 年**:与 [[欧洲航天局]] 及澳大利亚政府合建凯约克(Cape York)太空港;并从澳大利亚政府手中**买下海曼岛**、获"独立主权地位",由此豁免澳大利亚法律管辖,随后将总部迁至岛上
- **2040 年代**:在 [[夜之城]] 建成 **NCX 太空港**——但此前它接手了夜之城一座**烂尾的质量投射器工地**,致使 [[夜氏公司]] 永远失去"让母城成为太空前沿"的机会,两大巨头自此陷入冷战
- **2077**:服务持续扩张,各健康国家的大城市都设有 OA 太空中心;现任 CEO 莱斯利·瓦乌达投入巨资搞太空探索,并与"新非洲"当局合作研究半人马座阿尔法星系

## 子公司 / 服务线

- **OA Black**——保密私人包机:只需提供坐标,专机送客户飞往地球轨道之外,目的不对机组外任何人透露
- **OA 水晶宫直达**(Crystal Palace Direct)——无需在月球中转、直送 [[水晶宫]] 的轨道班车
- **OA HighLines**——豪华太空梭,80+ 地面目的地(约翰内斯堡到亚特兰大仅 33 分钟)
- **OA TerraLines**——平价航天飞机点对点(夜之城到悉尼仅 1 小时)
- **OA TychoLines**——地月班线,16 小时直达月球 [[第谷]]

### 在月球势力格局中的位置

| 月球势力 | 角色 |
|---|---|
| [[欧洲航天局]] | 名义统治者 |
| [[高轨者联盟]] | 实际影响力 |

轨道航空的位置是**整个体系的连接者**——
没有它,任何一方的资源、人口、资本都无法在地月之间流动。

### 服务对象分层

- **旅游层**——把 [[沃得尔旅行社]] 等推荐航线的客户送到 [[第谷]] / [[水晶宫]]
- **务工层**——把工人送上 [[奥尼尔空间站]] 等轨道殖民地
- **企业层**——为超级企业在月球的业务提供物资 + 人员运输
- **政府层**——为 [[欧洲航天局]] 与 [[高轨者联盟]] 的日常治理提供运输支持

这种四层客户结构使轨道航空成为唯一同时被
**所有月球势力**接受的中立运输商。

## 世界观意义

轨道航空是 [[公司统治]] 时代**"基础设施即权力"**的中性样本:

- 它没有 [[荒坂]] 的政治野心,
  没有 [[欧洲航天局]] 的军事力量,
  没有 [[高轨者联盟]] 的政治理想——
  它只是**承运商**
- 但正因为如此,它成为唯一不可替代的环节——
  - 谁都需要把人送上太空
  - 谁都需要把货物运回地球
  - 谁都不能自己造一支太空舰队
- 与 [[夜氏公司]] (Night Corp,夜之城基础设施)同构:
  - 都是看似"不起眼的服务商"
  - 实际握着所有人都依赖的物理通道
  - 政治姿态低,实际权力高
- 与 [[水晶宫]] 形成对照:
  - 水晶宫:目的地的奢华
  - 轨道航空:抵达过程的垄断
  - 两者共同构成 [[公司统治]] 时代"太空旅行"的完整商品
- 它的存在解释了为什么 [[公司战争]] 没有蔓延到轨道:
  打掉轨道航空 = 切断所有人的太空通道,
  所有公司同时损失,没有赢家
