# 全食品

> 英文原名：**All Foods**
> 别名：全食品股份有限公司 / 全食品工厂股份有限公司

## 类型

合成食品 / 人造肉 / 跨物种基因杂交食品工业巨头

- 母公司：**[[生物技术]]（Biotechnica）**——基因工程与培养肉技术由母公司提供，
  全食品负责加工、包装、销售、营销
- 主要市场：**[[新美利坚]]**（NUSA）
- 行业定位：赛博朋克世界事实上的"廉价蛋白唯一供应商"——
  现实世界**麦当劳 + 雀巢 + 泰森食品 + 预制菜厂**的合体

## 核心业务

参见 [[全食品 吃得明白 吃得放心]]——

- **人造肉**：牛肉、猪肉、禽肉，以及**跨物种基因改造杂交组合肉**
- **素食线**：尖端水培实验室生产的海藻 + 蔬菜
- **替代乳制品**：高纯度碳酸钙着色的甘油奶
- **合成蛋白**：合脂合成鸡蛋（号称富含维生素 A）
- **糖果线**：人工香精糖果——"甜到大自然都自愧不如"
- **典型产品**："三倍脆皮酥炸合成鸡肉" / "羽衣甘蓝大蒜混合维生素"

## 公司历史

- 起家于**墨西哥城的一家肉类商店**
- 战后扩张为全国连锁食品企业
- 进一步扩张为全球级食品供应商
- 最终被 [[生物技术]]（Biotechnica） 收购，成为其食品产业的核心子公司

到 2077 年，普通市民每天入口的"肉",
绝大多数都已经是全食品出品的合成肉、培养肉或蛋白浆——
真正的天然肉退化为富人的奢侈品。

## 关联科技 / 产品

### 招牌产品：EEZYBEEF

全食品最有名的产品线，宣传语意为"**未来的肉**"：

- 人造**培养肉**——细胞培养，非传统屠宰
- 成本极低、供应量极大
- 味道做到接近真牛肉
- 夜之城绝大多数快餐店的"牛肉"原料即 EEZYBEEF

EEZYBEEF 是全食品最成功的语义胜利：
它让"培养肉"在普通消费者那里不再是"假肉",而直接等于"肉"本身。

## 已知活动 / 深度档案

### 全食品工厂（All Foods Factory）

夜之城北部工业区的旧厂区，曾是全食品的**蛋白加工厂**：

- 生产**蛋白浆**（Protein Slurry）、人造肉、近似肉制品
- 巨型加工设备、输送带、冷冻仓库、肉类包装线一应俱全

后**突然关停**,被 [[漩涡帮]] 整体占领,改造为帮派据点。

主线任务《拿货》(The Pickup) 即发生于此——
[[V]] 与 [[杰克·威尔斯]] 在这里第一次正面接触
[[漩涡帮]] 的 **罗伊斯（Royce）、达姆达姆（Dum Dum）、布里克（Brick）**
为夺取 [[军用科技]] 飞蛾机器人完成交易（或不完成交易）。

这座工厂本身就是 2077 食品工业的一个标本：
**一座可以喂饱半个北加州的合成肉厂,荒废后变成帮派军火库**——
食物基础设施和帮派基础设施在 [[公司统治]] 时代可以无缝互换。

### 商业话术

广告口径反复打三张牌：

1. **饥饿叙事**："帮助全球数百万人摆脱了饿肚子的痛苦"——
   把公司定位为"战后秩序的食物兜底者"
2. **无菌话术**："从生产到存储，我们的流水线都是无菌环境"
3. **黑市恐吓**："切勿从黑市商店购买有机肉和三色食品。
   不受管制的肉类和农产品可能会导致感染、慢性病甚至死亡"——
   把"有机食物"反过来污名化为危险品，
   把"工业合成食物"包装成唯一安全选择

### 已知运输与物流

参见 [[走私]]——

- 全食品的**运输队**是夜之城重要走私通道：
  > "我还搭了辆全食品运输队的便车。
  >  没人知道有几箱子吃的里面装的其实是毒品。"
- 即：全食品的物流网络对走私者来说**比公司广告更有价值**——
  车队规模 + 跨州通行能力 + 食品箱的伪装空间
  使其成为夜之城黑市的事实搭便车通道

### 已知客户

参见 [[生物技术]] 工厂访客记录（早班）——

- **06:15**，全食品方面派出 **8 人小组** 抵达 [[生物技术]] 工厂
- 这表明全食品与顶级义体公司之间存在**早班级别的常态业务往来**——
  可能涉及厂区配餐、食品供应合同，或工厂员工的强制食堂

## 世界观意义

全食品是 [[公司统治]] 时代"食物商品化到底"的样本：

- "饿肚子的痛苦"被讲述成**单一公司可以独家解决的世界难题**——
  这是公司话术接管"国家功能"的典型样本：
  既然 [[新美利坚]] 不再做粮食安全，
  那么"全食品"就负责定义什么叫"吃得安全"
- "**跨物种基因改造杂交组合肉**"——
  公司明面广告里**主动炫耀**这个细节，
  说明在 [[公司统治]] 时代消费者已经不再恐惧"非自然食物"，
  反而把它当作技术进步
- "切勿从黑市购买有机食物"——
  公司利用恐吓把**真实食物**反向定义为危险品，
  完成对食物范畴的语义垄断
- 全食品的卡车跑着走私货——
  完美讽刺：**养活全球的物流网络也是毒品物流网络**；
  食物供给与黑货供给共用同一条公司动脉
- 与 [[创伤小组]] 同构——
  公共功能（医疗 / 食品安全）私有化为公司服务，
  公司同时利用同一基础设施跑黑货：
  救命车跑毒品，运粮车跑毒品——
  公共服务的物理特权变成了黑市的物理特权
