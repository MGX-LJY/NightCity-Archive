# 创伤小组

> 英文原名：**Trauma Team International**（TTI）
> 总部：美国西雅图 / 创立:2020 年前 / 员工:约 17,000(2020)
> 招牌承诺:"7 分钟到场,否则退款"

## 类型

私营紧急医疗与战术救援公司

- 全称：**Trauma Team International**（TTI）
- 起家地：美国西雅图，后扩张至北美、欧洲、日本，最终落地 [[夜之城]]
- 在 [[公司统治]] 时代成长为全球性医疗巨头
- 与 [[荒坂]]、[[军用科技]]、[[夜氏公司]]、[[生物技术]]、[[岐路司]] 等众多超企合作,使其员工无需自费即可享会员;2077 年还与 [[德拉曼]] 公司结盟
- 据称是夜之城**唯一享有极高公众信任**的公司:不玩政治、不问来由,付费即保命

## 核心业务

- 为高端会员提供"战场级医疗救援"——
  收到求救信号后，武装医疗小队会以战术规模介入战区
- 服务对象按会员级别分层——普通市民几乎接触不到
- 是 [[公司统治]] 时代私人化医疗的极致样本
- 三层业务并存：
  - **医疗保险**——客户植入生物监测芯片，生命体征触发阈值即自动报警
  - **武装救援**——无视交火现场，必要时直接开火清场，原则只有一条："客户必须活着离开"
  - **现场手术**——AV 机舱即手术室，做创伤治疗、器官稳定、神经修复、义体维持

## 公司历史

- **四次公司战争(2022–2023)**:业务激增、运力濒临极限;为保中立,TTI 宣布**不再响应 [[荒坂]] 或 [[军用科技]] 成员的求救**,只接平民单,且只要半公里内有人开枪就按"战斗费率"收费
- **2045**:战争耗尽其有限资源与供应链,北美 TTI 退化为区域性、各自为政的**加盟制**(Trauma Team North America);蓝黄制服被迫换成军规重甲,整支队伍变得疲惫、易怒
- **2077**:TTI 重组、收回大量资产,因 NUSA 犯罪率攀升而涨价、武装也比 2020 年更强;飞行器换装 [[泽塔科技]] 制造的 Atlus,武器由 [[康陶]] 供应

## 已知活动 / 深度档案

### 服务等级

会员合同分级，等级越高响应越快、优先级越高：

- **银级（Silver）**——基础救援
- **金级（Gold）**——更快响应；[[康陶]] 等公司为员工统一订阅的级别
- **白金级（Platinum）**——最高优先级，无论现场情况如何都优先派遣

> 你的会员级别决定你今天能不能活到明天——这是 TTI 最诚实的广告。

### 装备与编制

#### 标准小队构成

- **战斗医护兵**——急救、诊断、现场手术
- **安保人员**——压制火力、清场、保护撤离路线

成员普遍接受军事级训练，配重型防弹护甲，标志性的**白蓝配色**在夜之城辨识度极高。

### 南街区贫民区劫药事件

- [[夜之城]] **南街区**——超级摩天楼贫民区，居民集中生病、缺药
- 居民代表**玛格达琳·尤西奇克** 找到武装人员**豪尔赫·罗恩** 帮忙
- 一名邻居的少年黑客**几下操作就黑入了创伤小组的派送系统**——
  定位到一辆装载药物的浮空车
- 计划：用 EMP / 武器把浮空车打下来劫药
- 豪尔赫的反应：":D 你们死定了 / 真是命都不要了" + 仍然答应帮忙
- 玛格达琳的报酬要求："不要钱，我只想认识一下你隔壁那个天才儿童"
- 这是 [[公司统治]] 时代**草根反创伤小组**的样本：
  - 公共医疗失能 → 贫民区生病无药可拿
  - 富人 / 公司员工的派送车却装满救命药从头顶飞过
  - 一个少年黑客 + 一群武装居民 + 一个老兵 ≈ 一次劫药行动
- 玛格达琳提到："我本来以为 [[瓦伦蒂诺帮]] 会帮忙，帮助普通老百姓"
  - 暗示瓦伦蒂诺帮在海伍德/南街区一带的"罗宾汉"叙事**实际并不兑现**
- 这次行动可能就是 [[飞行记录 3287-AFH]] 中那架"被 EMP 击中、失去高度、坠落"的浮空车的对应视角
- 参见 [[对话记录 豪尔赫·罗恩和玛格达琳·尤西奇克]]

### 黑暗面:救护资源走私黑货

参见 [[交货情报 创伤小组黑货]]——

街头交易短讯直接称呼"**创伤的人给我们带了新货**":

- 时间表:"我一小时内过来"——
  创伤小组的医疗车速度被用作**黑货专递**
- 交易方式:"把钱给他们就是了"——
  现金面交,无任何医疗记录
- 警告:"千万别冲动,别犯傻"——
  这暗示来送货的是装备齐全的武装医疗组,得罪不起

这条线揭示创伤小组**第三层身份**:

- 公开身份:私营战术救援公司
- 商业身份:富人保命合同提供方
- **隐藏身份:利用救护车优先通行权 + 不被检查权 + 武装跨城运输能力,
  暗中替黑市运毒 / 运义体 / 运芯片**

这种黑货生意的逻辑闭环:

- 救护车 / 空中医疗机享有**全城最高优先通行权**——
  NCPD 不会拦截、海关不会开箱
- 武装医疗组配枪+战术护甲——
  比帮派马仔安全得多
- "1 小时内送达"——
  比一切走私渠道都快
- 客户付钱 = 救命会员费的隐性增项,
  富人客户拿到的"额外服务"

与之前 [[定制急救服务]] 中"客户死亡可通过倒卖器官与植入体带来收入"
的指控形成闭环——
**创伤小组从抢救到尸体处理,整条链都是商品**。
活人是 VIP 服务,死人是器官来源,运输能力是黑货载体。

### 续费催缴话术样本

参见 [[您的创伤小组保险已过期]]——

会员合同到期通知模板：

> "亲爱的客户，
>  我们遗憾地通知您，由于未能及时付费，您的创伤小组保险已过期。
>  请不要忘记立刻激活您的会员卡，
>  以便我们继续在最危险的时刻保障您的健康与安全。
>  **生命宝贵，请千万不要犹豫**。"

关键修辞：

- "**最危险的时刻**" + "**生命宝贵**"——
  通知本身就是恐吓——
  把财务催缴包装成"你的命随时会丢"的警告
- 没有具体时间表 / 没有补偿条款 / 没有缓冲期——
  续费的紧迫性被无限放大
- "**遗憾地通知您**"——
  公司化哀悼语气：
  你的账单逾期被讲述成公司的损失，
  实际上一旦你欠费、你下次受伤就被路边了
- 与 [[第 23HT15 号止赎通知]]（[[泽塔科技]]）同样使用
  "格式法律函 + 极短窗口"模板——
  夜之城两大私有化服务（医疗 / 房产）的催缴函都已**标准化为恐吓信**

### 价格与公开批判

据《[[定制急救服务]]》：

- 2020 年起，民众已认同每月 **500 欧元**的创伤小组保费"价格合理"
- 私有化医疗在 [[公司统治]] 时代被视为"无替代方案"——文章作者讥讽："放屁。"
- 对照：太平洋彼岸的**俄联邦** 提供公共医疗——技术精湛医生 + 高精度纳米手术套件 + 现代浮空救护车，"不会逼任何人去公司里交买命钱"
- 该文核心指控：创伤小组**把投保人视为"有待治疗的潜在患者和有待交易的潜在产品"**——
  得救者是回头客；客户死亡可通过倒卖器官与植入体带来收入

## 世界观意义

创伤小组是 [[公司统治]] 时代医疗私有化的样本：

- "急救"在这个时代是商品——
  你有合同就能在交火中被空降救援，没合同你死在街上
- 与 [[NCPD]] / [[MaxTAC 暴恐机动队]] 同构——
  公共安全 / 公共医疗早已被职业化、私有化、阶级化
- 与 [[清道夫]] 互为镜像：
  创伤小组用枪保护客户的肉体不被拆，
  清道夫用枪把陌生人的肉体拆来卖——
  两端都把人体看作有合同的物
- "你的会员级别决定你今天能不能活到明天"——
  这是这家公司最诚实的广告语
- 南街区劫药事件揭示创伤小组的另一面：
  它不只是"私人化医疗的极致"——
  当公共医疗彻底失能，创伤小组的派送车成为
  **唯一可见的、装满救命药物的、从穷人头顶飞过的目标**——
  劫药因此从犯罪变成"看见即出手"的本能
