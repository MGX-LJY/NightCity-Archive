# 航天专机一号

> 别名:航天专机一号 / 空天一号 / NUSA 总统专机

## 类型

**[[新美利坚]] 总统专机坠落事件** /
**《[[往日之影]]》主线导火索** / [[百灵鸟]] 精心设局的策划事件

## 事件经过

- **执行任务**:总统 [[罗莎琳德·迈尔斯]] 乘**航天专机一号**飞越夜之城
- **真实运输内容(秘密)**:专机上以**"零号乘客"**身份秘密押送 [[百灵鸟]]——
  执行 [[指令 P0-08]] 的运输任务
  - "首要任务:零号乘客安全"
  - "运输期间严禁与被运输对象进行任何交流"
  - 显示这是把百灵鸟作为**被关押对象**秘密押解
- **百灵鸟设局**:她**故意让自己被押上专机**——
  从内部策划专机在 [[狗镇]] 上空被击落
- **坠落结果**:专机在狗镇坠毁,总统迈尔斯被困此地、
  百灵鸟"借此脱身"进入狗镇的混乱

> 重要更正:**[[神经矩阵]] 一直在 [[汉森]] 手中(锁在 [[狗镇]] EBM 沛卓石化体育场最深处)**,
> 飞机上从未有过矩阵。
> 百灵鸟把自己运到狗镇,是为了**靠近矩阵**而不是空运矩阵。

## 真正动机:百灵鸟的多重套利

参见 [[百灵鸟]] 与 [[神经矩阵]]:

- 百灵鸟知道自己脑损伤 + [[V]] 的 [[Relic]] 病情
- 谎称"神经矩阵能同时治好两个人"——实际只能用一次
- **让自己被押到狗镇** = 把自己放到 [[汉森]] 矩阵所在地段
- 利用 [[V]] 的战力与 [[汉森]] 做交易,**在混乱中盗走矩阵**

## 后续连锁

- **[[所罗门·李德]]** 与 V 急需进入狗镇救援总统 + 追捕零号乘客
- **[[汉斯先生 韦德·布莱克]]** 成为李德的**最大赞助者**——
  通过协助救援总统持续削弱 [[汉森]] 势力
- 整个《往日之影》主线由此展开

## 世界观意义

航天专机一号坠机是 [[公司统治]] 时代**"国家级机密被个人套利"**的样本:

- **总统专机**这种国家级象征,在百灵鸟手里只是**布局棋子**
- 揭示 [[公司战争]] 之后,国家机器与个人野心的力量差距已被抹平
- "让自己被押解到目的地"作为情报特工的极端操作——
  说明 [[新美利坚]] 的国家安保体系已经被网监内部腐蚀到**犯人能反向操纵押送方向**
- 这是 [[V]] 进入主线的物理推动力:
  没有这次坠机,V 就不会被 [[所罗门·李德]] 与 [[汉斯先生 韦德·布莱克]] 卷入狗镇
